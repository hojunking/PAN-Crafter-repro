# PANDA s1·s3 병렬 40시간 실험 계획 — S2D 검증 / 고정 donor Stage 2

작성일: 2026-10-16. 실행 레지스트리: `panda40/plan.py`.
캠페인: `PANDA_S13_ALIGNER_STAGE2_40H_20261016_v1`.

## 1. 확정된 범위와 가설

두 서버가 **각각 최대 40시간**을 병렬 사용한다. 합계 40 GPUh가 아니라
최대 약 80 server-GPUh의 상한이다. 40시간은 캠페인 최초 시작부터의 경과
시간이며, preflight·donor 검증/보충 학습·calibration·공식 평가·저장을 포함한다.
중단 후 재시작해도 시계를 초기화하지 않는다.

- **s1:** 기존 Direct PAN Aligner와 새 S2DGlobalPANAligner를 동일 Teacher,
  동일 데이터·초기화 seed·loss·학습량으로 비교한다. S2D의 효과는 아직 가설이다.
- **s3:** 해당 서버에서 얻은 **하나의 기존 Direct/MASK2 donor A/T**를 고정하고,
  새 W112/D123 Student를 각 case/seed마다 처음부터 학습한다. donor 교체로
  loss 효과를 설명하는 혼선을 막는다.
- 두 서버 모두 WV3. s1·s3 절대 metric을 서로 직접 순위 비교하지 않는다.
- 이번 s1은 Aligner/Stage 1 검증이며, s1 S2D donor를 s3 Stage 2에 넣지 않는다.

선행 근거: donor24 A1은 HQNR 목표 통과 사례가 있었으나 ERGAS가 함께 최적이었던
것은 아니다. A3/A5는 absolute/epsilon 압력의 인접 조건이다. 따라서 A1 하나의
일시적 최고 HQNR만 근거로 구조 개선을 주장하지 않고 조건·seed 대조를 둔다.

## 2. 공통 고정 항목

| 항목 | 고정 설정 |
| --- | --- |
| 데이터 | 등록된 WV3 RR train; 공식 평가 RR20 + FR20 |
| 복원기 | W112, D(1,2,3), P0, BICUBIC_MS residual base |
| 입력 | aligned PAN + MS; **LPAN/HPAN 미사용** |
| Aligner reference | 제공된 native LMS; GT를 Aligner 입력에 넣지 않음 |
| 학습 | fresh initialization, AdamW, FP32, AMP/TF32 off |
| 배치 | effective 48 = microbatch 12 × accumulation 4 |
| 시간축 | 50,000 updates, warmup 100 + cosine, minimum LR 0 |
| 복원기 LR | 1e-4; weight decay 0.01 |
| 반복 | R1 = 261016101, R2 = 261016102 |
| seed 분리 | A/T/S 초기화·RR 표본·augmentation·epsilon 독립 stream |
| 평가 | 같은 paused model로 원본 PAN/native LMS 기준 RR20·FR20 |
| 필수 로그 | HQNR, SCC, ERGAS; loss 및 gradient/support 진단 |

공식 평가는 **마스킹하지 않는다**. 학습의 MASK2와 분리하여 기존 RR crop,
FR full-frame, radiometry/clipping, Q8/JQM 및 scene별 평균 구현을 그대로 쓴다.
학습 epsilon은 area-uniform disk radius 3 current-PAN px이며 FR에서 ×4 하지 않는다.

## 3. s1 — Direct/S2D 대조 큐

`D_`는 기존 Direct, `S_`는 새 S2D. 모든 case의 reconstruction loss는 기존
Stage 1 MASK2를 그대로 적용한다. S2D는 별도 구현이며 기존 Aligner 파일을
교체하지 않는다. 동일 pair는 Teacher 초기화·학습 스트림·epsilon seed를 맞춘다.

| 그룹 | case | Aligner | λabs | λepsilon | LR A | 반복 |
| --- | --- | --- | --- | --- | --- | --- |
| A1 geometry | D_A1 / S_A1 | Direct / S2D | 2 | 0.003 | 1e-5 | 각각 R1, R2 |
| A3 geometry | D_A3 / S_A3 | Direct / S2D | 3 | 0.0015 | 1e-5 | 각각 R1, R2 |
| A5 geometry | D_A5 / S_A5 | Direct / S2D | 2 | 0.0015 | 1e-5 | 각각 R1, R2 |
| 여유시간 | S_LR | S2D | 2 | 0.003 | 5e-6 | R1, R2 |

실행 순서: `D_A1/R1 → S_A1/R1 → D_A1/R2 → S_A1/R2`, 다음 A3, A5,
마지막 S_LR. 총 12개 주 비교 + 2개 예비 실행이다. 한 그룹의 남은 실행들을
끝낼 예산이 없으면 그룹 전체를 skip하며, 시간 때문에 한 seed만 선택해서
보고하지 않는다. 이미 완료된 seed를 삭제하지 않고 실제 완료 범위를 기록한다.

S2D는 crop/normalization 후 PAN과 LMS 모두 pixel-unshuffle(4)를 적용한다.
정보를 버리는 단순 downsampling과 같다고 해석하지 않는다. 원본 이미지
픽셀 단위 dy/dx 한 벡터를 출력하고 기존 native warp와 동일한 loss를 사용한다.

분석은 조건별 2-seed의 HQNR·ERGAS·SCC, 선택 step, correction 크기,
support 비율, epsilon consistency, 학습시간/비용을 함께 비교한다. 최고
HQNR이 올라도 ERGAS가 악화되면 구조 개선 확정으로 쓰지 않는다.

## 4. s3 — 하나의 기존 Direct donor + 새 Stage 2

우선 해당 서버의 **완료된** donor24 WV3/MASK2 실행에서 실제 파일이 남은
후보를 찾는다. HQNR ≥ 0.959 후보 중 ERGAS 최소를 선택하고, 없으면 최고
HQNR 후보를 `exploratory`로 명시한다. SCC는 순위에 사용하지 않는다.
선택 파일 SHA와 A/T를 재로딩하고 RR20·FR20 예측/metric을 재검증한 뒤
`fixed_donor.json`으로 동결한다. 모든 Stage 2 case는 같은 A/T·파일 SHA를 쓴다.

사용 가능한 로컬 donor가 없으면 D_A1/R1을 fresh H50으로 한 번 학습한다.
이 비용도 같은 40시간에 포함된다. 기준 미달이어도 탐색용 donor라는 표기를
유지하고 Stage 2를 진행한다. donor 후보가 있었지만 파일/재평가 검증에 실패한
경우는 조용히 다른 모델로 대체하지 않고 오류를 드러낸다.

| 순서 | case | variant | α | β | γ | loss 영역 | 반복 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | G | gt_only | 0 | 0 | 0 | MASK2 | R1 → R2 |
| 2 | E | panda_e | 0.5 | 0 | 0 | MASK2 | R1 → R2 |
| 3 | ES | panda_e | 0.5 | 0.05 | 0 | MASK2 | R1 → R2 |
| 4 | Q | panda_condq | 0.5 | 0.05 | 0.5 | MASK2 | R1 → R2 |
| 5 | Q_FULL | panda_condq | 0.5 | 0.05 | 0.5 | 전체 픽셀 대조 | R1 → R2 |
| 예비 | Q_WEAK | panda_condq | 0.25 | 0.025 | 0.25 | MASK2 | R1 → R2 |

총 10개 주 비교 + 2개 예비. 먼저 같은 case의 두 seed를 완료한 후 다음으로
진행한다. 각 Student는 fresh W112/D123이며 Teacher 복사 초기화가 아니다.
Aligner/Teacher는 frozen, optimizer는 Student parameter만 소유한다.

### Loss와 MASK2 연결

band 평균 절대 오차를 eS, eT라 하고 δ=1e-6으로 둔다.

```text
d_e = stopgrad(eT / (eT + tau_e))
a_T = stopgrad(max(eS - eT, 0) / (eS + delta))
w_H = 1 + alpha*d_e + gamma*d_e*r_q_bar
L_H = mean_domain(w_H * eS)
L_S = mean_domain((1-d_e) * a_T * abs(S-T).mean_band)
L = L_H + beta*L_S
```

G는 GT-only, E는 hard error weighting, ES는 selective soft KD 추가,
Q는 conditional-q hard weighting 추가다. 별도 output spatial loss나 Stage 2
epsilon loss는 없다. q weight는 fixed ROI8 밖에서 0이며 GT hard supervision을
없애는 형태가 아니다.

MASK2는 Stage 1과 같은 native warp support를 correction에서 **detach**하여
구한다. Stage 2의 Hard/Soft는 **샘플별 유효 픽셀 평균 → batch 평균**으로
줄여 샘플마다 동일 가중치를 유지하고 microbatch accumulation과 일치시킨다.
이는 Aligner가 mask를 움직여 loss를 줄이는 gradient를 만들지 않는다.
ROI8 Scharr stencil의 유효성 검사는 유지하고 support 위반은 fail-closed한다.

MASK2와 FULL은 calibration artifact를 따로 만든다. `tau_e`는 각각 **유효한
train 픽셀 전체**와 **전체 train 픽셀**의 정확한 median으로 재계산한다.
q/g는 동일한 fixed ROI8, RR train 전체, augmentation 없는 frozen donor 출력으로
K=5 conditional empirical CDF를 구축한다. old calibration 또는 다른 mask
정책의 artifact를 혼용하지 않는다. 따라서 Q 대 Q_FULL은 mask와 그에 일관된
tau_e calibration을 함께 바꾸는 대조이며, tau_e까지 완전히 고정한 단일 변수
실험으로 표현하지 않는다.

## 5. 체크포인트 선택과 시트 표시를 구분한다

**모델 저장/선택:** HQNR ≥ **0.959** 후보가 있으면 그 안에서 **ERGAS 최소**.
동률이면 HQNR, 이른 step으로 결정한다. 아직 HQNR 통과 후보가 없으면
best-HQNR를 탐색용으로 저장한다. best-HQNR backup도 별도 보존한다.
SCC는 출력·분석용이며 선택 tie-breaker에 넣지 않는다. 마지막/중단 시점의
resume용 모델은 좋은 모델 선택과 구분한다.

**기존 시트 표시:** HQNR ≥ **0.960** 그리고 ERGAS ≤ **2.045**인 모든 step,
없으면 run별 best-HQNR 한 행. 연구 checkpoint의 0.959 gate와 별개인 기존
표시 규칙을 그대로 유지한다. 시트에 없는 평가가 삭제되었다는 뜻은 아니다.
전체 평가와 checkpoint provenance는 로컬 JSON/outbox에 보존된다.

Run에는 `case`, `a/b/q` 또는 `a/eps/lrA`, `MASK2/FULL`, replica를 짧게 쓴다.
매 공식 평가 직후 immutable outbox를 생성하고 별도 publisher가 주기적으로
같은 `WV3-ablations`에 반영한다. 네트워크 실패는 학습을 멈추지 않고 재시도한다.
값 append와 Result_ID readback 검증을 사용하여 이전의 멀리 떨어진 빈 행
문제를 재발시키지 않으며 다른 서버/과거 캠페인 행을 정렬·삭제하지 않는다.

## 6. 40시간 예산·검증·cost

고정된 시간 추정으로 모든 case 완료를 약속하지 않는다. Direct/S2D 또는
G/Q의 disposable 100-update + 공식40 preflight에서 update p90·평가시간을
실측하고, 그룹의 남은 H50 실행 비용 합에 1.2 safety factor를 적용한다.
마지막 1,800초는 closeout 여유로 남긴다. 예산 부족 그룹은
`SKIPPED_BUDGET`; 정상적으로 시작한 실행도 deadline/사용자 중단 시에는
부분 결과와 중단 checkpoint를 명시한다. 성능 결과에 따른 seed 선별은 하지 않는다.

Cost는 GPU가 격리되고 학습 trainer가 CPU에 있을 때 fresh deployment graph로
측정한다. Stage 1은 실제 Direct/S2D A+warp+T, Stage 2는 A+warp+S만 포함한다.
frozen training Teacher·loss·calibration은 deployment cost에서 제외한다.
RR256/FR512, batch1 FP32의 Params, MAC-scale 부분 FLOPs, latency, peak allocated
memory를 보존하고 같은 서버/정확한 구조·코드 signature로만 재사용한다.
불완전하거나 CPU-only인 측정을 시트의 GPU cost로 기입하지 않는다.
Train/Eval 시간은 해당 선택 step까지의 실제 로그 합; 추정 ETA를 실측처럼 쓰지 않는다.

검증 대상: 동일-state 평가, 원본 reference 유지, gradient 분리, mask support,
calibration 정책 분리, model/optimizer/stream checkpoint 무결성, donor 재로딩,
seed pair admission, 업로드 응답 유실·동시 append·readback, cost 구조 구분이다.
CPU synthetic smoke 결과는 정식 metric 또는 공식 checkpoint 후보로 올리지 않는다.

## 7. 각 서버 실행

사용자가 push한 commit을 s3에서 pull한 뒤, 저장소 루트에서 다음 한 명령으로
해당 서버 캠페인을 시작한다. **git pull 자체가 실험을 자동 실행하지는 않는다.**

```bash
bash scripts/run_panda40_docker.sh s3 --replace-donor24
```

s1은 서버 인자만 `s1`로 바꾼다. `--replace-donor24`는 해당 서버의 정확한 기존
donor24 학습만 안전하게 종료하고 새 실행으로 전환하기 위한 명시 옵션이다.
데이터와 `gspread/account.json`은 각 서버의 로컬 자산이며 Git으로 공유하지 않는다.
launcher가 검증·필요 donor 보충·calibration·학습·평가·publisher를 연결하므로
수동으로 중간 calibration 명령을 여러 번 실행할 필요가 없다.

산출물은 `work_dir/panda40/<campaign>/<server>/WV3/` 아래에 보존한다.
캠페인 종료 후에도 업로드 미완료가 있으면 outbox는 남고 재실행 가능한 상태다.
최종 upload readback과 안정된 terminal-state가 확인된 경우에만 publisher가
`terminal_upload.json`을 남기고 종료한다.
