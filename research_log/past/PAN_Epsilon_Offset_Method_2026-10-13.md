## 2. ε 가 하는 일

정합 모듈 A 는 PAN 과 MS 기준 영상을 보고 PAN 을 옮길 전역 보정량 c = (dy, dx) 를 예측함. 정답 정합량이 없으므로, PAN 을 **알려진 양 ε 만큼 더 옮긴 입력**에서 예측이 정확히 그만큼 반대로 달라지도록 가르침.

```text
c₀ = A(P,      R_A)          # 원래 입력의 보정량
P_ε = W(P, ε)                 # 합성 변위 (기울기 없음)
c_ε = A(P_ε,   R_A)          # 옮긴 입력의 보정량
L_ε = mean | c_ε + ε − stopgrad(c₀) |      # 이상적이면 c_ε − c₀ = −ε
```

| 기호 | 뜻 | 언제 정해지나 |
|---|---|---|
| b | 합성 변위의 최대 길이(반경), PAN 화소 | 관측 통계를 보고 run 시작 전에 고정 |
| ε | 표본 하나에 실제로 더하는 2차원 변위 | update 마다 표본별로 새로 뽑음 |
| c₀ · c_ε | 원래 · 옮긴 입력에 대한 정합 모듈의 보정량 예측 | 각 forward 에서 예측 |
| R_A | 정합 모듈의 MS 기준 영상(4배 bicubic MS, 또는 원본 데이터의 LMS) | 데이터에서 고정, 기울기 없음 |

warp 의 부호는 샘플링 위치 기준 — `P̃(y, x) = P(y + dy, x + dx)`. 예를 들어 dx = +2 이면 PAN 내용이 왼쪽으로 2 화소 이동하고, 이상적인 정합 모듈은 dx 예측을 −2 만큼 바꿔야 함.

이 손실은 **같은 스케일에서 알려진 추가 이동에 반응하는 관계**만 가르침. 예측에 일정한 치우침(bias)이 있어도 차분에서 상쇄되므로 절대 정합량의 정답을 주지 않음.

## 3. 반경 b 산정

### 3.1 원칙

- b 는 데이터셋의 관측된 변위 규모를 참고해 **사람이 정하는 증강 설정값**. 역전파로 배우는 값도, 영상마다 자동 추정하는 값도 아님.
- run 시작 전에 고정하고 run 중에 바꾸지 않음. 성능을 보고 고르지 않음(반경 sweep 없음).
- 관측 통계의 **크기만** 쓰고 방향은 쓰지 않음 — 분포는 0 중심 · 모든 방향.
- 정합 모듈 출력에 ±b 제한(clamp · tanh)을 두지 않음. 반경은 학습 때 경험하는 추가 이동의 범위이지 출력 범위가 아님.

### 3.2 값의 이력

| 시점 | 값 | 근거 | 상태 |
|---|---|---|---|
| 09-10 처음 | 1.0 PAN 화소 | WV3 **학습 세트**에서 추정한 전역 변위 크기 P90 0.250 MS 화소 × 4 | 대체 |
| 09-10 변경 | **2.0 PAN 화소** | WV3 **원 해상도 입력**의 변위 크기 P95 1.98 PAN 화소 근방까지 경험시키기 위함 | **현재** |

- 반경 2.0 의 근거에 **논문 평가용 원 해상도 테스트 20장의 입력 통계**가 들어감. 정답을 쓴 것은 아니지만 "학습 세트만으로 정한 설정", "테스트를 보지 않은 설정"이라고 쓰지 않음.
- 데이터 버전 · 전처리 · 패치 크기가 바뀌면 다시 검토할 값. 자동으로 데이터에 맞춰지는 값이 아님.

## 4. ε 표본 추출

\[
u_1,u_2\sim U(0,1),\quad
\rho=b\sqrt{u_1},\quad \theta=2\pi u_2,\quad
\epsilon=(\rho\sin\theta,\ \rho\cos\theta)=(dy,\ dx),\quad b=2.0
\]

- **원판 면적 균등.** `ρ = b·u` 가 아니라 `ρ = b·√u` — 전자는 원점 근처에 표본이 몰림. 축별 독립 균등(정사각형)도 쓰지 않음 — 대각선에서 길이가 √2·b 까지 커짐.
- 분포에서 유도되는 값: 축별 표준편차 b/2 = 1.0, 길이 평균 2b/3 ≈ 1.33, 길이 중앙값 b/√2 ≈ 1.41 PAN 화소.
- **표본마다 하나의 전역 벡터** — 같은 영상의 모든 위치에 같은 이동. 국소 변형 없음.
- **update 마다 새로 뽑음.** 증강(뒤집기 · 회전)을 마친 원래 PAN 에서 매번 만들고, 이전 변위 위에 누적하지 않음.
- **전용 난수 생성기.** 데이터 순서 · 증강과 독립(Teacher 계열은 별도 CPU 생성기, 10-06 구현은 seed + 500000). 10-06 구현은 손실이 꺼진 조건에서도 같은 난수를 소비해, 조건끼리 같은 update 에 같은 ε 가 가도록 맞춤.

## 5. 적용과 손실

### 5.1 warp

- `grid_sample` bicubic, 경계 `border`, `align_corners=False`, FP32. ε 에 대해서는 기울기를 흘리지 않음(`P_ε` detach).
- PAN 만 옮김. 정답 영상 · MS · MS 기준 영상의 좌표는 그대로.
- bicubic 재샘플링이 두 번(합성 변위 → 정합 보정) 들어가므로, 한 번에 합친 이동과 정확히 같지는 않음(흐림 · 경계 support 차이).

### 5.2 손실과 기울기 경로

- `L_ε = mean |c_ε + ε − sg(c₀)|` — 성분별 L1 평균, PAN 화소 단위. c₀ 는 stop-gradient(10-06 계획에 대조용 대칭 · stop-gradient 없는 조건 1개).
- **U-Net 에는 변위 입력을 넣지 않음.** 복원 손실은 매 update 원래 입력으로만 계산하고, ε 경로는 정합 모듈의 일관성에만 씀.
- 최종 손실 = 복원 손실 + λ · L_ε (해당 update 에서 ε 경로가 켜진 경우).

### 5.3 주기와 계수

| 구현 | ε 경로가 켜지는 update | λ | 비고 |
|---|---|---|---|
| 기준 Teacher 계열 — 보정량 일관성 가중치 탐색에서 고른 1e-4 Teacher, 이후 WV3 · GF2 Teacher | 홀수(0-based) update, 즉 격 update | **1e-4** | 증가 일정(ramp) 없음 |
| QB Teacher | 같음 | **3e-4** | |
| 10-06 Teacher 단독 실험 계획(정식 학습 전) | **매 update** | 주력 **1e-3** · 대조 0 / 1e-4 / 1e-2 · 기존 방식 재현(격 update, 데이터셋별 기존 λ) | 반경 2.0 은 전 조건 공통 |
| 09-10 최초 구현(현재 미사용) | 원래 · 변위 입력 1:1 | 0.01, 5,000 update 증가 일정 | 변위 입력을 U-Net 복원에도 사용 — 현재 방식과 다름 |

λ 1e-4 는 09-12 가중치 탐색에서 3 seed 모두 정합 모듈 없는 기준보다 HQNR 이 높았던 값이고(평균 +0.0044), 09-13 정밀 확인(3e-5 · 3e-4 모두 평균 낮음)에서 유지됨.

### 5.4 추론

합성 변위를 넣지 않음(ε = 0). 정합 모듈이 입력에서 예측한 보정량 c₀ 로 PAN 을 옮긴 뒤 복원함.

## 6. ε 학습이 제대로 됐는지 재는 방법

### 6.1 반응률(gain)

알려진 변위 ε 를 넣고 보정량 변화 Δ = c_ε − c₀ 를 재서,

\[
\text{gain}=\frac{-\sum \Delta\cdot\epsilon}{\sum \epsilon\cdot\epsilon}
\]

정확한 보정이면 1, 입력 이동에 무반응이면 0. 함께 보는 값: 잔차 `Δ + ε` 의 성분별 MAE · 끝점 오차(EPE), 축별 gain.

이 값은 **주입한 추가 변위에 대한 반응률**이지 실제 센서 어긋남의 교정률이 아님.

### 6.2 고정 변위 묶음 (10-06 구현)

| 묶음 | 내용 |
|---|---|
| 축 방향 16개 | 상하좌우 4방향 × 반경 0.25 · 0.5 · 1 · 2 |
| 대각 방향 16개 | 대각 4방향 × 같은 반경 |
| 원판 64개 | 학습과 같은 원판 분포에서 고정 seed 로 뽑은 64개(학습에 쓰지 않은 표본) |
| 범위 밖 8개 | 축 방향 × 반경 4 · 8 — 학습 반경 밖, 판정과 분리해 진단만 |

축 방향 16개 묶음에서 **완전히 무반응인 예측기의 MAE 는 0.46875 화소** — 반응 여부를 판단하는 기준선. 같은 축 방향 16개 묶음은 고정 Teacher 정합 모듈의 정합 일관성 점수 q 계산에도 쓰였음.

### 6.3 현재 측정값 (10-06 진단, 기존 학습 완료 모델)

| 모델 | 학습 조각 64² | 축소 해상도 256² | 원 해상도 512² |
|---|---:|---:|---:|
| WV3 Student | 0.043 | 0.038 | **0.029** |
| QB Student | 0.043 | 0.042 | **0.020** |
| GF2 Student | 0.199 | 0.204 | **0.140** |

원 해상도 MAE 는 WV3 0.458 · QB 0.463 · GF2 0.411 화소로, WV3 · QB 는 무반응 기준선(0.469)과 거의 같음. Teacher 도 비슷한 수준이라 Student 학습 과정에서 잃은 것으로 보기 어려움.

## 7. 알려진 한계 · 열린 문제

1. **반응이 매우 약함.** 반경 2 안의 알려진 변위에도 gain 0.02–0.20. λ 가 작고 복원 손실과 목적이 충돌한다는 설명이 가능하지만 확인되지 않음(10-06 계획의 λ 1e-3 · 매 update 조건이 이를 검증하는 설계).
2. **상대 반응만 가르침.** 예측 치우침은 상쇄되므로 절대 정합의 정답이 없음.
3. **스케일 대응 없음.** 보정량은 입력 PAN 의 화소 단위 그대로 적용됨. 같은 영상을 4배 축소해도 예측 크기는 1.04–1.26배만 변함 — 원 해상도에서 4배 큰 변위를 내도록 강제하는 장치가 없음.
4. **MS 기준 영상의 위상.** 4배 bicubic MS 는 정답 대비 축마다 약 0.5 화소 위상 차이가 있음(원본 데이터의 LMS 는 약 0). 이 차이를 센서 어긋남으로 간주하면 안 됨 — 10-06 계획이 원본 LMS 를 정합 모듈 기준으로 쓰는 조건을 비교함.
5. **센서 공통 반경.** QB 원 해상도 변위 P95(2.98)가 반경 2.0 을 넘음. 센서별 반경은 검토되지 않음.
6. **반경 근거에 테스트 입력 통계 포함**(§3.3).
