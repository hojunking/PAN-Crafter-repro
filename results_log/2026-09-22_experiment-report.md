# 2026-09-22 실험 보고서 — GF2 추가 학습 세 방향 · GF2 PAN 혼합 증강 · PAN-Crafter 원 모델 재현(s3·s4·s5)

**작성일:** 2026-09-22
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** GF2 — Gaofen-2 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 GF2 세트. MS 4밴드 + PAN 1밴드. PAN-Crafter 원 모델 재현(③)에는 같은 벤치마크의 WV3(WorldView-3, MS 8밴드) · QB(QuickBird, MS 4밴드) 세트로도 학습하고, WV2(WorldView-2, MS 8밴드) 세트는 WV3 로 학습한 모델을 학습 없이 그대로 적용하는 평가에만 사용. 모든 세트가 PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 이날 실험은 모두 미리 정한 마지막 반복의 모델(학습 종료 시점)로 평가하고, GF2 는 논문 보충 표의 PAN-Crafter 값(HQNR 0.964 · ERGAS 0.552)을 같은 모델에서 동시에 넘는지를 공동 목표로 확인.
**서버:** s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

GF2 에서 작은 Student 의 원 해상도 품질을 논문 PAN-Crafter 수준(HQNR 0.964)까지 올리는 것이 목표. 전날(09-21) 서버마다 자기 Teacher 로 100,000 반복 학습한 Student 들은 대부분 ERGAS 가 논문 값(0.552) 아래로 내려왔으나 HQNR 은 최고 0.956 으로 목표 미달. 이날은 이 Student 들에서 출발한 세 방향의 짧은 추가 학습(①), 그중 효과가 난 PAN 주파수 증강의 전이 · 강도 확인(②)을 차례로 진행하고, 저녁에는 비교 기준인 PAN-Crafter 원 모델 자체의 재현(③)으로 전환.

**① GF2 학습 경로 · 감독 강도 · PAN 주파수 증강 (s3 · s4 · s5)**
- **문제:** 09-21 결과의 세 관측 — (a) 같은 설정 · 거의 같은 ERGAS(0.5513 · 0.5515)의 두 seed 가 HQNR 0.0093 차이, 축소 해상도 정확도만으로 원 해상도 품질이 정해지지 않음. (b) 정답 가중 계수를 처음부터 1 → 0.1 로 줄이면 ERGAS 는 개선되나 두 seed 모두 공간 왜곡(D_s) 악화. (c) edge 감독 계수를 절반으로 줄여도 두 seed 모두 불리. 기존 계수의 0.5–2배 조정으로는 학습 신호의 비중 자체가 거의 바뀌지 않았을 가능성(이전 50,000 반복 모델의 기울기 진단에서 Teacher 추종 · edge 항의 크기가 정답 항의 약 1% · 0.03%).
- **접근:** 새 Teacher 없이, 학습이 끝난 Student 를 출발점으로 20,000 반복 추가 학습하며 서버별로 한 방향씩 — s3 는 정답 가중 완화를 학습 후반에만 적용(학습 경로), s4 는 Teacher 추종 10배 · edge 감독 50배로 신호 비중 자체를 크게 변경(감독 강도), s5 는 학습 때만 PAN 의 고주파 세기를 무작위로 바꾸는 증강(PAN 주파수 증강). 사전 기준을 넘는 방향은 새 초기값의 100,000 반복 학습에서 다시 비교.

**② GF2 PAN 혼합(PANMIX) 전이 · 강도 (s3 · s4 · s5)**
- **문제:** ① 에서 PAN 주파수 증강만 HQNR 을 올렸으나 s5 의 Teacher 하나에서 얻은 결과. 다른 Teacher 에서도 나는지, 증강의 세기 · 빈도 · 방향 · 적용 시점 중 무엇이 효과를 정하는지 확인되지 않은 상태.
- **접근:** 세 서버가 각자 자기 Teacher 로 ① 과 같은 09-21 Student 에서 출발 — s3 는 다른 Teacher 로의 전이와 더 긴 추가 학습(60,000 반복), s4 는 증강 폭(γ ±0.125 · ±0.25 · ±0.5)과 원 입력 비율(25 · 50 · 75%) 선별, s5 는 증강 방향(낮추기만 · 높이기만)과 적용 시점(처음부터 · 후반만 · 처음만) 비교. 마지막에 서버마다 새 seed 의 새 학습에서 기본 증강 재확인. 모든 증강 설정에 같은 기준값 · 원 입력의 대조를 짝지어 입력 효과만 분리. 서버마다 40시간.

**③ PAN-Crafter 원 모델 재현 (s3 · s4 · s5)**
- **문제:** GF2 Student 의 목표치는 논문 PAN-Crafter 수치이나, 이 서버들에서 원 모델을 논문 설정대로 학습한 결과가 없음. 이전 재구성본(논문 본문 · 그림대로 다시 구현한 7.17 M 모델)도 교차 모달 주의 블록의 PAN 쪽 입력이 논문 식과 다름.
- **접근:** s3–s5 의 GF2 방법 탐색을 끝내고 전환. 교차 모달 주의를 논문 식대로 고친 원 모델 하나를 세 서버가 같은 설정으로 WV3 · QB · GF2 에서 각각 50,000 반복 학습하고, WV3 모델을 WV2 에 그대로 적용해 논문의 네 데이터셋 결과와 비교. 이 주기를 서버마다 기한 없이 반복 — 첫 주기는 논문 seed 2025, 이후 주기마다 새 seed.

| 용어 | 뜻 |
|---|---|
| PAN · MS · HRMS | 고해상도 흑백 영상 · 저해상도 다중분광 영상 · 둘을 합쳐 만든 고해상도 다중분광 영상 |
| 정답 영상 (GT) | 학습과 축소 해상도 평가의 목표 영상. 원래 MS 를 정답으로 두고, 입력은 PAN · MS 를 4배 줄여 만듦 |
| 축소 해상도 평가 · 원 해상도 평가 | 줄인 입력으로 복원해 정답과 비교하는 평가 · 실제 해상도 입력으로 복원해 정답 없이 평가하는 평가(논문과 같은 테스트 영상 20장) |
| HQNR | 원 해상도 품질 지표 = (1 − D_λ)(1 − D_s). 1 에 가까울수록 좋음 |
| D_λ · D_s | HQNR 의 두 성분 — 분광 왜곡(입력 MS 의 밴드 간 관계와 어긋남) · 공간 왜곡(입력 PAN 과의 공간 구조 어긋남). 낮을수록 좋음 |
| SCC · ERGAS | 축소 해상도 평가 지표 — 정답과의 공간 상관(높을수록 좋음) · 상대 전역 오차(낮을수록 좋음, 참고용) |
| 판정 기준 0.0031 | 같은 설정을 seed 만 바꿔 학습했을 때 HQNR 이 흔들리는 폭(표준편차의 2배). 이보다 작은 차이는 우연 범위 |
| seed | 초기 가중치 · 데이터 순서를 정하는 난수 초기값 |
| 학습 종료 시점 · 검증 ERGAS 최소 시점 | 미리 정한 마지막 반복(추가 학습 20,000 · 60,000, 새 학습 100,000, 원 모델 재현 50,000)의 모델 · 학습 중 검증 세트 ERGAS 가 가장 낮았던 시점의 모델(보조) |
| 공동 목표 (GF2) | 같은 모델에서 HQNR > 0.964 이면서 ERGAS < 0.552 — 논문 보충 표의 PAN-Crafter GF2 값 |
| px | PAN 해상도 기준 픽셀 |
| 폭 · 깊이 | U-Net 첫 단계의 채널 수 · 해상도 단계별 블록 수 |
| 정합 모듈 | PAN 과 MS 를 보고 영상 전체 이동량 (dy, dx) 하나를 예측해 PAN 만 그만큼 옮긴 뒤 U-Net 에 넣는 작은 CNN. MS · 정답 · 출력의 좌표는 그대로 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용. 여기서 Teacher 는 U-Net 폭 112 · 깊이 [1,2,3], Student 는 폭 104 · 깊이 [1,2,2] |
| 서버별 Teacher | GF2 에서 서버마다 따로 100,000 반복 학습한 Teacher(09-21). 각 서버의 Student 는 자기 서버 Teacher 만 사용 |
| 저·고주파 PAN 입력 | Student U-Net 에 정합한 PAN 과 함께 그 저주파 성분(흐림 후 4배 축소한 PAN 을 다시 확대해 같은 양만큼 옮긴 것)과 고주파 성분(PAN − 저주파)을 넣는 방식 |
| q (정합 일관성 점수) | 고정한 Teacher 정합 모듈에 PAN 을 알려진 양만큼 옮긴 입력을 여러 개 넣었을 때, 예측 이동량이 그 이동을 정확히 되돌리지 못하는 정도(표본별 잔여 오차의 평균). 낮을수록 정합 예측이 일관됨 |
| 정답 가중 (계수 α) | 정답 L1 손실. Teacher 오차가 큰 위치일수록 가중을 (1 + α × 정규화한 Teacher 오차)로 키움. 기본 α = 1 |
| Teacher 추종 (계수 β) | Student 가 Teacher 보다 정답에서 멀고 Teacher 오차는 작은 위치에서만 Student 출력을 Teacher 출력에 맞추는 손실. 기본 β = 0.1 |
| q 가중 정답 edge 감독 (계수 λE) | 출력과 정답의 경계(Scharr 미분) 차이 손실을, q 가 낮은(정합 예측이 일관된) 표본일수록 크게 가중. 기본 λE = 0.002. U-Net 에만 전달 |
| 정합 모듈 학습 (Student) | Student 정합 모듈은 q 로 가중한 정답 가중 손실로만 학습. Teacher 추종 · edge 감독 신호는 받지 않음 |
| 기준값 · 혼합 기준값 | Teacher 오차를 0–1 로 정규화하는 기준(학습 표본 3,072개의 Teacher 오차 중앙값)과 q 의 기준(같은 표본의 q 중앙값) · 증강한 PAN 까지 포함해 다시 계산한 같은 값 |
| 출발 모델 · 추가 학습 | 이미 학습을 끝낸 Student(09-21 의 100,000 반복 Student 등) · 그 가중치에서 최적화 상태만 새로 시작해 낮은 학습률로 더 학습하는 것 |
| 새 학습 | U-Net 새 초기값 + Teacher 정합 모듈 복사로 처음부터 학습 |
| 데이터 순서 | 같은 출발 모델의 대조군과 변경안이 같은 표본 순서 · 같은 뒤집기 · 회전을 보도록 맞추는 난수값. 가중치 초기값은 바꾸지 않음 |
| PAN 혼합 증강 (PAN 주파수 증강) | 학습 때만 PAN 의 고주파 세기를 배율 γ 로 바꾼 PAN 을 원 PAN 과 섞어 쓰는 증강: P_γ = G(P) + γ·(P − G(P)), G 는 가우시안 흐림(σ 1 px, 7×7). 저주파 PAN 은 바뀐 PAN 에서 다시 만들고 MS · 정답은 그대로, Teacher 도 같은 입력. 평가는 원 PAN |
| 증강 폭 · 원 입력 비율 | γ 가 1 에서 벗어나는 크기(기본 ±0.25) · 원 PAN(γ = 1)이 뽑히는 확률(기본 50%) |
| 사전 기준 (진입 조건) | 추가 학습 결과로 새 학습 확장 여부를 정하는 미리 정한 규칙 — 두 출발 모델 모두 HQNR 상승 · D_s 감소, 평균 +0.002 이상, ERGAS 증가 평균 0.5% · 각 1% 이내. s3 는 HQNR 하락 0.001 이내에서 ERGAS 평균 0.3% 이상 개선도 인정 |
| PAN-Crafter 원 모델 | 논문 모델. 교차 모달 주의 · 모드 변조 · PAN 재구성 보조 과제를 갖춘 3단계 U-Net(폭 128) |
| 교차 모달 주의 블록 | MS 특징과 PAN 특징 사이의 국소(3×3) 주의 연산으로 두 정보를 섞는 블록. 인코더 · 병목 · 디코더에 1개씩 |
| 모드 변조 | 같은 네트워크를 MS 복원 모드와 PAN 재구성 모드로 쓰기 위해 모드별로 학습한 계수로 특징을 조절하는 장치 |
| PAN 재구성 보조 과제 | 네트워크를 PAN 모드로 한 번 더 통과시켜 입력 PAN 자체(밴드 수만큼 복제)를 복원하게 하는 보조 손실. 추론은 MS 모드만 |
| WV2 적용 | WV2 는 학습하지 않고 같은 주기의 WV3 모델을 그대로 평가(논문의 WV2 평가 방식) |
| 주기 | 서버 하나가 WV3 · QB · GF2 를 한 번씩 학습하고 WV2 적용 평가까지 마치는 단위 |
