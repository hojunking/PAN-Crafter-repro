## 가장 중요한 결과 — 오늘 DML 보고서의 정정

[DML 보고서](2026-08-27_dml-teacher-teacher-170hx.md)의 peer 다양성 수치는
**밴드-원소 단위**로 계산된 것이었다. 8/18·8/20 문서의 정의(그리고 게이트 임계
≥0.97 / <+5% 가 묶여 있는 스케일)는 **픽셀 단위**(밴드 평균 오차 지도)다.

| M0 다양성 | 보고서 값 (원소 단위) | **교정 값 (픽셀 단위)** |
|---|---:|---:|
| 오차 상관 | 0.9557 | **0.9797** |
| 오라클 이득 | +8.16% | **+4.31%** |

**정정 사항:**
1. **조기 게이트는 픽셀 정의로는 "보류" 였다** (ρ≥0.97 이고 오라클<+5%). M1 은 이미
   완료됐으므로 운영상 무효화는 없지만, "게이트 통과" 서술은 정의 선택의 산물이었다.
2. **"시드 다양성(0.9557) > 구조쌍(0.9733)" 비교는 철회한다** — 단위가 달라 비교가
   성립하지 않는다. 픽셀 단위로는 0.9797 로 구조쌍보다 **높다** (예상대로 시드쌍이 더 닮음).
3. **M1 의 핵심 결론(RR↔FR 트레이드)은 영향 없다** — 대응표본 검정 기반이라 다양성
   정의와 무관하다. 다만 "DML 헤드룸이 예상보다 크다" 는 §2 서술은 축소해 읽어야 한다.

`CONVENTION.md` §5 에 따라 원 보고서는 고치지 않고 이 문서로 정정한다.

## 미검증으로 남은 것 (집계 버그로 판정 유실 — 자체 평가)

- **비결정 CUDA 로 λ=0 구간에도 M0/M1 궤적이 갈라진다** — 실제로 Iter[100] anchor 가
  0.19% 어긋나는 것을 관측했다. paired init 은 초기 상태 동일성을 보장하지만 **궤적
  동일성은 보장하지 못하므로**, DML 보고서의 sub-1% 대응표본 p 값은 run 잡음을 0 으로
  가정한 만큼 과신이다. 보고서 §5 의 "확정은 시드쌍 반복 후" 방침이 그대로 유효하다.
- 캠페인 체인이 명세 §4 의 이분 실행(C4 무손실 시 C3/C2 생략)을 구현하지 않음 —
  s1 의 의도된 단순화로 보이나, c4 완료 시점에 생략 여부를 사람이 판단할 것.

## 제안 — `_run_cases.sh` stale checkpoint 수정안 (체인 유휴 시 적용)

```bash
# run 시작 전, 완료 산출물이 없는데 잔존 상태가 있으면 fresh start 전에 치운다
if [ ! -f "work_dir/${TAG}/results/reduced_best_hqnr.mat" ] && [ -d "work_dir/${TAG}" ]; then
    mv "work_dir/${TAG}" "work_dir/${TAG}_stale_$(date +%s)"   # 삭제 대신 보존
fi
```
또는 재시도와 동일하게 첫 실행도 `--resume $(latest_ckpt)` 로 이어붙이는 방안
(best_state.json 이 함께 남아 있으므로 과거 best 가 보존된다).
