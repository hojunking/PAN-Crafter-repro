# 2026-09-20 실험 보고서 — QB·GF2 이식 40시간(s1–s5) · GF2 HQNR 격차 감사(s1) · GF2 전 서버 20시간(s1–s5)

**작성일:** 2026-09-20
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** QB · GF2 — WV3 와 같은 공개 팬샤프닝 벤치마크(PanCollection)의 QuickBird 위성 세트(QB)와 Gaofen-2 위성 세트(GF2). 둘 다 MS 4밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배. 화소 최대값 QB 2047(11비트) · GF2 1023(10비트), 학습 조각(PAN 64×64) QB 17,139개 · GF2 19,809개. QB 학습 · 검증 세트는 MS 약 2/3 가 정답 영상과 저해상도 1 px 어긋나 있어 정답에서 다시 만든 복구본 사용. WV3(WorldView-3 위성, MS 8밴드)는 이전 계획 변경과 비교 참고로만 등장.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위(WV3 실측)라 "차이 없음"으로 판정. 이날 목표는 논문 PAN-Crafter 의 세트별 보고값 — QB HQNR 0.920 · ERGAS 3.570, GF2 HQNR 0.964 · ERGAS 0.552(논문 본문 표에는 0.522 로, 논문 안에서 값이 다름). 모델마다 50,000 반복 중 1,010 반복 간격 50개 시점을 모두 평가.
**서버:** s1 · s2 · s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

**s1–s5 — GF2 에서 구조를 고정한 채 학습 균형을 바꾸면 격차가 줄어드는가 (GF2 전 서버 20시간)**

| 정합 모듈 | PAN 과 MS 를 보고 영상 전체 이동량 (dy, dx) 하나를 예측해 PAN 만 그만큼 옮긴 뒤 U-Net 에 넣는 작은 CNN. MS · 정답 · 출력의 좌표는 그대로 |
| 보정량 일관성 | PAN 을 ε 만큼 더 옮긴 입력에 대한 예측 이동량이 원래 예측보다 정확히 ε 만큼 달라지도록 하는 손실. 정합 모듈에만 학습 신호 |
| 반응 기울기 | 64×64 조각의 PAN 을 알려진 양만큼 옮겼을 때 예측 이동량이 따라 바뀌는 비율(축별, (dy, dx)). −1 이면 추가 이동을 정확히 되돌림, 0 이면 반응 없음. 이날 값은 학습 조각 128개의 평균 |
| 저주파 PAN · 고주파 PAN | PAN 을 가우시안(σ 1.98)으로 흐리게 해 1/4 로 줄였다가 다시 확대한 영상 · PAN 과 저주파 PAN 의 차. 정합 모듈이 예측한 이동량만큼 PAN 과 함께 옮겨 입력 |
| q (정합 일관성 점수) | 고정한 Teacher 정합 모듈에 PAN 을 알려진 양만큼 옮긴 입력을 여러 개 넣었을 때, 예측 이동량이 그 이동을 정확히 되돌리지 못하는 정도(표본별 잔여 오차의 평균). 낮을수록 정합 예측이 일관됨 |
| q 기준값 · 무반응 값 | 학습 조각 3,072개(회전 4가지)의 q 중앙값. 표본의 q 가 이 값보다 낮을수록 edge 감독 · 정합 모듈 조정을 크게 반영(가중 = 기준값 / (기준값 + q)) · 정합 모듈이 입력과 상관없이 같은 이동량만 낼 때의 q(0.469) |
| e (복원 오차) · Teacher 오차 기준값 | 표본의 복원 결과와 정답 영상의 차이 · 학습 조각 3,072개에서 잰 Teacher 복원 오차의 중앙값. Teacher 오차가 이 값보다 큰 위치일수록 정답 가중을 키우고 Teacher 추종을 줄임 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용. 여기서는 Student 가 Teacher 보다 작음 |
| 정답 기준 적응형 KD (정답 가중 α · Teacher 추종 β) | 정답 손실은 모든 위치에 유지하고, Teacher 오차가 큰 곳은 정답 손실 가중을 키우고(계수 α), Student 가 Teacher 보다 뒤지는 곳에서만 Teacher 출력을 따르게 하는(계수 β) KD |
| q 가중 정답 edge 감독 | 출력과 정답 영상의 경사(Scharr 필터) 차이를 줄이는 손실. 표본의 q 가 낮을수록(Teacher 정합 반응이 일관될수록) 크게 반영 |
| Student 정합 모듈 조정 | Student 정합 모듈을 Teacher 정합 모듈로 시작해 q 가중 정답 손실로만 이어 학습. Teacher 추종 · edge 손실은 정합 모듈에 전달하지 않음 |
| PAN 재구성 보조 과제 · 모드 변조 | 원 PAN-Crafter 의 구성 요소 — 하나의 망이 HRMS 와 PAN 을 함께 복원하도록 학습하는 보조 과제 · 어느 쪽을 복원하는지에 따라 특징을 조절하는 층 |
| 출력–PAN 유사도 · 입력 MS–저주파 PAN 유사도 | D_s 를 밴드 · 장면별로 나눈 두 항. 앞쪽이 더 크면 출력이 원래 MS 가 PAN 과 맺던 관계보다 PAN 을 과하게 따른다는 뜻 |
| CANConv 배포 가중치 · 무처리 기준 | 다른 공개 팬샤프닝 모델(CANConv) 저자가 배포한 학습 가중치 · 4배 확대한 MS 를 그대로 출력으로 본 기준. 둘 다 문헌 값과 비교해 평가기를 검증하는 데 사용 |
| MTF 이득 | D_λ 계산에서 센서의 광학적 흐림을 흉내 내는 필터의 상수 |
| MS–정답 복구본 (QB) | QB 학습 · 검증 세트에서 MS 가 정답 영상과 저해상도 1 px 어긋나 만들어진 조각을 정답에서 다시 만든 세트 |
| 평가기 | 팬샤프닝 표준 평가 코드(DLPan-Toolbox, MATLAB)를 파이썬으로 옮긴 것 |
