## 1. 논문 대비 현재 아키텍처

전체 목록은 [불일치 문서](2026-08-25_paper-vs-code-divergences.md)에 있다. 여기서는 **현재 무엇이
적용된 상태인가**를 정리한다.

### 1.1 반영된 것 (11곳)

| 분류 | 항목 | 배포 코드 | 현재 재구성본 |
|---|---|---|---|
| **구조** | spatial scale | 4 | **3** |
| | Down/UpConv | 3 / 3 | **2 / 2** |
| | AttnBlock | 5 | **3** (H/2 enc · H/4 bottleneck · H/2 dec) |
| | 배치 원칙 | H/2 에도 CM3A | **고해상도는 ResBlock only** |
| **블록** | ResBlock 정규화 | `GroupNorm32` | **LayerNorm** (Eq 5) |
| | mode modulation | mode token + `Linear(128,2C)`, 블록당 33,024 | **γ,β ∈ R^C 직접 학습**, 블록당 512 (Eq 6) |
| | dropout | 0.2 | **0.0** (수식에 없음) |
| **CM3A** | local attention k | bottleneck 만 k=1 | **전 위치 k=3** |
| | key 별칭 (A-1) | `q, k_pan, k_pan = …` | **Eq (10)/(11) 대로** |
| | LocalAttn (A-2) | `reset_parameters()` 미호출 | **호출 + bias 0 고정** (Sec 3.3) |
| **입력** | 채널 | 11ch | **9ch** — `concat(I_pan, I_lrms)` |

결과: **params 9.969 M → 7.1707 M.** 논문 주장 7.170 M 과 **+0.01%** 다.

### 1.2 아직 반영하지 않은 것 (2곳)

| 항목 | 논문 | 왜 안 했나 |
|---|---|---|
| `[K_pan\|V_pan]` | 결합 conv 1개 (Eq 11) | 결합하면 params 가 7.2122 M 이 되어 지금의 +0.01% 일치가 **+0.59%** 로 벌어진다. 방침(논문 우선)상 적용 대상이지만, 그러면 **파라미터 일치가 우연이었을 가능성**을 함께 받아들여야 한다 |
| 증강 `crop` | *"random cropping"* | **논문대로 구현할 수 없다.** 학습 패치가 이미 최소 단위(PAN 64×64 / MS 16×16)라 잘라낼 여지가 없다. 현재 `crop: False` 를 s1 Teacher screening 에서 시험한다 |

### 1.3 논문이 명시하지 않아 우리가 정한 것

| 항목 | 선택 | 근거 |
|---|---|---|
| ResBlock depth 배분 | `(2, 2, 4)` | params 7.17 M 제약에서 총 12개. 배분은 미확정 — `(1,3,4)`·`(3,2,2)`·`(1,1,8)` 이 전부 같은 값이다 |
| `mlp_ratio` | 4.0 | params 적중이 두 갈래였다(mlp 4.0 + 12블록 / mlp 1.0 + 13블록). §3.3 에서 **구분 불가**로 판정 |
| `s_embed_size` | 128 | 배포본 유지 |
| 잔차 기준선 | `bicubic(ms,×4)` | 논문이 보간법을 안 적었다. 배포본 유지 |

## 2. 판정 기준의 변화 — 이 문서의 전제

**시드 표준편차를 두 계열에서 따로 쟀고, 값이 12배 다르다.**

| 계열 | 구성 | 시드 3벌 ERGAS | σ | **2σ** |
|---|---|---|---:|---:|
| 배포 코드 (프루닝 6.694M) | `x1_panbr_dec4` 계열 | 2.2527 / 2.2344 / 2.2638 | 0.0149 | **1.32%** |
| **재구성본 (7.171M)** | `p25_s*` | 2.2176 / 2.2195 / 2.2199 | **0.0012** | **0.11%** |

> **주의: 두 값은 같은 조건의 비교가 아니다.** 앞은 프루닝된 6.694 M, 뒤는 온전한 7.171 M 이다.
> 재구성 자체가 안정성을 준 것인지, 프루닝이 불안정을 만든 것인지는 이 데이터로 구분되지 않는다.
> 다만 **각 계열 안에서의 판정선으로는 유효하다.**

**대응표본 t-검정만으로는 부족하다.** 그것은 같은 가중치를 20장에 적용해 이미지 간 변동만
제거한다. 시드를 바꾸면 뒤집힐 수 있다. **아래 모든 판정은 해당 계열의 2σ와 함께 읽는다.**

## 3. 내부 튜닝 결과

### 3.1 A-1 / A-2 (배포 코드 계열) — 재판정이 필요하다

50K 4벌. 선택 규칙을 고정하고 대응표본으로 비교했다.

| 선택 규칙 | 지표 | baseline | fixed | 차이 | p | **2σ=1.32% 기준** |
|---|---|---:|---:|---:|---:|---|
| test-sel | ERGAS↓ | **2.1633** | 2.1765 | +0.61% | 0.0057 | **구분 불가** |
| val-sel | ERGAS↓ | **2.1643** | 2.1804 | +0.74% | 0.0014 | **구분 불가** |
| test-sel | SAM↓ | 2.9093 | **2.9019** | −0.26% | 0.0184 | **구분 불가** |
| val-sel | SAM↓ | 2.9123 | **2.9024** | −0.34% | 0.0202 | **구분 불가** |

**기존 결론을 정정한다.** 8/24 재현 감사에서 "논문 수식대로 고치면 ERGAS 는 나빠지고 SAM 은
좋아진다 (둘 다 유의)" 라고 썼는데, **p 값은 작지만 차이가 전부 2σ 아래**다. 시드 1벌씩으로
얻은 값이므로 **RR 지표에서는 A-1/A-2 효과를 주장할 수 없다.**

### 3.2 그런데 full-res 와 zero-shot 에서는 방향이 다르다

| 실행 | WV3 ERGAS↓ | WV3 HQNR↑ | WV2 ERGAS↓ | **WV2 HQNR↑** |
|---|---:|---:|---:|---:|
| `wv3_baseline` | **2.1633** | 0.9486 | **4.3162** | 0.9125 |
| `wv3_baseline_valsel` | 2.1643 | 0.9475 | 4.3251 | 0.9155 |
| `wv3_fixed` | 2.1765 | 0.9496 | 4.3364 | 0.9305 |
| `wv3_fixed_valsel` | 2.1804 | **0.9508** | 4.3362 | **0.9345** |
| **논문** | **2.040** | **0.958** | **4.169** | **0.942** |

**WV2 zero-shot HQNR 이 0.9155 → 0.9345 (+2.08%)** 로, RR 차이(0.7%)보다 3배 크다.
WV3 HQNR 도 0.9475 → 0.9508 로 일관되게 오른다.

**해석.** A-1/A-2 는 CM3A 의 key 경로를 논문 수식대로 되돌리는 수정이다. 죽어 있던
`k_pan` 611,584개(전체의 6.13%)가 살아나고 `dep_conv` 가 진짜 이웃 gather 가 된다.
그 결과 **cross-modality alignment 가 실제로 작동**하는데, 이것이
in-domain 픽셀 정확도(ERGAS)보다 **구조 충실도(HQNR)와 미지 센서 일반화(WV2)** 에서 드러난다.

> **HQNR·SCC 를 우선 지표로 삼는다면 `fixed` 계열이 낫다.** 다만 HQNR 은 시드 반복이 없어
> 아직 σ를 모른다. FR 은 8장뿐이라 RR 보다 검정력이 낮다.

### 3.3 재구성본 내부 튜닝

| 비교 | 지표 | 이전 | 이후 | 차이 | p | **2σ=0.11% 기준** |
|---|---|---:|---:|---:|---:|---|
| **GN → LN** | ERGAS↓ | 2.1494 | **2.1205** | **−1.34%** | 0.040 | **유의** (12σ) |
| | SAM↓ | 2.8950 | **2.8418** | **−1.84%** | 0.004 | **유의** |
| LN → LN+mlp1 | ERGAS↓ | 2.1205 | 2.1229 | +0.11% | 0.418 | **구분 불가** |
| | SAM↓ | 2.8418 | 2.8492 | +0.26% | 0.0006 | 경계 (2σ의 2.4배) |

**LayerNorm 이 단일 변경으로는 최대 이득이다.** 새 판정선으로 보면 12σ 로 압도적이다.

**`mlp_ratio` 갈래는 정리됐다.** params 적중이 두 갈래였는데(mlp 4.0 + 12블록 / mlp 1.0 + 13블록)
ERGAS 로는 구분되지 않는다. 더 단순한 **mlp 4.0 / 12블록**을 표준으로 둔다.

### 3.4 누적 — 무엇이 얼마나 기여했나

WV3 50K, ERGAS 기준.

```
배포 코드 재현                    2.1643
  └ 구조 재구성 (3-scale, AttnBlock 3,
     mode modulation, k=3, 9ch)    2.1494   −0.69%  (p=0.044)
      └ + LayerNorm                2.1205   −1.34%  (p=0.040)
                                   ─────
                        누적       −2.02%  (p=0.005)
논문 주장                          2.040   남은 격차 +3.94%
```

**구조 재구성(−0.69%)보다 LayerNorm 하나(−1.34%)가 더 크다.** 파라미터 수를 맞추는 데
집중하느라 놓쳤던 항목이 실제로는 더 컸다는 뜻이다.

## 4. full-resolution 은 반대로 갔다

| (index 12–19, 8장) | D_λ↓ | D_s↓ | HQNR↑ |
|---|---:|---:|---:|
| 논문 | 0.016 | 0.027 | **0.958** |
| `wv3_baseline_valsel` | 0.0249 | 0.0283 | 0.9475 |
| `wv3_fixed_valsel` | 0.0234 | **0.0265** | **0.9507** |
| `paper_wv3` (GN) | 0.0276 | 0.0352 | 0.9382 |
| `paper_ln` (LN) | 0.0309 | 0.0342 | 0.9359 |

**RR 이 좋아질수록 HQNR 이 떨어진다.** 재구성이 진행되며 0.9475 → 0.9382 → 0.9359 다.
논문은 양쪽 다 좋은데(2.040 / 0.958) 우리는 트레이드오프가 생긴다.

기전은 짚인다. D_s 는 PAN 고주파 주입량을, D_λ 는 스펙트럼 왜곡을 잰다. 재구성본이 ERGAS 를
얻은 것은 **PAN 구조를 더 공격적으로 주입**했기 때문이고, 그것이 full-res 에서 벌점이 된다.

**현재 HQNR 최고는 `wv3_fixed_valsel`(0.9508)** — 배포 구조에 A-1/A-2 만 적용한 것이다.
ERGAS 최고(`paper_ln` 2.1205)와 HQNR 최고가 **서로 다른 구성**이다.

> 이는 [불일치 문서](2026-08-25_paper-vs-code-divergences.md)의 미반영 2건과 연결될 수 있다.
> `[K_pan|V_pan]` 결합은 PAN 경로의 표현을 바꾸고, `crop` 은 학습 중 MS→GT 열화관계를
> 왜곡한다. 둘 다 PAN 주입 특성에 직접 관여한다.

## 6. 한계

  (0.003~0.015)가 시드 노이즈를 넘는지 확정할 수 없다.

## 7. 이 검토가 바꾸는 것

1. **A-1/A-2 를 "RR 손해" 로 기술하던 서술을 고쳐야 한다.** RR 에서는 구분 불가이고,
   **HQNR·WV2 zero-shot 에서는 이득**이다. 우선 지표가 HQNR·SCC 로 옮겨간 지금
   `fixed` 계열의 위상이 달라진다.
2. **ERGAS 최고와 HQNR 최고가 갈린다.** Teacher 선정은 둘 중 무엇을 우선할지 정해야 한다.
   현재 계획(s1 screening)은 HQNR 우선이므로, `paper_ln` 이 자동으로 Teacher 가 되지 않는다.
3. **재구성본의 판정선이 0.11% 로 좁다.** 앞으로의 구조 비교는 시드 1벌로도 0.2% 차이를
   가릴 수 있다 — 탐색 효율이 크게 오른다.
