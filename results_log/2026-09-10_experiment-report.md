# 2026-09-10 실험 보고서 — 정합 모듈 반응 학습(s1) · 정답 기준 지식 증류(s2) · 모델 폭·깊이 기준(s3)

**작성일:** 2026-09-10
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정.
**서버:** s1 · s2 · s3 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

작은 U-Net 의 복원 품질을 두 방향으로 끌어올리는 것이 목표 — (1) PAN 과 MS 사이 위치 어긋남의 보정(정합), (2) 먼저 학습한 모델(Teacher)의 출력을 보조 정답으로 쓰는 지식 증류(KD). 두 갈래를 서버별로 나눠 진행하고, s3 에서 모델 크기의 기준값 확보.

**s1 — 정합 모듈이 입력의 어긋남에 반응하도록 학습 가능한가**
- **문제:** 전날(09-09) 도입한 정합 모듈(PAN 을 MS 위치에 맞춰 옮기는 작은 CNN, 영상마다 이동량 하나를 예측)이 입력이 달라져도 거의 같은 이동량만 내는 상태. 학습 데이터의 PAN–MS 어긋남이 거의 일정해, 입력을 보고 이동량을 바꾸도록 배울 신호가 없다고 판단.
- **접근:** 학습 중 PAN 을 알려진 양만큼 무작위로 더 옮기고, 정합 모듈의 예측 이동량이 그만큼 달라져 추가 이동을 되돌리도록 직접 감독(보정량 일관성). 추가 이동의 크기는 데이터셋의 실제 어긋남 규모를 재서 결정.

**s2 — Teacher 출력을 정답 기준으로 걸러 전달하면 Student 가 정답에 더 잘 맞춰지는가**
- **문제:** Teacher 출력을 그대로 따르게 하면 Teacher 의 오류까지 학습.
- **접근:** 정답 영상(GT)과의 손실은 모든 위치에 유지하고, Teacher 가 크게 틀린 곳은 정답 손실을 키우고, Student 가 Teacher 보다 뒤지는 곳에서만 Teacher 출력을 따르게 함(정답 기준 적응형 KD). 같은 원리를 출력 영상의 경사(gradient) 통계에도 적용하고, Teacher 가 쓰던 정합 모듈을 Student 가 어떻게 쓸지(고정 · 이어 학습 · 새로 학습)도 비교. 요소를 하나씩 바꿔 효과 분리.
- **후속:** 정합 이동량의 불확실성을 KD 에 쓰는 방법과, Teacher 신호 중 정답 방향과 맞는 성분만 고르는 방법은 구현 후 위 결과 뒤로 보류.

**s3 — 모델 폭·깊이의 기준값**
- 09-09 정한 기준 모델(폭 96 · 깊이 [1,2,4] U-Net)에서 깊이를 줄이고 폭을 바꾼 기준 모델을 학습해, 이후 실험의 모델 크기를 정하는 기준값으로 사용. 같은 날 s1 · s2 새 실험의 모델 크기는 이 가운데 폭 112 · 깊이 [1,2,3].

## 2. 결과 요약

- **s1 — 정합 모듈은 추가 이동에 반응하게 됐으나 HQNR 은 하락.** 보정량 일관성을 준 모델은 일부러 넣은 이동을 거의 그대로 되돌림(반응 기울기 −0.98, 이상값 −1; 되돌린 뒤 잔여 오차 0.06 px). 그러나 원 해상도 테스트에서 PAN 을 1.0–1.9 px 씩 옮기게 되면서 학습 종료 시 HQNR 0.924–0.943 으로, 09-09 정합 모듈(0.948)보다 낮아짐. 하락은 HQNR 의 공간 왜곡 항(D_s)에서 발생.
- **s1 분석 — WV3 학습 데이터의 PAN–MS 어긋남은 측정 오차 바닥 수준(0.17 vs 0.16 px).** 정합 모듈이 배울 변동이 없었다는 판단의 근거. 원 해상도 테스트의 어긋남은 위성마다 거의 일정(WV3 1.79 px, 20장 모두 같은 방향).
- **s2 — Teacher 출력을 따르게 하는 KD 가 HQNR 을 낮춤.** −0.0061 로 판정 기준(0.0031)의 2배. 출력 통계 감독을 더해도 회복 없음. 정합 모듈을 고정 · 이어 학습 · 새로 학습해도 차이 없고, 정합 모듈 자체의 기여도 없음(정합 모듈 없는 모델 대비 +0.0006).
- **s3 — 깊이 [1,2,3] 은 [1,2,4] 와 차이 없음(파라미터 8% 감소), 폭 112 가 폭 96 보다 평균 +0.0025~+0.0050.**

- **정답 가중만(Teacher 추종 없음)은 HQNR 차이 없음**(−0.0010)이나 축소 해상도 지표는 악화(SCC 0.9802, ERGAS 2.458).
- **정합 모듈 처리 방식 간 차이 없음** — 고정 / 이어 학습 / 새로 학습이 서로 0.0015 이내.
- **가져온 정합 모듈의 기여 없음** — 정합 모듈 없음 대비 +0.0006. Teacher 의 HQNR 도 Student 기준과 같은 수준.
- 모두 seed 하나씩의 결과.

### ⑤ 정합 이동량 불확실성(공분산) KD — s2 — 계획 (실행 보류, 9개)

Teacher 정합 모듈의 이동량 예측을 Student 정합 모듈에 전달하되, 그 예측을 얼마나 믿을지(불확실성)로 가중. 가중 형태(평균 · 스칼라 · 대각 · 전체 공분산 · 분포 KL)와 신뢰도 출처(영상 구조 / 추가 이동에 대한 반응 일관성)를 바꾼 7개 + 구조 기반 1개 + 대조 1개, ④ 의 "정합 모듈 이어 학습" 설정 기반. 지금 가져다 쓰는 정합 모듈은 이동에 반응하지 않아 불확실성 신호가 무의미 — 반응하도록 학습한 정합 모듈(③)과 ④ 의 정합 모듈 학습 결과 이후 기동 예정.

### ⑥ 정답 방향 선택 KD — 출력값 · 통계 성분 · 정합 민감도 — s2 — 계획 (실행 보류, 22개)

④ 의 Teacher 추종 항 가운데 **정답 방향과 맞는 성분만** 유지 — (A) 밴드별 출력값, (B) 출력 경사 통계의 성분별, (C) 정합 이동량이 바뀌면 크게 흔들리는 Teacher 출력은 약화. 같은 양을 무작위 위치에 주는 대조와 표본 섞기 대조 포함. Teacher 예측 전체가 아닌 정답에 필요한 수정 방향만 전달했을 때의 KD 개선 여부 확인. ④ 이후 기동 예정.

## 5. 용어 정의

| 용어 | 뜻 |
|---|---|
| PAN · MS · HRMS | 고해상도 흑백 영상 · 저해상도 다중분광 영상 · 둘을 합쳐 만든 고해상도 다중분광 영상 |
| 정답 영상 (GT) | 학습과 축소 해상도 평가의 목표 영상. 원래 MS 를 정답으로 두고, 입력은 PAN · MS 를 4배 줄여 만듦 |
| 축소 해상도 평가 · 원 해상도 평가 | 줄인 입력으로 복원해 정답과 비교하는 평가 · 실제 해상도 입력으로 복원해 정답 없이 평가하는 평가(논문과 같은 테스트 영상 20장) |
| HQNR | 원 해상도 품질 지표 = (1 − D_λ)(1 − D_s). 1 에 가까울수록 좋음 |
| D_λ · D_s | HQNR 의 두 성분 — 분광 왜곡(입력 MS 의 밴드 간 관계와 어긋남) · 공간 왜곡(입력 PAN 과의 공간 구조 어긋남). 낮을수록 좋음 |
| SCC · ERGAS | 축소 해상도 평가 지표 — 정답과의 공간 상관(높을수록 좋음) · 상대 전역 오차(낮을수록 좋음, 참고용) |
| 판정 기준 0.0031 | 같은 설정을 seed 만 바꿔 학습했을 때 HQNR 이 흔들리는 폭(표준편차의 2배). 이보다 작은 차이는 우연 범위 |
| seed | 초기 가중치 · 데이터 순서를 정하는 난수 초기값 |
| 학습 중 최고 · 종료 시점 | 학습 중 약 1,000 반복마다 HQNR 을 재서 가장 높았던 시점의 모델 · 50,000 반복 학습의 마지막 모델 |
| px | PAN 해상도 기준 픽셀 |
| 폭 · 깊이 | U-Net 첫 단계의 채널 수 · 해상도 단계별 블록 수 |
| 기준 모델 | 정합 모듈 없는 U-Net. 입력은 PAN 1채널 + 4배 확대(bicubic)한 MS 8채널, HRMS 복원만 학습. 원 PAN-Crafter 의 PAN 재구성 보조 과제 · 모드 변조 · 추가 PAN 입력 제거 |
| 정합 모듈 | PAN 과 MS 를 보고 영상 전체 이동량 (dy, dx) 하나를 예측해 PAN 만 그만큼 옮긴 뒤 U-Net 에 넣는 작은 CNN(0.105 M). MS · 정답 · 출력의 좌표는 그대로 |
| 보정량 일관성 | PAN 을 ε 만큼 더 옮긴 입력에 대한 예측 이동량이 원래 예측보다 정확히 ε 만큼 달라지도록 하는 손실 |
| 원본 쪽 학습 신호 차단 | 보정량 일관성 손실에서 원본 PAN 에 대한 예측은 목표값으로만 쓰고 그쪽으로는 학습시키지 않는 방식(stop-gradient) |
| 반응 기울기 | 64×64 조각의 PAN 을 알려진 양만큼 옮겼을 때 예측 이동량이 따라 바뀌는 비율(축별). −1 이면 추가 이동을 정확히 되돌림, 0 이면 반응 없음 |
| 잔여 오차 | 추가 이동을 되돌린 뒤 남는 이동량 오차의 평균 |
| 원 해상도 이동량 | 원 해상도 테스트 20장에서 정합 모듈이 PAN 을 옮기는 양의 중앙값 |
| 측정 오차 바닥 | 어긋남이 없는 영상 쌍(같은 정답 영상의 밴드 두 묶음)에 같은 측정법을 적용한 값 — 이 이하는 측정 잡음 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용. 여기서는 Teacher 와 Student 의 크기가 같음 |
| 정답 기준 적응형 KD | 정답 손실은 모든 위치에 유지하고, Teacher 오차가 큰 곳은 정답 손실 가중을 키우고, Student 가 Teacher 보다 뒤지는 곳에서만 Teacher 출력을 따르게 하는 KD |
| 출력 통계 감독 | 출력 영상의 방향별 경사(gradient) 국소 분산(5×5 창)을 정답 영상의 값 — 또는 정답과 Teacher 를 적응형 KD 규칙으로 섞은 목표 — 에 맞추는 보조 손실 |
| 평가기 | 팬샤프닝 표준 평가 코드(DLPan-Toolbox, MATLAB)를 파이썬으로 옮긴 것 |
