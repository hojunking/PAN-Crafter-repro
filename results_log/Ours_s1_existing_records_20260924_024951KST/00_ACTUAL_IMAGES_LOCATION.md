# 실제 이미지 저장 위치

추가 승인 후 지정 WV3·QB 체크포인트의 실제 추론을 완료했습니다.

[실제 이미지·전체 밴드 배열·ZIP 안내](../Ours_s1_images_20260924_031541KST/00_SAVED_RESULTS.md)

각 센서 RR20 + FR20, 합계 80개의 실제 예측 배열·예측 PNG를 저장했습니다. 참조·오차·비교 패널을 포함한 PNG는 440개입니다. ZIP의 CRC 및 SHA256도 검증했습니다.

이 기존 폴더는 최초의 메타데이터 복사 기록으로 유지합니다. 원 README의 RAW_MISSING 상태는 당시 복사 작업에 관한 설명이며, 새 이미지 파일은 위의 별도 폴더에 있습니다.
