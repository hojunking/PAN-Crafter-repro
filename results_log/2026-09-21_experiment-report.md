# 2026-09-21 실험 보고서 — 구성 요소 제거 반복 실험(s1 WV3 · s2 QB) · GF2 긴 학습 + 서버별 Teacher(s3 · s4 · s5) · GF2 평가 · 정합 모듈 분석

**작성일:** 2026-09-21
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** 공개 팬샤프닝 벤치마크(PanCollection)의 세 위성 세트 — WV3(WorldView-3, MS 8밴드), QB(QuickBird, MS 4밴드), GF2(Gaofen-2, MS 4밴드). 모두 PAN 1밴드, PAN 해상도는 MS 의 4배. 학습 조각(64×64 PAN) 수 WV3 9,714 · QB 17,139 · GF2 19,809.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 이날 실험의 주 비교는 테스트 영상으로 모델 시점을 고르지 않은 값 — 구성 요소 제거 반복 실험은 검증 기준 시점(학습과 별도로 떼어 둔 검증 영상의 ERGAS 가 가장 낮은 시점), GF2 긴 학습은 학습 종료 시점. 판정 기준 0.0031 은 WV3 에서 잰 값이라 QB · GF2 에는 참고로만 적용하고, GF2 목표는 PAN-Crafter 논문의 GF2 값(HQNR 0.964 · ERGAS 0.552)을 같은 모델에서 함께 넘는 것.
**서버:** s1 · s2 · s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

현재 방법(작은 Student U-Net 에 저·고주파 PAN 입력(PAN 을 흐린 저주파 성분과 나머지 고주파 성분을 추가 입력) · 정합 모듈(PAN 을 MS 위치에 맞춰 옮기는 작은 CNN) · Teacher 기반 지식 증류(KD) · 정답 edge 감독(출력과 정답 영상의 경계 차이를 줄이는 보조 손실) · q 가중(정합 예측이 일관된 표본에 더 큰 가중)을 더한 구성)의 요소별 기여를 WV3 · QB 에서 반복 측정하고, 논문과 격차가 가장 큰 GF2 에서 학습 길이와 계수를 조정. GF2 의 평가 절차와 GF2 에서만 크게 나타나는 정합 모듈 효과는 학습 없는 분석으로 점검.

**s1 · s2 — 완성형 방법의 구성 요소가 각각 기여하는가 (s1 WV3 · s2 QB)**
- **문제:** 완성형 방법에 여러 요소가 한꺼번에 들어 있어 요소별 기여 분리 불가. 요소 하나의 효과가 seed 변동보다 작을 수 있어 seed 하나의 비교로는 판단 불가.
- **접근:** 기본형에서 요소를 하나씩 더한 7단계(마지막이 완성형)와 완성형에서 요소를 하나씩 뺀 9가지, 기본형 포함 Student 17개를 같은 초기 가중치 · 데이터 순서로 각각 처음부터 학습. 회차마다 Teacher · Student seed 를 모두 새로 뽑아 5회차 반복(센서당 Teacher 10 · Student 85 = 95개), 같은 회차 안의 차이로 비교. 중간 결과와 무관하게 5회차를 모두 채우는 사전 고정 설계. WV3 는 s1, QB 는 s2 가 각자 진행.

**s3 · s4 · s5 — GF2 에서 학습 길이를 2배로 늘리면 논문 수준에 가까워지는가**
- **문제:** GF2 는 원 해상도 HQNR 이 논문 값(0.964)에 못 미침. GF2 학습 조각 수가 WV3 의 약 2배라, 같은 5만 반복이면 학습 데이터를 도는 횟수가 WV3 의 절반(약 121회 vs 247회).
- **접근:** Teacher · Student 를 10만 반복으로 학습(약 242회, WV3 5만 반복 수준). 서버마다 자기 Teacher 를 새로 학습해 그 서버 Student 에만 사용(서버 간 Teacher 공유 없음). s3 는 Teacher · Student 학습 길이(5만 · 10만) 조합, s4 는 Teacher 오차 큰 곳의 정답 가중 축소, s5 는 정답 edge 감독 절반을 각각 Student seed 2개로 같은 서버 안에서 비교.

**분석 (학습 없음) — GF2 평가 절차와 GF2 정합 모듈 효과**
- **문제:** GF2 의 낮은 HQNR 에 평가 절차 차이가 섞여 있을 가능성, 그리고 정합 모듈이 GF2 에서만 HQNR 을 크게 올리는 이유.
- **접근:** GF2 평가 절차(데이터 · 지표 계산 · 모델 시점 선택 · 입력 생성)를 논문 · 저자 코드 · 표준 평가 코드와 항목별 대조. 정답이 있는 축소 해상도 테스트 20장에서 PAN · 확대 MS(MS 를 4배 확대한 영상) · 정답 사이 어긋남과 정합 모듈 보정량을 같은 측정법으로 재서 WV3 와 비교.

## 2. 결과 요약

- **s1 (WV3) — 구성 요소를 하나씩 뺀 9가지 모두 완성형과 HQNR 차이 없음.** 가장 큰 차이는 저·고주파 PAN 입력 제거(−0.0026, 5회차 중 4회 하락). 학습 중 최고 시점(HQNR 이 가장 높았던 시점)으로 비교하면 저·고주파 PAN 입력 제거(−0.0054)와 기본형(−0.0057)만 5회차 모두 하락해 판정 기준 초과. 그 밖의 요소(정합 모듈 · Teacher 관련 요소 · 정답 edge 감독 · q 가중)는 어느 시점 기준으로도 판정 기준 미만.
- **s2 (QB) — 회차 간 흔들림(같은 구성의 HQNR 표준편차 최대 0.0145)이 커서 요소별 효과 분리 불가, 모델 시점에 따라 순서 역전.** 검증 기준 시점에서는 기본형(0.9173)이 완성형(0.9046)보다 높고, 저·고주파 PAN 입력은 분광 왜곡(D_λ)을 낮추는 대신 공간 왜곡(D_s)을 높임. 학습 중 최고 시점(학습 초반, 중앙값 9,090 반복)에서는 완성형이 가장 높고(0.9364) 저·고주파 PAN 입력 제거가 −0.0221.
- **s3 · s4 · s5 (GF2) — 18개 모두 완료, 목표(HQNR > 0.964 & ERGAS < 0.552) 동시 달성 0개.** 10만 반복 Student 12개 중 8개가 ERGAS < 0.552, HQNR 최고 0.9560. Student 학습 2배는 ERGAS 만 두 seed 모두 개선(−1.3% · −1.8%), HQNR 은 차이 없음. Teacher 학습 2배 · 정답 가중 축소는 두 seed 방향 불일치, edge 감독 절반은 차이 없음. 같은 설정의 seed 간 HQNR 차이(0.0093)가 설정 효과보다 큼.
- **분석 — GF2 평가에 결과를 무효화할 오류 없음, 다만 논문과 모든 조건이 같다고는 판정 불가.** 정합 모듈이 GF2 에서 HQNR 을 +0.021(WV3 +0.006) 올리는 것은 GF2 에서만 정합 모듈이 보는 어긋남과 실제 어긋남의 방향이 일치(보정 방향과 실제 어긋남 방향의 코사인 GF2 +0.81, WV3 −0.40)하기 때문 — 센서 · 데이터 조건의 결과이지 방법의 일반 효능이 아님.

## 4. 실험 내용 및 결과

### ① 구성 요소 제거 반복 실험 — s1 (WV3) · s2 (QB) — 실행

모든 모델 처음부터 5만 반복(batch 48). Teacher 는 폭 112 · 깊이 [1,2,3] U-Net + 정합 모듈(PAN + 확대 MS 입력, 2.76 M), Student 는 폭 104 · 깊이 [1,2,2] U-Net(정합 모듈 포함 2.21 M, QB 2.20 M; 정합 모듈 없는 구성 2.10 M · 2.09 M). 1회차 = Teacher 2개(보정량 일관성 — PAN 을 일부러 더 옮겼을 때 예측 이동량이 그만큼 따라 바뀌도록 하는 손실 — 을 가중 1e-4 로 넣어 학습 / 같은 초기값에서 그 손실 없이 학습) + Student 17개. 같은 회차의 Student 17개는 초기 가중치 · 데이터 순서가 같고 구성만 다름. Teacher 를 쓰는 구성은 같은 회차의 보정량 일관성 Teacher 를 사용(제거 4 만 보정량 일관성 없는 Teacher 사용). 회차마다 Teacher · Student seed 를 모두 바꾸므로 회차 간 차이는 Teacher 와 Student 를 함께 다시 학습한 변동.

완성형 방법: 입력 = 정합한 PAN · 저주파 PAN · 고주파 PAN + 확대 MS. 정합 모듈은 Teacher 것을 복사해 이어 학습(학습률 3e-6, U-Net 1e-4). U-Net 은 정답 기준 적응형 KD(정답 L1 손실 — Teacher 오차 큰 곳 최대 2배 — 에, Student 가 Teacher 보다 뒤지는 곳에서만 Teacher 출력 추종을 더한 것, 추종 계수 0.1) + 정답 edge 감독(계수 0.002 × q 가중)으로, 정합 모듈은 q 가중 정답 손실로만 학습.

HQNR 은 회차 평균 — WV3 5회차(제거 4–8 은 4회차), QB 기본형 · 누적 1–6 · 제거 9 · Teacher 5회차, 나머지 4회차. Δ 는 같은 회차 완성형과의 차의 평균(QB 는 완성형이 있는 4회차), 괄호는 완성형보다 낮았던 회차 수 / 비교 회차 수. 마지막 열은 같은 계산을 학습 중 최고 시점 모델로 한 값.

- **WV3 — 뺀 요소 9가지 모두 판정 기준 미만(−0.0026 ~ +0.0019).** 방향이 일관된 것은 저·고주파 PAN 입력뿐 — 기본형에 더하면 +0.0026(5회차 모두 상승), 완성형에서 빼면 −0.0026(4/5). 학습 중 최고 시점 기준으로는 −0.0054(5/5)로 판정 기준 초과.
- **WV3 — 저·고주파 PAN 입력 외의 요소는 모두 두 시점 기준 판정 기준 미만.** Student 정합 모듈, Teacher 정합 모듈 초기화, 출력 추종, 적응형 KD, 정답 가중, 정답 edge 감독, q 가중, Teacher 보정량 일관성 모두 해당. Teacher 전체를 빼도 −0.0002(학습 중 최고 시점 −0.0017).

| HQNR | 원 해상도 품질 지표 = (1 − D_λ)(1 − D_s). 1 에 가까울수록 좋음 |
| D_λ · D_s | HQNR 의 두 성분 — 분광 왜곡(입력 MS 의 밴드 간 관계와 어긋남) · 공간 왜곡(입력 PAN 과의 공간 구조 어긋남). 낮을수록 좋음 |
| SCC · ERGAS | 축소 해상도 평가 지표 — 정답과의 공간 상관(높을수록 좋음) · 상대 전역 오차(낮을수록 좋음, 참고용) |
| JQM | 정답 없이 원 해상도 결과를 평가하는 보조 지표. 여기서는 센서 분광 응답 대신 영상별 회귀 가중을 쓴 변형 |
| 판정 기준 0.0031 | 같은 설정을 seed 만 바꿔 학습했을 때 HQNR 이 흔들리는 폭(표준편차의 2배). 이보다 작은 차이는 우연 범위. WV3 에서 잰 값 |
| seed | 초기 가중치 · 데이터 순서를 정하는 난수 초기값 |
| 학습 중 최고 · 종료 시점 | 학습 중 약 1,000 반복(10만 반복 학습은 약 2,000 반복)마다 저장한 50개 모델 가운데 HQNR 이 가장 높았던 모델 · 학습 마지막 모델 |
| 검증 세트 · 검증 기준 시점 | 학습 데이터와 별도로 떼어 둔 축소 해상도 영상(WV3 1,080 · QB 1,905 · GF2 2,201 조각) · 저장한 50개 모델 가운데 검증 세트 ERGAS 가 가장 낮은 모델. 테스트 영상을 보지 않고 고름 |
| 중간 시점 (10만 반복 학습) | 10만 반복으로 학습하는 도중의 5만 반복 시점 모델. 처음부터 5만 반복으로 학습한 모델과는 학습률 일정이 다름 |
| px | PAN 해상도 기준 픽셀 |
| 폭 · 깊이 | U-Net 첫 단계의 채널 수 · 해상도 단계별 블록 수. 파라미터 수 — 폭 112 · [1,2,3] + 정합 모듈 2.76 M, 폭 104 · [1,2,2] + 정합 모듈 2.21 M(WV3) · 2.20 M(QB · GF2) |
| 확대 MS · 확대 위상 어긋남 | MS 를 bicubic 으로 4배 확대한 영상 · 확대 과정에서 생기는 확대 MS 와 정답 사이의 위치 차이 |
| 정합 모듈 | PAN 과 확대 MS 를 보고 영상 전체 이동량 (dy, dx) 하나를 예측해 PAN 만 그만큼 옮긴 뒤 U-Net 에 넣는 작은 CNN(0.105 M). MS · 정답 · 출력의 좌표는 그대로 |
| 보정량 일관성 | PAN 을 ε 만큼 더 옮긴 입력에 대한 예측 이동량이 원래 예측보다 정확히 ε 만큼 달라지도록 하는 손실. 여기서는 Teacher 학습에 가중 1e-4 로 사용(학습 반복 두 번에 한 번, 반경 2 px 안의 무작위 이동) |
| 학습 조각 쌍의 잔여 어긋남 | 4배 줄여 만든 학습 입력(PAN · MS)과 정답 사이에 남아 있는 전역 위치 차이 |
| 저·고주파 PAN 입력 | PAN 을 가우시안(σ 1.98)으로 흐려 MS 해상도로 줄였다가 다시 4배 확대한 저주파 PAN 과, PAN − 저주파 PAN 인 고주파 PAN 을 추가 입력 채널로 넣는 것. 정합 모듈의 이동을 PAN 과 똑같이 적용 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용. 여기서는 Teacher(폭 112 · 깊이 [1,2,3], PAN + 확대 MS 입력)가 Student(폭 104 · 깊이 [1,2,2])보다 약간 큼 |
| Teacher 오차 큰 곳 정답 가중 (α) | 정답 손실에 1 + α·d 를 곱하는 가중. d 는 Teacher 오차를 0–1 로 정규화한 값(d = e_T / (e_T + τ), τ 는 학습 데이터에서 잰 Teacher 오차 중앙값). 기준 α = 1(최대 2배) |
| Teacher 출력 추종 (β) | Student 출력을 Teacher 출력에 맞추는 보조 손실의 계수. 기준 β = 0.1 |
| 정답 기준 적응형 KD | 정답 손실은 모든 위치에 유지하고, Teacher 오차가 큰 곳은 정답 손실 가중을 키우고, Student 가 Teacher 보다 뒤지는 곳에서만 Teacher 출력을 따르게 하는 KD |
| 정답 edge 감독 | 출력과 정답 영상의 경계 응답(Scharr 필터) 차이를 줄이는 보조 손실. 기준 계수 0.002 |
| q (정합 일관성 점수) | 고정한 Teacher 정합 모듈에 PAN 을 알려진 양만큼 옮긴 입력을 여러 개 넣었을 때, 예측 이동량이 그 이동을 정확히 되돌리지 못하는 정도(표본별 잔여 오차의 평균). 낮을수록 정합 예측이 일관됨 |
| q 가중 | 표본별 가중 q_ref / (q_ref + q) — q_ref 는 학습 데이터 q 의 중앙값. q 가 낮은 표본일수록 edge 감독과 정합 모듈 학습의 가중이 커짐(q = q_ref 이면 0.5) |
| 기본형 · 완성형 방법 | 기본형 = PAN + 확대 MS 입력, 정합 모듈 · Teacher 없이 정답 L1 손실만 쓰는 Student · 완성형 = 저·고주파 PAN 입력 + Teacher 정합 모듈을 복사해 이어 학습하는 정합 모듈 + 정답 기준 적응형 KD + 정답 edge 감독 + q 가중 |
| 회차 | ① 의 반복 단위. 1회차 = Teacher 2개 + Student 17개, 회차마다 Teacher · Student seed 를 모두 새로 뽑음 |
| GF2 목표 | 같은 모델에서 HQNR > 0.964 그리고 ERGAS < 0.552(PAN-Crafter 논문 보충자료의 GF2 값) |
| 평가기 | 팬샤프닝 표준 평가 코드(DLPan-Toolbox, MATLAB)를 파이썬으로 옮긴 것 |
