# 2026-09-24 실험 보고서 — 논문 최종 모델 예측 영상 추출(s1 WV3 · QB, s4 GF2)

**작성일:** 2026-09-24
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 · QB · GF2 — 공개 팬샤프닝 벤치마크(PanCollection)의 WorldView-3 · QuickBird · Gaofen-2 위성 세트. MS 8밴드(WV3) · 4밴드(QB · GF2) + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 이날 다룬 모델은 WV3 · QB 가 목표 선택 시점(원 해상도 HQNR 하한을 넘는 저장 시점 가운데 축소 해상도 ERGAS 최소), GF2 가 학습 종료 시점.
**서버:** s1 · s4 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

새 학습 없이, 논문 결과표에서 제안 방법 행("우리 방법", Ours)으로 보고하는 데이터셋별 최종 모델의 예측 영상을 확보하는 날. 논문의 정성 비교 그림 · 오차 지도에 쓸 전 밴드 원시 예측을 결과표 수치와 같은 모델에서 추출.

**s1 — WV3 · QB 최종 모델의 예측 영상**
- **문제:** 결과표 수치와 연결된 목표 선택 시점 모델만 있고 예측 영상은 없음. 그림용 영상이 결과표 수치와 같은 모델에서 나왔다는 확인도 필요.
- **접근:** 지정 시점 모델로 추론만 다시 수행(학습 · 시점 재선택 없음)해 축소 · 원 해상도 테스트 각 20장의 예측을 전 밴드 그대로 저장. 저장한 배열로 지표를 다시 계산해 결과표 수치와 대조. 이어 오차 지도용으로 축소 해상도 예측과 정답 영상을 한 묶음으로 정리.

**s4 — GF2 최종 모델의 예측 영상**
- **접근:** s4 에서 진행 중인 실험을 안전 지점에서 일시 정지 → GF2 최종 모델로 같은 추출 → 같은 실험을 멈춘 상태 그대로 재개하는 절차.

## 5. 용어 정의

| 용어 | 뜻 |
|---|---|
| PAN · MS · HRMS | 고해상도 흑백 영상 · 저해상도 다중분광 영상 · 둘을 합쳐 만든 고해상도 다중분광 영상 |
| 정답 영상 (GT) | 학습과 축소 해상도 평가의 목표 영상. 원래 MS 를 정답으로 두고, 입력은 PAN · MS 를 4배 줄여 만듦 |
| 축소 해상도 평가 · 원 해상도 평가 | 줄인 입력으로 복원해 정답과 비교하는 평가 · 실제 해상도 입력으로 복원해 정답 없이 평가하는 평가(논문과 같은 테스트 영상 20장) |
| HQNR | 원 해상도 품질 지표 = (1 − D_λ)(1 − D_s). 1 에 가까울수록 좋음 |
| D_λ · D_s | HQNR 의 두 성분 — 분광 왜곡(입력 MS 의 밴드 간 관계와 어긋남) · 공간 왜곡(입력 PAN 과의 공간 구조 어긋남). 낮을수록 좋음 |
| SCC · ERGAS | 축소 해상도 평가 지표 — 정답과의 공간 상관(높을수록 좋음) · 상대 전역 오차(낮을수록 좋음, 참고용) |
| 판정 기준 0.0031 | 같은 설정을 seed 만 바꿔 학습했을 때 HQNR 이 흔들리는 폭(표준편차의 2배). 이보다 작은 차이는 우연 범위 |
| seed | 초기 가중치 · 데이터 순서를 정하는 난수 초기값 |
| 논문 최종 모델 (우리 방법, Ours) | 논문 결과표에서 제안 방법으로 보고하는 데이터셋별 최종 Student 모델. 정합 모듈 + 저·고주파 PAN 입력 U-Net(폭 104 · 깊이 [1,2,2], 약 2.2 M). 추론에는 이 Student 만 사용(Teacher · 정답 영상 불필요) |
| 목표 선택 시점 | 학습 중 1,010 반복 간격으로 저장한 후보 50개(마지막 50,000 반복 포함) 가운데 원 해상도 HQNR 이 하한을 넘는 것 중 축소 해상도 ERGAS 최소(동률이면 SCC → PSNR → 이른 시점). 하한은 PAN-Crafter 논문 보고값 기준 — WV3 0.9585 이상(보고값 0.958 보다 조금 엄격) · QB 0.92 초과 |
| 폭 · 깊이 | U-Net 첫 단계의 채널 수 · 해상도 단계별 블록 수 |
| 정합 모듈 | PAN 과 MS 를 보고 영상 전체 이동량 (dy, dx) 하나를 예측해 PAN 만 그만큼 옮긴 뒤 U-Net 에 넣는 작은 CNN. MS · 정답 · 출력의 좌표는 그대로 |
| 저·고주파 PAN 입력 | U-Net 입력 = 4배 확대한 MS + 정합된 PAN + 그 저주파 성분(흐린 PAN) + 고주파 성분(PAN − 흐린 PAN). 입력 채널 = MS 밴드 수 + 3 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용 |
| 09-18 새 Teacher (s1) | 09-18 에 s1 에서 정합 모듈과 U-Net(폭 112 · 깊이 [1,2,3])을 무작위 초기값에서 50,000 반복 학습한 Teacher(입력 PAN + MS, 보정량 일관성 가중치 1e-4, seed 71001). WV3 최종 모델의 Teacher |
| QB Teacher | QB 최종 모델의 Teacher. 09-18 새 Teacher 와 같은 구조를 QB 로 처음부터 학습(보정량 일관성 가중치 3e-4, seed 81002) |
| 보정량 일관성 | PAN 을 ε 만큼 더 옮긴 입력에 대한 예측 이동량이 원래 예측보다 정확히 ε 만큼 달라지도록 하는 손실 |
| q (정합 일관성 점수) | 고정한 Teacher 정합 모듈에 PAN 을 알려진 양만큼 옮긴 입력을 여러 개 넣었을 때, 예측 이동량이 그 이동을 정확히 되돌리지 못하는 정도(표본별 잔여 오차의 평균). 낮을수록 정합 예측이 일관됨 |
| 정답 기준 적응형 KD (정답 가중 α · Teacher 추종 β) | 정답 손실은 모든 위치에 유지하고, Teacher 오차가 큰 곳은 정답 손실 가중을 키우고(계수 α), Student 가 Teacher 보다 뒤지는 곳에서만 Teacher 출력을 따르게 하는(계수 β) KD. Student 정합 모듈은 q 가중 정답 손실로만 학습 |
| q 가중 정답 edge 감독 (λE) | 출력과 정답 영상의 경계(가로 · 세로 밝기 변화) 차이를 줄이는 손실. 표본의 q 가 낮을수록(Teacher 정합 반응이 일관될수록) 크게 반영. U-Net 에만 전달 |
| PAN 혼합 증강 (PANMIX) | 학습 때만 PAN 의 고주파 세기를 배율 γ 로 바꾼 PAN 을 원 PAN 과 섞어 쓰는 증강. GF2 최종 모델은 γ 0.5 · 1 · 1.5 를 확률 0.25 · 0.5 · 0.25. 추론에는 원 PAN |
| 원 화소값 (DN) | 위성 영상의 원래 밝기 단위. 여기서는 0–2047 |
| 전 밴드 예측 배열 | RGB 변환 · 밝기 조정 전의 모든 밴드 예측값(장면마다 밴드 × 세로 × 가로) |
