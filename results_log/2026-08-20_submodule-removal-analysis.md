# 서브모듈 제거 분석 — 무엇을 자를 수 있는가 (2026-08-20)

[스윕](2026-08-20_student-architecture-sweep.md)에서 "H/2 CM3A 제거가 무손실" 을 확인한 데 이어,
**어떤 서브모듈이 제거에 용이한지**를 파라미터·연산·시간 세 관점에서 전수 조사했다.
학습은 아직 하지 않았다 — 이 문서는 **정적 비용 지도와 실험 설계**다.

## 결론 먼저

1. **비용 절감 관점에서는 H/2 CM3A 가 사실상 전부다.** 추론 시간의 **41.8%** 를 차지하고
   제거해도 품질 손실이 없다(p=0.20). 이미 최대 이득을 챙겼다.
2. **그 다음으로 큰 덩어리(27.1%)는 서브모듈이 아니라 구조**다 — ResBlock 잔여 + conv + interpolate.
   서브모듈을 하나씩 빼는 방식으로는 더 못 줄인다.
3. **bottleneck CM3A(cond4)는 추론의 0.9%** 다. 비용 목적으로 건드릴 이유가 전혀 없다.
4. **interpolate 중복 제거는 4.2% 공짜다** — 출력이 **비트 단위로 동일**하다. 즉시 적용 가능.

따라서 앞으로의 서브모듈 실험은 **비용 절감이 아니라 "논문 메커니즘 중 무엇이 실제로 기여하는가"**
라는 진단 목적으로 설계해야 한다.

## 1. 추론 시간 구성 (256×256, 배포본 전체 구성 17.45 ms)

구성별 모델을 따로 만들어 **차분**으로 분해했다(훅 오버헤드 배제).

| 구성요소 | ms | 비중 | 제거 시 품질 |
|---|---:|---:|---|
| **CM3A H/2** (cond2_e + cond2_d) | **7.29** | **41.8%** | **무손실 (p=0.20, 검증됨)** |
| ResBlock 절반 (D2222→D1111) | 2.95 | 16.9% | val/test 엇갈림 (미결) |
| CM3A H/4 (cond3_e + cond3_d) | 2.32 | 13.3% | −1.5% (A3→A1, p=0.001) |
| CM3A bottleneck (cond4) | 0.15 | 0.9% | 미검증 |
| 나머지 (ResBlock 잔여 + conv + interpolate) | 4.73 | 27.1% | 구조 변경 필요 |
| └ 그중 interpolate 중복 | 0.75 | 4.2% | **비트 동일 — 공짜** |

CM3A 합계 9.77 ms = **56.0%**. 파라미터로는 41.8% 인데 시간으로는 56% 다 —
`dep_conv` 가 key/value 를 k²=9 배로 펼치기 때문이다.

## 4. 제안하는 실험 세트

비용 절감이 아니라 **진단**이 목적이다. 모두 A3 기준, 25K, 각 약 1.4시간 → **총 약 11시간**.

### 그룹 A — CM3A 위치: 어느 해상도의 정합이 필요한가

| # | 구성 | 답하는 질문 |
|---|---|---|
| A1 | A3 − bottleneck | 최저해상도 전역 정합이 필요한가 (비용은 0.9%) |
| A2 | A3 − encoder H/4 | 정합이 **인코더**에서 필요한가 |
| A3 | A3 − decoder H/4 | 정합이 **디코더**에서 필요한가 |

논문 Table 4 는 CM3A 를 통째로만 ablate 했다. 위치별로 쪼개면
**"cross-modality alignment 는 어느 스케일에서 작동하는가"** 라는 더 정밀한 주장이 된다.

### 그룹 B — CM3A 내부: cross-modality 가 정말 필요한가

| # | 구성 | 답하는 질문 |
|---|---|---|
| B1 | A3 − `k_pan` | 배포본에서 죽은 6.1% 를 빼도 정말 동일한가 (**무손실 예상, 확인용**) |
| B2 | **A3 − PAN 브랜치 전체** (MS self-attention 만) | **CM3A 의 cross-modality 가 실제로 기여하는가** |
| B3 | A3 − `v_pan` 의 `pan − ↑4lpan` 채널 | 고주파 주입이 핵심이라는 주장이 맞는가 |

**B2 가 가장 중요하다.** A-1 버그로 PAN 브랜치의 key 경로가 깨진 채로도 논문 수준 성능이 났다.
PAN 브랜치를 통째로 빼도 유지된다면 논문의 핵심 주장이 흔들리고, 무너진다면 value 경로가
진짜 기여자라는 뜻이 된다. 어느 쪽이든 보고 가치가 있다.

### 그룹 C — MARs 조건화

| # | 구성 | 답하는 질문 |
|---|---|---|
| C1 | A3 − AttnBlock adaLN gate (상수로) | Eq (8) 의 mode별 α 가 필요한가 |
| C2 | A3 − ResBlock mode 변조 (β,γ) | Eq (6) 의 mode별 변조가 필요한가 |

논문 Table 14 가 이미 ablate 했으나 **CM3A 를 줄인 상태에서도 같은지**는 미확인이다.

### 즉시 적용 가능 (학습 불필요)

- **interpolate 중복 제거** — 출력 비트 동일, 추론 4.2% 절감. `forward` 에서 스케일별 피라미드를
  한 번만 만들어 재사용하면 된다. `cond3_e`/`cond3_d` 가 `pan/4` 를, `cond2_e`/`cond2_d` 가
  `ms×2`·`lpan×2`·`pan/2` 를 각각 두 번 계산하고 있다.

## 5. 구현 필요 사항

| 실험 | 필요한 코드 변경 |
|---|---|
| A1–A3 | 없음 — `cm3a_locations` 로 지정 가능 |
| B1 | `CMAAA` 에 `use_k_pan` 플래그. 배포본에서는 출력이 버려지므로 계산만 생략 |
| B2 | `CMAAA` 에 `pan_branch` 플래그. `k_pan`/`v_pan`/`proj_pan` 제거 + forward 단일 브랜치 |
| B3 | `v_pan` 입력 채널 구성을 옵션화 |
| C1 | `adaLN_modulation` 을 학습 가능한 상수 파라미터로 교체 |
| C2 | `ResBlock` 의 `use_scale_shift_norm` 을 mode 무관으로 |

B2 가 가장 손이 많이 가지만(약 30줄) 가치도 가장 크다.
