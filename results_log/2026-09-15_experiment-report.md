# 2026-09-15 실험 보고서 — 기준 Teacher 정합 모듈 재사용 KD 파생 실험(s2~s5) · q 선택 정답 edge 감독과 Teacher 추종 상호작용(s1~s5) · 다중 데이터셋 표본 기전 검증(s1)

**작성일:** 2026-09-15
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배. 다중 데이터셋 표본 기전 검증에는 같은 벤치마크의 QB(QuickBird 위성, MS 4밴드) · GF2(Gaofen-2 위성, MS 4밴드) 세트를 학습 · 평가에, WV2(WorldView-2 위성, MS 8밴드) 세트를 평가에만 사용.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 모든 값은 학습 중 HQNR 최고 시점 모델의 값. 기준 Teacher 정합 모듈 재사용 KD 계열(① ② ③ ⑥ ⑦)의 공통 목표는 WV3 HQNR 0.959 이상. QB · GF2 모델도 각 세트의 원 해상도 · 축소 해상도 테스트 20장으로 같은 방식 평가.
**서버:** s1 · s2 · s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

전날(09-14) 시작한 기준 Teacher 정합 모듈 재사용 KD — 기준 Teacher 의 정합 모듈을 Student 가 복사해 쓰고, U-Net 은 새로 학습하면서 Teacher 출력을 KD 에 활용하는 방식 — 의 첫 결과에서, 주력 KD 조합(Teacher 오차 가중 + Teacher 추종 + 정답 edge 감독, 이하 기준 KD 조합)이 서버 · seed 마다 KD 없는 Student 보다 높기도 낮기도 함. 목표 HQNR 0.959 에 가까운 경로를 찾기 위해 네 갈래로 진행 — (1) 기준 KD 조합의 구성 요소와 정합 모듈 학습 방식 분해, (2) 더 작은 Student U-Net 으로 교체, (3) 정합 일관성 점수(q)로 정답 edge 감독 대상을 고르는 새 방식, (4) q 와 복원 오차가 어긋나는 표본의 특성을 다른 위성 세트까지 넓힌 분석.

**s2 · s4 · s5 — 기준 KD 조합의 어느 요소가 작용하는가, 정합 모듈 학습 방식이 영향을 주는가 (①)**
- **문제:** 기준 KD 조합의 효과가 서버마다 반대 방향. Teacher 추종 · 정답 edge 중 어느 쪽 때문인지, Student 학습 중에도 정합 모듈에 보정량 연습을 계속 시키는 것이 필요한지 분리 불가.
- **접근:** 서버마다 seed 하나로 — (s2 · s4) 기준 KD 조합에서 Teacher 추종 · 정답 edge 를 하나씩 뺀 설정과 Teacher 없이 edge 만 준 설정, (s4 · s5) 보정량 연습 제거와 정합 모듈 고정 대조, (s5) 학습 후반(25,000 반복부터) 정합 모듈 동결.

**s3 — 같은 분해를 다른 seed 에서 완성하고, 후반 동결을 다른 KD 조합과 결합 (②)**
- **문제:** s3 에서는 Teacher 추종을 뺀 설정이, s5(①)에서는 후반 동결 + 기준 KD 조합이 가장 높음. 두 관측이 조건을 바꿔도 유지되는지 확인되지 않은 상태.
- **접근:** s3(seed 2026)에서 Teacher 추종 × 정답 edge 네 조건을 채우고, Teacher 없는 정답 L1 + edge, 후반 동결 세 가지(KD 없음 / 기준 KD 조합 / Teacher 추종 제거) 추가.

**s4 — 더 작은 Student U-Net 에서도 정합 모듈 재사용 · KD 가 유효한가 (③)**
- **문제:** 정합 모듈 없는 작은 U-Net(폭 104 · 깊이 [1,2,1], 1.90 M)이 s3 의 이전 정답 L1 학습에서 seed 3개 평균 HQNR 0.9558 로, 현재 Student(폭 112 · 깊이 [1,2,3], 2.66 M)와 같은 수준.
- **접근:** Teacher(폭 112)와 정합 모듈 출처는 그대로 두고 Student U-Net 만 폭 104 · 깊이 [1,2,1]로 교체. 정합 모듈 없음 / 이어 학습 / 고정 × KD 없음 / 기준 KD 조합 / Teacher 추종 제거 5개 비교.

**s1 — 정합 예측은 일관한데 복원이 어려운 표본은 어떤 표본인가 (④ ⑤)**
- **문제:** 전날 분석(정합 일관성 점수(q) 검증)에서 q 와 복원 오차(e)가 약한 음의 상관 — 정합 예측이 일관한(q 낮은) 표본에서 오히려 복원 오차가 큰 경우 관측. WV3 에만 해당하는지, 영상의 어떤 특성과 연결되는지 확인되지 않은 상태.
- **접근:** QB · GF2 에 WV3 와 같은 절차의 모델 세트를 새로 학습(센서당 5개), WV2 는 WV3 모델로 평가만. 네 세트에서 q–e 관계, 영상 대비로 나눈 뒤의 관계, 같은 잔여 이동에 대한 출력 민감도, 학습된 보정의 이득을 측정.

**s5 · s1 · s2 — q 로 정답 edge 감독 대상을 고르면 나아지는가 (⑥)**
- **문제:** q 를 Teacher 신뢰도로 쓰는 방식은 전날 분석에서 채택 안 함. 한편 정답 edge 감독의 효과가 서버마다 엇갈려(① ②) 모든 표본에 같은 강도로 주는 것이 적절한지 불명.
- **접근:** 작은 Student(③)에서 기준 KD 조합의 edge 감독을 q 가 기준값 미만인 표본(약 절반)에만 적용. 서버 안에서 KD 없는 Student · 기준 KD 조합과 비교, 고유 seed 3개(s5 2026 · 777, s1 1234). s1 에는 같은 평균 강도로 줄인 상수 대조와 q 표지를 섞은 셔플 대조 추가.

**s3 · s4 — q 선택 edge 가 Teacher 추종과 결합될 때만 작용하는가, edge 감독을 어느 모듈로 보내야 하는가 (⑦)**
- **문제:** ⑥ 만으로는 q 선택의 효과가 Teacher 추종과의 결합 때문인지, U-Net 과 정합 모듈 중 어느 쪽에 대한 감독 제한 때문인지 분리 불가.
- **접근:** s3 는 q 선택 edge × Teacher 추종 유무 2×2, 상수 강도 · 셔플 대조, Teacher 추종 절반. s4 는 U-Net 에는 모든 표본의 edge 를 주고 정합 모듈로 가는 edge 학습 신호만 q 로 제한하는 경로 분리, 정합 모듈 edge 차단 대조, 후반 동결과의 결합. 서버마다 seed 2개(s3 2026 · 4321, s4 1234 · 3407)를 사전 고정.

- **s2 · s4 · s5 (①) — 기준 KD 조합의 효과는 서버 · seed 마다 다름.** s2 는 Teacher 추종과 정답 edge 를 함께 쓸 때만 높고(하나씩 뺀 설정 대비 +0.0037 · +0.0045), 하나만 쓴 설정은 Teacher 오차 가중만과 차이 없음. s4 는 새 설정 6개(0.9524–0.9562)가 모두 KD 없는 Student(같은 설정 2회 0.9594 · 0.9568)보다 낮음. 보정량 연습 제거 위에 기준 KD 조합을 더해도 차이 없음(s4 +0.0003 · s5 −0.0001). s5 의 후반 동결 + 기준 KD 조합이 0.9587 로 ① 의 최고지만 기준 KD 조합 대비 +0.0011(차이 없음).
- **s3 (②) — 새 5개 모두 대조 대비 차이 없음(−0.0004 ~ +0.0023).** Teacher 추종 × 정답 edge 상호작용은 s3 −0.0047, s2 +0.0042 로 방향 반대(각 seed 하나).
- **s4 (③) — 작은 Student(정합 모듈 포함 파라미터 27% 감소)가 원래 크기와 같은 수준(0.9565–0.9585).** 작은 Student 안에서는 KD 조합 · 정합 모듈 처리 방식 간 차이 없음(KD 없는 Student 대비 −0.0020 ~ −0.0005).
- **s1 (④ ⑤) — q 와 복원 오차의 음의 상관이 네 위성 세트 모두에서 반복(ρ −0.17 ~ −0.44).** 정합 일관 · 복원 어려움 집단은 네 세트 모두 영상 대비 · 텍스처가 가장 큰 집단. 오차를 대비로 나누면 WV3 · QB 는 상관 부호가 양으로 바뀌고 GF2 · WV2 는 음 유지 — 대비만으로는 설명 불가. 준비 학습에서는 QB 의 정합 모듈 모델 4개가 모두 정합 모듈 없는 기준보다 HQNR 0.074–0.094 낮고(공간 왜곡 증가), GF2 는 반대로 0.015–0.036 높음.
- **s5 · s1 · s2 (⑥) — q 선택 정답 edge 감독은 기준 KD 조합과 차이 없음.** 고유 seed 3개에서 −0.0003 · +0.0010 · +0.0007(평균 +0.0005). 같은 평균 강도의 상수 감소 · q 셔플 대조와도 차이 없음.
- **s3 · s4 (⑦) — q 선택 edge 와 정합 모듈 전달 경로 제한 모두 일관된 효과 없음.** q 선택 edge 의 기준 KD 조합 대비 차이는 seed 4개 중 3개에서 기준 미만, s4 에서는 seed 1234 −0.0022 · seed 3407 +0.0032 로 방향 반대. 최고값은 s4 후반 동결 + Teacher 추종 제거 0.9589 로 KD 없는 Student(0.9585)와 같은 수준.
