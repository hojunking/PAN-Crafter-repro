# MS-only ablation — 소형 모델에서 MARs 는 이득이 아니라 비용이다 (2026-09-01, 170hx)

계획: [`s2_ms_only_ablation_and_uncertainty_audit.md`](../research_log/s2_ms_only_ablation_and_uncertainty_audit.md).
**6벌**(단일-task 2구조 × 2시드 + dual 대조군 2벌) + 적대적 감사 4 에이전트.

**세팅 대응표.** 골격 `R4` = 재구성본 w96 · depth[1,2,4] · attention 없음 · 11ch ·
nocrop · LN · 50K · seed 2025(별도 표기 시 1234) · 선택 `select_on: hqnr`.
`MS1`=PAN mode·loss·배치복제 제거, **모드 변조(γβ) 유지** · `MS2`=거기서 **모드 변조까지 제거**
(순수 single-task residual U-Net) · `M0`/`R4_dual_ctrl`=dual MARs 대조군(각각 MutualTrainer
variant m0 / 표준 Trainer). **"MS-only" 는 입력에서 PAN 을 빼는 게 아니다** — 입력 11ch 는
그대로이고 *학습 task* 에서 PAN 재구성만 뺀다.

| 교란 가설 | 기각 근거 |

## 3. 범위 — 이 결과가 말하지 않는 것

1. **일반 명제가 아니다. 구조 의존이다.** 같은 ablation 의 **깨끗한 단일축 쌍**
   (`c0_hqnr` vs `m1_single` — w128·7.17M·attn3, `mars` 한 줄만 다름)은 같은 ep225 에서
   **−0.64%**(18/20, p=7e−4)다. **−2.68% 는 R4(소형·attention 없음) 조건의 값**이고,
   두 점을 잇는 읽기는 "**모델이 작을수록 보조 task 의 부담이 커진다**"이다.
   Student(2M 급) 설계에는 이 쪽이 직접 걸린다.
2. **배포본 MARs 의 반박이 아니다.** 재구성본의 모드 분리는 블록당 γβ 512 파라미터인데
   배포본은 mode token 을 Linear(128,2C)=33,024 로 사영한다. 두 task 를 얹기가 여기서 더
   어려울 수 있다 — 논문 구조에서의 MARs 가치는 이 실험이 판정하지 않는다.
3. **동일 가중 보조 task 에 한정된다.** `w_off=1.0`(배포/논문 기본값)은 조정하지 않았다.
   수렴 시 PAN 항은 MS 항의 1/126 이라 손실 크기 지배는 아니지만, 가중을 낮춘 dual 은
   측정하지 않았다.
4. **프로토콜을 밝혀야 한다.** matched-epoch(ep225) 기준이다. 사전 등록된 `best_hqnr`
   산출물로는 −1.58% 이고 MS1(s2025)만 보면 동률이다 — 단 그 대조는 epoch 불일치
   (M0 ep245 vs MS1 ep105, MS1 은 그 시점에 아직 하강 중)라 **MS 에 불리한 쪽으로 치우친다.**
   ERGAS 주장에는 matched-epoch 이 깨끗하다.
5. **p 값은 장면 수준이다.** dual arm 은 이제 n=2(군집 폭 0.00%), MS arm 은 n=4(폭 0.33%)로
   run 수준 근거가 생겼지만, 1e−8 급 p 를 headline 으로 쓰지 않는다.

## 4. 부수 확인 — 시드 반복이 필수였다

MS1 의 raw ERGAS 는 2.1016 → 2.0542 로 **2.17% 흔들렸다.** 2단 선택(HQNR-동급 내 ERGAS
최소)으로 보면 2.0364 → 2.0357 로 **0.04%** 다. 시드가 아니라 **선택 복권**이었고,
1벌만 봤으면 "MS1 불안정" 이라는 틀린 결론이 났다. HQNR 선택 하에서
[선택 복권 기전](2026-08-29_s2-campaign-env-verification.md)이 또 확인된 사례다.

## 5. 다음

- **Student 기본형을 MS2(plain single-task)로 바꾼다.** 같은 성능에 파라미터가 더 적고
  (−3.8K) 학습이 1.6배 빠르다. 변조 유지(MS1)의 근거가 없다.
- **KD 캠페인의 T·S 양쪽에 적용 검토.** Teacher 도 단일-task 로 두면 KD 전체 비용이
  절반 이하로 떨어진다. 다만 Teacher 는 w128 급이라 이득이 −0.64% 로 작다 —
  **Student 쪽 이득이 본체**다.
- 미측정: `w_off` 를 낮춘 dual, 더 긴 스케줄에서의 dual 수렴, 9ch 판 MS-only.
