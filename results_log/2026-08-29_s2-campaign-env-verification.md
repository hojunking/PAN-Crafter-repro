## 2. ERGAS 기준(2σ=0.11%)이 왜 무의미해졌나 — 기전 실측

0.11% 는 **val-ERGAS 선택**(수렴 꼬리의 평탄 구간에서 뽑음) 하에서 보정된 값이다.
HQNR 선택은 다르다 — s2 실측:

| | HQNR-동급 epoch 수 / 전체 평가 | 그 구간의 ERGAS 폭 |
|---|---:|---:|
| c8_c4w96 | **43 / 49** (epoch 35~245) | 2.0592 ~ 2.4230 = **17.7%** |
| c5_c2d124 | 43 / 49 | 2.0437 ~ 2.2986 = **12.5%** |

HQNR 곡선이 학습 초반부터 판정선 이내로 평탄하므로, 어느 epoch 이 최대가 되는가는
**run 잡음이 정한다**(선택 epoch 실측: 65~245 산개). 그런데 ERGAS 는 그 구간에서
12~18% 움직이므로, **선택된 체크포인트의 ERGAS 는 복권**이다.
서버 간 c8 의 −5.13% 는 환경 차이가 아니라 s1/s2 가 다른 epoch 을 뽑은 결과다
(HQNR 은 +0.14% 로 일치).

**따라서 s1 보고서(2026-08-28)의 ERGAS 기반 서열은 선택 잡음 위에 서 있다.**
"c8 부터 실손실"(s1 2.2004)은 s2(2.0876)에서 재현되지 않고, c6 다크호스의 ERGAS 우위도
이 잡음 안에서 다시 읽어야 한다. HQNR 동급 집합이라는 결론(§2.1)은 그대로 유효하다 —
오히려 s2 재현으로 더 단단해졌다.

## 3. 제안 — 2단 선택: HQNR-동급 집합 안에서 ERGAS 최소를 뽑는다

선택 규칙을 "HQNR argmax" 에서 **"HQNR ≥ best×(1−판정선) 인 epoch 중 ERGAS 최소"** 로
바꾸면, 판정선 이내의 HQNR 을 유지하면서 ERGAS 복권이 사라진다. s2 곡선으로 시뮬(py 지표):

| case | HQNR 선택 (ep / ERGAS) | **2단 선택 (ep / ERGAS)** | ERGAS | HQNR 양보 |
|---|---|---|---:|---:|
| c0 | 100 / 2.0743 | 235 / **2.0239** | −2.4% | −0.64% |
| c1 | 130 / 2.0501 | 235 / 2.0249 | −1.2% | −0.42% |
| c4 | 100 / 2.0914 | 240 / 2.0331 | −2.8% | −0.42% |
| c3b | 110 / 2.0749 | 240 / 2.0273 | −2.3% | −0.25% |
| c3e | 110 / 2.0748 | 240 / 2.0299 | −2.2% | −0.49% |
| c2 | 105 / 2.0727 | 215 / 2.0281 | −2.2% | −0.43% |
| **m1** | 65 / 2.1164 | 220 / **2.0106** | **−5.0%** | −1.14% |
| c5 | 85 / 2.1452 | 220 / 2.0437 | −4.7% | −0.63% |
| c6 | 200 / 2.0598 | 245 / 2.0554 | −0.2% | −0.07% |
| c7 | 160 / 2.0751 | 245 / 2.0566 | −0.9% | −0.19% |
| c8 | 175 / 2.0720 | 245 / 2.0592 | −0.6% | −0.13% |

세 가지가 눈에 띈다.

1. **전 case 의 2단 ERGAS 가 2.01~2.06 의 좁은 밴드로 수렴한다** — 선택 잡음이 사라지면
   case 간·서버 간 비교가 다시 성립한다. 2단 epoch 은 일관되게 후반(215~245)이다.
2. **m1(MARs 제거)이 2.0106 으로 논문 2.040 아래다**(py 지표 기준). "MARs 제거 = ERGAS
   +1.4% 손실" 이라는 s1 판정도 선택 잡음이었다 — 2단으로 보면 m1 이 c0(2.0239)보다 낫다.
   학습 2배 가속과 합치면 m1 의 가치가 더 커진다.
3. c6~c8(소형)은 개선 폭이 작다 — HQNR 최대가 이미 후반에 있었기 때문. 즉 소형 모델은
   원래 안정적이었고, 대형일수록 복권이 심했다.

**구현.** 학습 코드 수정 없이 가능하다 — 곡선(공식 HQNR + ERGAS)은 로그/CSV 에 있고,
다만 이번 캠페인의 epoch 체크포인트는 25 간격이라 2단 epoch(235 등)이 정확히 저장돼
있지 않다. 후반 평탄 구간이라 인접 저장분(225)으로 근사하거나, **다음 캠페인부터
선택 로직에 2단 규칙을 넣는 것**을 권한다. 최종 확정은 matlab 재평가로 한다.
