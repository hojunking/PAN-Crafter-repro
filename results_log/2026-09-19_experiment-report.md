# 2026-09-19 실험 보고서 — 저·고주파 PAN 입력 후속 20시간(s1–s5) · 정합 모듈·U-Net 시점 교차 평가(s1)

**작성일:** 2026-09-19
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 이번 실험은 모델마다 학습 중 50개 시점을 저장해 모두 평가하고, HQNR 0.9585 이상인 시점 중 ERGAS 가 가장 낮은 시점(목표 선택)을 함께 기록 — 그 ERGAS 가 2.040 미만이면 공동 목표 달성(PAN-Crafter 논문의 WV3 값 HQNR 0.958 · ERGAS 2.040 기준).
**서버:** s1 · s2 · s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

전날(09-18) 저·고주파 PAN 입력 + 새 Teacher 12시간 실험의 후속. 그 실험은 PAN 을 저주파 성분(흐리게 한 PAN)과 고주파 성분(PAN − 저주파 성분)으로 나눠 U-Net 입력 채널로 추가하고, Teacher 를 서버마다 정합 모듈까지 처음부터 새로 학습한 것. 관측 — 추가 입력을 준 Student 가 같은 Teacher 아래 기본 입력 Student 보다 종료 시점 HQNR 이 높고 ERGAS 가 낮음(6개 대조 모두), 깊이 [1,2,2] 가 종료 시점 ERGAS 를 낮춤(2.044–2.045), 모든 Student 에서 HQNR 최고 시점 이후 ERGAS 는 내려가고 공간 왜곡(D_s)은 올라감, 공동 목표 달성 모델 없음(저장 시점 전체의 ERGAS 최저 2.044).

이번에는 범위를 넓히지 않고, 유망한 조합(저주파 추가 · 저·고주파 추가 입력 × 깊이 [1,2,2])을 같은 서버 · 같은 Teacher 에서 Student seed 만 바꿔 반복하는 것이 중심. 함께 두 원인 가설을 분리 — (1) 학습 후반의 D_s 증가가 정합 모듈 쪽 변화 때문인가, (2) 새 Teacher 정합 모듈이 PAN 이동에 거의 반응하지 않는 것(5개 Teacher 의 q 0.453–0.457, 전혀 반응하지 않으면 0.469)이 문제인가. Teacher 는 서버별 09-18 Teacher 를 그대로 재사용하고, Student 학습 방식(q 가중 복원 KD)과 계수는 바꾸지 않음. 서버마다 유효 작업 20시간 이상 — 기본 묶음을 먼저 마치고, 20시간에 못 미치면 시간 예비 묶음을 순서대로.

**s1 — 학습 후반의 공간 왜곡 증가는 정합 모듈 때문인가 (기본 입력 Teacher)**
- **문제:** Student 의 정합 모듈과 U-Net 이 함께 학습돼, 후반의 HQNR 하락이 어느 쪽 변화에서 오는지 불명.
- **접근:** 09-18 모델 2개에서 서로 다른 학습 시점의 정합 모듈과 U-Net 을 바꿔 끼워 평가(분석). 사전 기준을 넘으면 10,000 반복 이후 정합 모듈 학습률만 1/3 로 줄인 학습을, 넘지 못하면 저·고주파 추가 입력의 깊이 [1,2,1] 대 [1,2,2] 반복 비교를 진행. 첫 학습 전에 한 번만 결정.
- **경로:** 사전 기준 미충족 → 깊이 비교로 진행.

**s2 — Teacher 정합 모듈을 반응 학습된 가중치에서 시작하면 나아지는가 (저주파 추가 Teacher)**
- **문제:** 09-18 새 Teacher 5개 모두 정합 모듈이 이동에 거의 반응하지 않음.
- **접근:** 같은 저주파 추가 Teacher 를 정합 모듈만 09-10 반응 학습 정합 모듈에서 시작해 다시 학습하고, 기존 Teacher 와 새 Teacher 아래 같은 Student 를 5개 seed 로 비교.
- **변경:** 이 대조는 계획에 미리 정한 대체 비교 — 같은 Teacher 아래 저주파 추가 대 저·고주파 추가 입력(깊이 [1,2,2]) — 로 진행.

**s3 — 고주파 추가 입력에서 깊이 [1,2,2] 의 효과가 seed 를 바꿔도 유지되는가, 폭 112 가 남은 ERGAS 차이를 줄이는가 (고주파 추가 Teacher)**
- **접근:** 고주파 추가 Student 의 깊이 [1,2,1] 대 [1,2,2] 5개 seed 쌍 + 깊이 [1,2,2] 에서 폭 104 대 112 5개 seed 쌍.

**s4 · s5 — 저주파 추가 대 저·고주파 추가 입력과 깊이의 조합 (저·고주파 추가 Teacher, s5 는 Teacher seed 가 다른 두 번째 Teacher)**
- **문제:** 09-18 s4 에서 깊이 [1,2,1] 일 때 저주파 추가 입력의 종료 시점 ERGAS 가 저·고주파 추가보다 낮았음(2.0495 대 2.0527, HQNR 은 0.9546 으로 같음). 저주파 추가 · 깊이 [1,2,2] 는 미측정.
- **접근:** seed 마다 입력 2가지 × 깊이 2가지 네 조건을 모두 학습(서버당 4개 seed) + 폭 112 연결 비교 몇 개. 비교는 서버 안의 같은 seed 묶음 단위.

**조정(저녁):** 첫 12개 결과 중 HQNR 0.9585 이상 시점을 확보한 모델은 저·고주파 추가 · 깊이 [1,2,2] 하나(s1 · seed 73101, 학습 중 최고 0.9612, 목표 선택 HQNR 0.9587 · ERGAS 2.056). 09-18 결과와 합친 같은 seed 깊이 대응 9쌍에서 [1,2,2] 의 종료 시점 ERGAS 가 모두 낮았고(종료 시점 HQNR 은 2쌍 개선 · 7쌍 악화), s4 · s5 의 네 조건 묶음에서는 [1,2,2] 일 때 저·고주파 추가가 저주파 추가보다 HQNR · ERGAS 모두 나았음 → 이 조합을 중심 후보로 두고, 대표 성능을 학습 중 최고 대신 목표 선택으로 읽기로 함. s3 · s4 · s5 는 진행 중인 묶음을 마친 뒤 폭 112 비교를 앞당김. 학습 방식 · Teacher · 실행 정의 · seed 는 그대로, 새 모델 없음.

## 2. 결과 요약

- **s1 분석 — 학습 후반의 HQNR 하락은 U-Net 쪽 변화.** 같은 U-Net 에 다른 시점의 정합 모듈을 넣어도 HQNR 변화 0.0001 미만. 원 해상도에서 Student 정합 모듈이 PAN 을 옮기는 양은 0.1 px 미만. 사전 기준을 만족한 비교 0/4.

- **공동 목표 달성 0/64.** HQNR 0.9585 이상 시점이 있는 모델 12개(저·고주파 추가 8 · 고주파 추가 4 · 저주파 추가 0/18), 그 안의 ERGAS 최저 2.052. ERGAS 2.040 미만은 한 모델의 한 시점(2.0399)뿐이고 그때 HQNR 0.9530.

## 4. 실험 내용 및 결과

**공통 설정 (②–⑧)** — Teacher 는 서버별 09-18 새 Teacher(폭 112 · 깊이 [1,2,3], 정합 모듈 포함)의 종료 시점 모델을 고정해 재사용, 이번에 새로 학습한 Teacher 없음. Student U-Net 은 무작위 초기값에서 50,000 반복(배치 48) 학습하고, Student 정합 모듈은 자기 서버 Teacher 의 정합 모듈을 복사해 시작해 함께 학습. 학습 방식은 q 가중 복원 KD(U-Net 학습률 1e-4, 정합 모듈 3e-6). 저주파 PAN 은 09-18 과 같은 방식으로 만든 것을 그대로 사용. 같은 seed 로 조건만 바꾼 모델끼리는 공통 초기 가중치 · 데이터 순서가 같고, 추가 입력 채널의 첫 층 가중치는 0 에서 시작.

### ① 정합 모듈 · U-Net 학습 시점 교차 평가 — s1 — 실행 (분석, 학습 없음)

09-18 에 s1 의 기본 입력 Teacher 아래 학습한 Student 2개(기본 입력 · 저·고주파 추가, 폭 104 · 깊이 [1,2,1], seed 72001)에서 10,100 · 24,240 · 50,000 반복 시점의 정합 모듈과 U-Net 을 서로 바꿔 끼운 9개 조합을 원 해상도 · 축소 해상도 테스트 20장씩으로 평가. 같은 시점 조합 3개는 원래 평가값과 일치 확인. 가중치는 고정(평가만).
