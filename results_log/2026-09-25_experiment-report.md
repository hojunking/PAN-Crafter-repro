**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.

**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 감독 계수 실험은 학습 중 저장 시점 50개 가운데 원 해상도 HQNR 최고 시점을 주 결과로, 50,000 반복 종료 시점을 보조 결과로 보고.

| 학습 중 최고 · 종료 시점 (감독 계수 실험) | 후보 50개(1,010 반복 간격 49개 + 50,000 반복) 가운데 원 해상도 HQNR 이 가장 높은 시점(동률이면 이른 시점) · 50,000 반복 학습의 마지막 모델. 최고 시점은 원 해상도 테스트 영상으로 고르는 선택(별도 검증 세트 없음) |
| 논문 최종 모델 (우리 방법, Ours) | 논문 결과표에서 제안 방법으로 보고하는 데이터셋별 최종 Student 모델. 정합 모듈 + 저·고주파 PAN 입력 U-Net(폭 104 · 깊이 [1,2,2], 약 2.2 M). 추론에는 이 Student 만 사용 |
| 목표 선택 시점 | 논문 최종 모델을 고른 시점 — 후보 50개 중 원 해상도 HQNR 하한(WV3 0.9585 이상 · QB 0.92 초과)을 넘는 것 가운데 축소 해상도 ERGAS 최소 |
| 공동 목표 | 같은 모델 시점이 HQNR 0.9585 이상 · ERGAS 2.040 미만을 함께 만족하는 것. 기준은 PAN-Crafter 논문의 WV3 값(HQNR 0.958 · ERGAS 2.040), HQNR 하한은 조금 엄격한 0.9585. 감독 계수 실험의 선택 · 판정 기준은 아님 |
| 폭 · 깊이 | U-Net 첫 단계의 채널 수 · 해상도 단계별 블록 수 |
| 정합 모듈 | PAN 과 MS 를 보고 영상 전체 이동량 (dy, dx) 하나를 예측해 PAN 만 그만큼 옮긴 뒤 U-Net 에 넣는 작은 CNN. MS · 정답 · 출력의 좌표는 그대로 |
| 저·고주파 PAN 입력 | U-Net 입력 = 4배 확대한 MS + 정합된 PAN + 그 저주파 성분(흐린 PAN) + 고주파 성분(PAN − 흐린 PAN). 입력 채널 = MS 밴드 수 + 3 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용 |
| 09-18 새 Teacher (s1) | 09-18 에 s1 에서 정합 모듈과 U-Net(폭 112 · 깊이 [1,2,3])을 무작위 초기값에서 50,000 반복 학습한 Teacher(입력 PAN + MS, 보정량 일관성 가중치 1e-4, seed 71001). WV3 최종 모델의 Teacher |
| 기준 Teacher | 보정량 일관성 가중치 1e-4, seed 2025 로 학습한 정합 모듈 + U-Net(폭 112 · 깊이 [1,2,3]). 주력 설정의 Teacher 이자 정합 모듈 출처 |
| 주력 설정 | 09-17 이후 WV3 seed 반복의 기준으로 쓴 q 가중 복원 KD 설정 — 입력 PAN + MS, Student 폭 104 · 깊이 [1,2,1], 기준 Teacher 고정, α 1 · β 0.1 · λE 0.002 · τR 0.0125 · q 기준값 0.328 · 정합 모듈 학습률 3e-6 |
| 보정량 일관성 | PAN 을 ε 만큼 더 옮긴 입력에 대한 예측 이동량이 원래 예측보다 정확히 ε 만큼 달라지도록 하는 손실 |
| q (정합 일관성 점수) | 고정한 Teacher 정합 모듈에 PAN 을 알려진 양만큼 옮긴 입력을 여러 개 넣었을 때, 예측 이동량이 그 이동을 정확히 되돌리지 못하는 정도(표본별 잔여 오차의 평균). 낮을수록 정합 예측이 일관됨 |
| 정답 기준 적응형 KD (정답 가중 α · Teacher 추종 β) | 정답 손실은 모든 위치에 유지하고, Teacher 오차가 큰 곳은 정답 손실 가중을 키우고(계수 α), Student 가 Teacher 보다 뒤지는 곳에서만 Teacher 출력을 따르게 하는(계수 β) KD. 정답 손실 가중 = 1 + α · d, d = Teacher 오차 / (Teacher 오차 + τR). Student 정합 모듈은 q 가중 정답 손실로만 학습 |
| Teacher 오차 기준값 τR | 위 d 의 기준값 — Teacher 오차가 τR 과 같으면 d = 0.5. Teacher 로 학습 데이터에서 한 번 정해 고정 |
| q 가중 정답 edge 감독 (λE) | 출력과 정답 영상의 경계(가로 · 세로 밝기 변화) 차이를 줄이는 손실. 표본마다 q 가중치를 곱해, q 가 낮을수록(Teacher 정합 반응이 일관될수록) 크게 반영. U-Net 에만 전달 |
| q 가중치 · q 기준값 | q 가중치 = q 기준값 / (q 기준값 + q). q 가 기준값과 같으면 0.5, q 가 작을수록 1 에 가까움. q 기준값은 Teacher 로 학습 데이터에서 한 번 정해 고정 |
| 정합 모듈 학습률 | Student 정합 모듈의 최대 학습률. U-Net 최대 학습률(1e-4)의 비율로 정함 — 0.03배(3e-6) |
| 원 화소값 (DN) | 위성 영상의 원래 밝기 단위. 여기서는 0–2047 |
