# 2026-09-11 실험 보고서 — 반응 학습된 정합 모듈 재사용(s1) · 정합 모듈 없는 같은 크기 지식 증류(s2·s3)

**작성일:** 2026-09-11
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정.
**서버:** s1 · s2 · s3 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

전날(09-10)의 두 갈래를 각각 한 요소씩 떼어 보는 단계. s1 은 반응을 배운 정합 모듈을 복원 학습과 분리해 재사용하고, s2 · s3 는 지식 증류(KD)를 정합 모듈과 분리해 독립 효과부터 확인.

**s1 — 반응을 배운 정합 모듈을 원본 입력 복원에 재사용 가능한가**
- **문제:** 09-10 에 PAN 을 일부러 더 옮기며 학습한 정합 모듈(PAN 을 MS 위치에 맞춰 옮기는 작은 CNN)은 이동에 반응하게 됐으나, 복원 U-Net 도 이동이 섞인 입력으로 학습돼 원본 입력 복원이 흔들리고 정합 모듈의 기여와 분리 불가.
- **접근:** 반응을 배운 정합 모듈만 가져오고, U-Net 은 항상 원본 입력으로 새로 학습. 추가 이동 연습은 정합 모듈에만 적용. 재사용 → 이어 학습 → 반응 유지 → 정답 기준 위치 감독을 한 단계씩 더해 단계별 효과 분리.

**s2 · s3 — 정합 모듈 없이도 같은 크기 Teacher 가 Student 에게 유효한 지식을 전달하는가**
- **문제:** 09-10 의 KD 는 정합 모듈과 함께 돌아, KD 자체의 효과와 정합 모듈의 효과 분리 불가.
- **접근:** Teacher · Student 모두 정합 모듈 없는 같은 크기 U-Net(폭 104 · 깊이 [1,2,2], 2.10 M)에서 KD 의 독립 효과부터 확인. 목적은 모델 압축이 아닌 같은 크기에서의 학습 강화 — Teacher 는 보조 신호원. 효과가 있다면 그 출처가 (a) Teacher 가 틀린 곳의 정답 가중, (b) Teacher 출력 모방, (c) 정답 · Teacher 의 출력 통계, (d) 성분별 방향 선택 중 어디인지 분해. 정합 연구는 별도로 유지하고, 유력한 KD 는 이후 정합 모듈과 결합해 검증 예정.
- **조정(오후):** 주 판정 지표를 원 해상도 HQNR 로 확정하고, 핵심 비교(KD 방식 단계 · 정답 통계 · 통계 정보원)를 먼저 도는 순서로 재배열. 나머지 확장 · 대조는 보류로 분리.

## 3. 결과 요약

- **s1 — 반응을 배운 정합 모듈은 원본 입력 복원에서도 HQNR 을 낮춤.** 반응을 유지한 설정은 모두 정합 모듈 없는 기준보다 0.007–0.020 낮음. 복원 손실만으로 이어 학습해 반응이 사라지고 이동량이 0.35 px 로 줄어야 기준 수준으로 회복. 이동량이 클수록 HQNR 이 낮은 관계. 정답 기준 위치 감독은 두 seed 모두 −0.004.
- **s2 · s3 — 정합 모듈 없는 같은 크기 KD 에서 어느 KD · 통계 감독도 두 서버에서 일관된 개선 없음.** 판정 기준을 넘은 개선 두 건은 seed 하나의 경계값(+0.0033)이고 서버 간 방향이 반대. Teacher 가 KD 없는 Student 보다 HQNR 이 낮음.

### 참고 — 평가 방식 변경

- 학습 중 평가 간격을 5 → 10 epoch(학습 데이터 전체를 한 번 도는 단위)로 확대 — ① 의 정합 모듈 사용 단계 전부, ② 전량. 평가가 전체 학습 시간의 절반 이상을 차지했기 때문.
- ② 에 진단 추가 — 모델마다 다른 평가 시점을 같은 간격으로 맞춘 최고 시점 재선택, 장면별 HQNR 분해, KD 손실의 정답 가중 항 · Teacher 추종 항 크기 기록. 원래의 최고 시점 모델은 보존.

## 6. 용어 정의

| 용어 | 뜻 |
|---|---|
| PAN · MS · HRMS | 고해상도 흑백 영상 · 저해상도 다중분광 영상 · 둘을 합쳐 만든 고해상도 다중분광 영상 |
| 정답 영상 (GT) | 학습과 축소 해상도 평가의 목표 영상. 원래 MS 를 정답으로 두고, 입력은 PAN · MS 를 4배 줄여 만듦 |
| 축소 해상도 평가 · 원 해상도 평가 | 줄인 입력으로 복원해 정답과 비교하는 평가 · 실제 해상도 입력으로 복원해 정답 없이 평가하는 평가(논문과 같은 테스트 영상 20장) |
| HQNR | 원 해상도 품질 지표 = (1 − D_λ)(1 − D_s). 1 에 가까울수록 좋음 |
| D_λ · D_s | HQNR 의 두 성분 — 분광 왜곡(입력 MS 의 밴드 간 관계와 어긋남) · 공간 왜곡(입력 PAN 과의 공간 구조 어긋남). 낮을수록 좋음 |
| SCC · ERGAS | 축소 해상도 평가 지표 — 정답과의 공간 상관(높을수록 좋음) · 상대 전역 오차(낮을수록 좋음, 참고용) |
| 판정 기준 0.0031 | 같은 설정을 seed 만 바꿔 학습했을 때 HQNR 이 흔들리는 폭(표준편차의 2배). 이보다 작은 차이는 우연 범위 |
| seed | 초기 가중치 · 데이터 순서를 정하는 난수 초기값 |
| 학습 중 최고 · 종료 시점 | 학습 중 1,000–2,000 반복마다 HQNR 을 재서 가장 높았던 시점의 모델 · 50,000 반복 학습의 마지막 모델 |
| px | PAN 해상도 기준 픽셀 |
| 폭 · 깊이 | U-Net 첫 단계의 채널 수 · 해상도 단계별 블록 수. 파라미터 수 — 폭 112 · [1,2,3] 2.66 M, 폭 104 · [1,2,2] 2.10 M |
| 정합 모듈 | PAN 과 MS 를 보고 영상 전체 이동량 (dy, dx) 하나를 예측해 PAN 만 그만큼 옮긴 뒤 U-Net 에 넣는 작은 CNN(0.105 M). MS · 정답 · 출력의 좌표는 그대로 |
| 보정량 일관성 | PAN 을 ε 만큼 더 옮긴 입력에 대한 예측 이동량이 원래 예측보다 정확히 ε 만큼 달라지도록 하는 손실 |
| 반응 기울기 | 64×64 조각의 PAN 을 알려진 양만큼 옮겼을 때 예측 이동량이 따라 바뀌는 비율(축별). −1 이면 추가 이동을 정확히 되돌림, 0 이면 반응 없음 |
| 잔여 오차 | 추가 이동을 되돌린 뒤 남는 이동량 오차의 평균 |
| 원 해상도 이동량 | 원 해상도 테스트 20장에서 정합 모듈이 PAN 을 옮기는 양의 중앙값 |
| 정답 기준 위치 감독 | 옮긴 PAN 의 경사 방향이 정답 영상(밴드 평균)의 경사 방향과 일치하도록 하는 손실. 정합 모듈에만 학습 신호 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용. 여기서는 Teacher 와 Student 의 크기가 같음 |
| KD 방식 단계 | 정답 L1 손실만 → 정답 손실 + 고정 비율로 Teacher 추종 → Teacher 오차가 큰 곳에 정답 손실 가중 → 여기에 Teacher 오차가 작은 곳에서 Teacher 추종 추가 → 여기에 Student 가 Teacher 보다 뒤지는 곳에서만 추종하도록 제한(적응형 KD). 모두 정답 손실은 모든 위치에 유지 |
| 출력 통계 감독 | 출력 영상의 국소 통계를 목표 통계에 맞추는 보조 손실. 통계 종류 — 밝기 분산 · 방향별 경사 분산 · 경사 공분산 · 밴드 간 분광 공분산, 또는 경계(edge) 응답 자체 |
| 통계 정보원 | 목표 통계를 어디서 가져오나 — 정답 / Teacher 통계 오차가 큰 곳에 정답 가중 / 적응(적응형 KD 규칙으로 정답·Teacher 혼합) / 정답·Teacher 고정 비율 결합 / Teacher 단독 |
| 평가기 | 팬샤프닝 표준 평가 코드(DLPan-Toolbox, MATLAB)를 파이썬으로 옮긴 것 |
