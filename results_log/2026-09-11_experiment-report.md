**대상:** WV3 · 서버 s1 · s2 · s3

## 1. 실험 목적

09-10 의 두 갈래를 각각 한 요소씩 떼어 보는 단계. s1 은 반응을 배운 정합 모듈을 복원 학습과 분리해 재사용하고, s2 · s3 는 KD 를 정합 모듈과 분리해 독립 효과부터 확인.

**s1 — 반응을 배운 정합 모듈을 원본 입력 복원에 재사용 가능한가**
- **문제:** 09-10 인위 변위 학습으로 정합 모듈은 변위에 반응하게 됐으나, 복원 U-Net 도 변위가 섞인 입력으로 학습돼 원본 입력 복원이 흔들리고 정합 모듈의 기여와 분리 불가.
- **접근:** 반응을 배운 정합 모듈만 가져오고, 복원 U-Net 은 항상 원본 입력으로 새로 학습. 변위 연습은 정합 모듈에만 적용. 재사용 → 이어 학습 → 반응 유지 → GT 기준 위치 감독을 한 단계씩 더해 단계별 효과 분리.

**s2 · s3 — 정합 모듈 없이도 같은 크기 Teacher 가 Student 에게 유효한 지식을 전달하는가**
- **문제:** 09-10 의 KD 는 정합 모듈과 함께 돌아, KD 자체의 효과와 정합 모듈의 효과 분리 불가.
- **접근:** Teacher · Student 모두 정합 모듈 없는 같은 골격(폭 104 · 깊이 [1,2,2], 2.10 M)에서 KD 의 독립 효과부터 확인. 목적은 압축이 아닌 같은 용량에서의 fitting 강화 — Teacher 는 참조 신호원. 효과가 있다면 그 출처가 (a) Teacher 가 틀린 곳의 GT 재가중, (b) Teacher 출력 모방, (c) GT · Teacher 구조 통계, (d) 성분별 방향 선택 중 어디인지 분해. 정합 연구는 별도 유지, 유력한 KD 는 이후 최종 정합 모듈에 이식해 상호작용 검증 예정.
- **조정(오후):** 주 판정 지표를 원 해상도 HQNR 로 확정하고, 핵심 비교(KD 방식 단계 · GT 통계 · 통계 정보원)를 먼저 도는 순서로 재배열. 나머지 확장 · 대조는 보류로 분리.

## 3. 결과 요약

- **s1 — 반응을 배운 정합 모듈은 원본 입력 복원에서도 HQNR 을 낮춤.** 반응을 유지한 설정은 모두 정합 모듈 없는 기준보다 0.007–0.020 낮음. 복원 loss 만으로 이어 학습해 반응이 사라지고 보정량이 0.35 px 로 줄어야 기준 수준으로 회복. 보정량이 클수록 HQNR 이 낮은 관계. GT 위치 감독은 두 seed 모두 −0.004.
- **s2 · s3 — 정합 모듈 없는 동일 용량 KD 에서 어느 KD · 통계 감독도 두 서버에서 일관된 개선 없음.** 판정선을 넘은 개선 두 건은 단일 seed 경계값(+0.0033)이고 서버 간 방향이 반대. Teacher 가 KD 없는 Student 보다 HQNR 이 낮음.

### ① 반응 학습된 정합 모듈 재사용 + 원본 입력 복원 학습 — s1 — 실행 (7벌)

골격 폭 112 · 깊이 [1,2,3], 복원 U-Net 은 seed 별 같은 초기값에서 새로 학습. 정합 모듈 출처는 09-10 반경 2 px 실험의 "보정량 일관성 · 원본 쪽 고정"판 최종(50K) 가중치. 정합 모듈 학습률은 U-Net 의 1/10. 예산 16 GPU-h.
