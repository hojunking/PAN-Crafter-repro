**작성일:** 2026-09-18
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 목표는 같은 시점의 모델에서 HQNR ≥ 0.9585 와 ERGAS < 2.040 을 동시에 넘는 것(논문 PAN-Crafter 의 WV3 보고값 HQNR 0.958 · ERGAS 2.040 기준, HQNR 쪽은 조금 더 엄격). ②·③ 은 학습 중 1,010 반복 간격 50개 시점 가운데 HQNR ≥ 0.9585 인 시점에서 ERGAS 가 가장 낮은 시점(목표 선택 시점)과 50,000 반복 종료 시점을 함께 기록.
**서버:** s1 · s2 · s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

09-16 부터의 주력 방법은 기준 Teacher 를 고정하고 작은 Student(정합 모듈 + 폭 104 · 깊이 [1,2,1] U-Net, 2.01 M)를 q 가중 복원 KD 로 학습하는 것. 이 방식으로 지금까지 학습한 모델 가운데 목표 달성 0개 — HQNR 0.9585 를 넘는 모델은 소수 있으나 ERGAS 는 최저 2.054(그 모델의 HQNR 0.950). 이날은 정합 모듈의 실제 기여 확인, ERGAS 격차의 원인 분석, 학습 편성과 입력 표현 변경의 세 갈래로 진행.

**s1–s5 — 학습된 Student 에서 정합 모듈이 실제로 기여하는가**
- **문제:** 정합 모듈에 대한 과거 판단이 엇갈림 — 09-12 정합 축 종합 판정은 부정적, 09-13 이후 약한 보정량 일관성에서만 소폭 이득. 현재 Student 가 정합 모듈 없이 추론해도 성능이 같은지, 오히려 나은지 확인되지 않은 상태.
- **접근:** 학습은 건드리지 않고, 각 서버가 가진 완료 Student 전부를 같은 가중치로 두 가지 추론 — 정합 켬(정상) · 정합 끔(정합 모듈 호출과 PAN 이동을 모두 생략하고 원 PAN 을 U-Net 에 바로 입력) — 에 넣어 축소 · 원 해상도 지표를 나란히 비교.

**s1–s5 — 전 서버 20시간 혼합 seed 재편**
- **문제:** 전날 계획(Teacher 추종 강도 0.1 / 0.2 마지막 비교로 한 설정을 고정한 뒤 seed 반복)은 비교 결과를 기다리는 동안 서버별 편성이 엇갈림. 모델 선택도 HQNR 최고 시점 하나만 봐서, ERGAS 가 그 시점이 학습의 어디였는지에 크게 좌우.
- **접근:** 남은 두 설정(Teacher 추종 강도 0.1 / 0.2)을 모든 서버에 같은 seed 쌍으로 미리 배정해, 서버마다 20시간 동안 서로 기다림 없이 독립 실행. 모델 선택 규칙을 "HQNR ≥ 0.9585 인 시점 중 ERGAS 최소"로 바꾸고 종료 시점 값도 함께 기록.

**s1–s5 — 저·고주파 PAN 입력 + 새 Teacher**
- **문제:** 계수 · seed 조정만으로는 ERGAS 가 2.05 부근에서 정체. 모든 Student 가 같은 기준 Teacher 에 묶여 있어 Teacher 쪽 변화도 시험 불가.
- **접근:** U-Net 입력에 PAN 의 저주파 · 고주파 성분을 추가 채널로 넣고(정합 모듈이 예측한 같은 이동량으로 함께 이동), 서버마다 Teacher 를 처음부터 새로 학습한 뒤 그 Teacher 로 Student 학습. s4 는 한 Teacher 아래에서 Student 입력 네 가지를 모두 학습해 Teacher 차이 없이 입력 효과를 비교.

**s1 — ERGAS 격차의 원인 분석 (학습 없는 분석)**
- **문제:** 정합 모듈은 64×64 조각으로 학습되지만 평가에서는 256×256(축소 해상도) · 512×512(원 해상도) 영상 전체를 한 번에 봄. 이 크기 차이 때문에 이동량 예측이 흐트러져 ERGAS 가 나빠진다는 가설. 또 설정 간 ERGAS 차이가 계수 효과인지, HQNR 최고 시점이 언제였는지의 차이인지 불분명.
- **접근:** 이미 학습된 모델로 (1) 정합 관련 기존 결과 재분석, (2) 입력 크기 · 정규화 통계 · 공간 평균 순서만 바꾼 추론, (3) 종료 시점 재측정과 두 학습 시점의 정합 모듈 · U-Net 교차, 가중치 보간, 이동량 상수 보정, MS 참조 교체, 짧은 추가 학습.

| 성분 대조군 | q 가중 복원 KD 의 한 성분만 바꾼 모델 — 정합 모듈 학습 가중을 균일(0.5) · 표본 간 섞기로 교체, edge 가중을 균일 · 섞기로 교체, 정합 모듈 고정 |
| 저주파 PAN · 고주파 PAN | PAN 을 가우시안(σ 1.98)으로 흐린 뒤 4배 축소하고 다시 확대한 영상 · PAN − 저주파 PAN |
| 입력 구성 | PAN+MS(9채널) · +저주파(10) · +고주파(10) · +저·고주파(11). 추가 성분은 PAN 과 같은 이동량으로 옮김 |
| 64 조각 중앙값 정합 | 영상을 겹치지 않는 64×64 조각으로 나눠 조각마다 이동량을 예측하고, 성분별 중앙값 하나로 전체 PAN 을 옮기는 추론 |
