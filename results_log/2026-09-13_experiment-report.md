# 2026-09-13 실험 보고서 — 보정량 일관성 가중치 정밀 확인(s1) · 정합 모듈 없는 같은 크기 KD 20시간 우선순위(s2·s3)

**작성일:** 2026-09-13
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. s2 · s3 의 조건부 후속 실험은 같은 서버 · 같은 seed 의 KD 없는 Student 대비 seed 3개 평균 HQNR 차이가 양수이고 3개 중 2개 이상이 양수인 후보에만 진행.
**서버:** s1 · s2 · s3 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

전날까지의 두 갈래를 각각 좁혀 확인하는 단계. s1 은 처음으로 판정 기준을 넘은 정합 설정이 우연이 아닌지, 그 이득이 실제 정합에서 오는지 확인하고, s2 · s3 는 정합 모듈 없는 같은 크기 KD 에서 남은 후보가 seed 를 바꿔도 재현되는지 확인.

**s1 — 보정량 일관성 가중치 1e-4 는 안정적인 값인가, 그 이득은 실제 정합에서 오는가**
- **문제:** 전날(09-12) 시작한 보정량 일관성 손실 가중치 탐색(0 · 1e-4 · 1e-3 · 3e-3 · 1e-2)에서 1e-4(=0.0001)만 정합 모듈 없는 모델보다 seed 3개 평균으로 판정 기준 이상 높았음. 그러나 1e-4 는 seed 하나로 고른 값이고 바로 옆 가중치(3e-5 · 3e-4)는 비어 있음. 또 가중치를 키울수록 정합 모듈(PAN 을 MS 위치에 맞춰 옮기는 작은 CNN)의 반응은 좋아지는데 HQNR 은 1e-4 를 넘으면 하락하고, 원 해상도 출력과 원 PAN 의 공간 상관(fSCC)은 1e-4 에서도 seed 3개 모두 하락 — HQNR 이득과 실제 정합의 관계가 불분명.
- **접근:** 1e-4 양옆 3e-5 · 3e-4 를 같은 seed 3개(1234 · 7777 · 2025)로 새로 학습하고, 정합 모듈 없음 · 가중치 0 · 1e-4 는 기존 모델을 대조군으로 재사용. 같은 모델에서 HQNR 과 정합 능력 — 추가 이동 반응, PAN · MS 상대 위치 대응, 독립 측정기로 잰 보정 전후 어긋남, 보정량 치환 — 을 함께 측정. 학습 구조 · 손실 종류는 그대로 두고 가중치만 변경. 계산 예산 GPU 18시간.

**s2 · s3 — 정합 모듈 없는 같은 크기 KD 의 남은 후보가 seed 를 바꿔도 재현되는가**
- **문제:** 09-11 부터 Teacher · Student 모두 정합 모듈 없는 같은 크기 U-Net 에서 KD 방식 · 출력 통계 감독을 분해해 왔으나, 판정 기준을 넘은 개선은 seed 하나의 경계값뿐이고 서버 간 방향도 엇갈림. 09-12 에 보류분까지 모두 편성한 최종 편성(s2 73개 · s3 83개)을 다 돌리기에는 신호가 약함.
- **접근:** 남은 서버당 GPU 20시간을 후보 셋에 집중 — 정답 경사 공분산(KD 없음), 적응형 KD + 정답 edge, 그리고 앞의 것이 재현될 때만 여는 정답 · Teacher 경사 공분산 고정 결합. 비어 있던 seed(777 · 2026)를 채워 공통 seed 3개(1234 · 777 · 2026)에서 같은 서버의 KD 없는 Student 와 비교하고, 진입 기준을 통과한 후보에만 후속 실험(Teacher 추종 항 제거 대조 · 고정 결합 통계)을 붙임. 계수 · 창 크기 · 학습률은 고정.

MS 를 다른 장면 것이나 밴드 평균값으로 바꾸면 반응 기울기가 −0.03 ~ +0.01 로 사라짐(가중치 0 · 1e-4 의 종료 시점 모델) — PAN 만 보는 지름길이 아님.
- **보정 후 PAN–MS 어긋남 감소.** 독립 측정기로 잰 원 해상도 20장의 어긋남(중앙값)이 보정 전 1.79 px(09-10 측정값과 같음) → 1e-4 · seed 1234 1.07 px, 3e-5 1.18 px, 3e-4 0.94–1.10 px(최고 시점) · 0.59–0.68 px(종료 시점). 20장 모두 감소하고 보정 방향이 추정 방향과 일치(코사인 평균 0.98 이상). 측정기의 장면별 신뢰도 조건을 통과한 장면은 없어 참고값. 어긋남을 가장 많이 줄인 3e-4 종료 시점 모델의 HQNR 이 가장 낮음.

| 보정량 치환 | 같은 모델에서 정합 모듈이 예측한 보정량만 다른 값 — 다른 장면의 보정 · 0 · 부호 반전 · 학습 조각 고정 보정 — 으로 바꿔 추론하는 검사. U-Net 은 원래 보정에 맞춰 학습된 상태라 입력 조건만 바꾼 결과 |
| 학습 조각 고정 보정 | 학습 데이터 64×64 조각 256개에서 정합 모듈이 예측한 보정량의 중앙값(0.13–0.19 px)을 모든 장면에 같게 적용한 값 |
| 기준 Teacher | 보정량 일관성 가중치 1e-4, seed 2025 로 학습한 정합 모듈 + U-Net(폭 112 · 깊이 [1,2,3]). 이후 실험의 Teacher 이자 정합 모듈 출처 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용. 여기서는 Teacher 와 Student 의 크기가 같음 |
| KD 방식 단계 | 정답 L1 손실만 → 정답 손실 + 고정 비율로 Teacher 추종 → Teacher 오차가 큰 곳에 정답 손실 가중(정답 가중) → 여기에 Teacher 오차가 작은 곳에서 Teacher 추종 추가 → 여기에 Student 가 Teacher 보다 뒤지는 곳에서만 추종하도록 제한(적응형 KD). 모두 정답 손실은 모든 위치에 유지 |
| Teacher 추종 항 | Student 출력을 Teacher 출력에 가깝게 만드는 손실 항. 적응형 KD 에서 이 항만 빼면 정답 가중만 남음 |
| 출력 통계 감독 | 출력 영상의 국소 통계를 목표 통계에 맞추는 보조 손실. 통계 종류 — 밝기 분산 · 방향별 경사 분산 · 경사 공분산 · 밴드 간 분광 공분산, 또는 경계(edge) 응답 자체 |
| 통계 정보원 | 목표 통계를 어디서 가져오나 — 정답 / Teacher 통계 오차가 큰 곳에 정답 가중 / 적응(적응형 KD 규칙으로 정답·Teacher 혼합) / 정답·Teacher 고정 비율 결합 / Teacher 단독 |
| 정답 edge | 출력의 경계(edge) 응답을 정답 영상의 경계 응답에 맞추는 보조 손실 |
| 진입 기준 | 같은 서버 · 같은 seed 의 KD 없는 Student 대비 seed 3개(1234 · 777 · 2026) 평균 HQNR 차이가 양수이고 3개 중 2개 이상이 양수. 조건부 후속 실험을 여는 조건 |
