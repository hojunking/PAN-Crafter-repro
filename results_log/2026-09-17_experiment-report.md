**작성일:** 2026-09-17
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 이날 목표는 논문 PAN-Crafter 의 WV3 보고값(HQNR 0.958 · ERGAS 2.040)을 같은 모델에서 넘는 것 — HQNR 0.9585 이상이면서 ERGAS 2.040 미만 — 이고, ②·③ 부터 목표 모델은 HQNR 0.9585 이상인 학습 시점 가운데 ERGAS 가 가장 낮은 시점.
**서버:** s1 · s2 · s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

09-16 에 다섯 서버에서 시작한 q 가중 복원 KD 전 서버 튜닝의 첫 결과를 보고, 남은 튜닝을 유력 설정의 반복 확인 중심으로 재편(①)한 뒤, 넓은 설정 탐색을 끝내고 설정 하나를 고정해 seed 만 바꿔 반복하는 단계로 전환(②·③). 별도로 s1 에서 이 방법이 기대는 정합 모듈 자체의 타당성을 기존 실험 산출물로 감사(④).

**공통 방법 — q 가중 복원 KD.** 기준 Teacher 를 고정하고, 더 작은 Student(폭 104 · 깊이 [1,2,1] U-Net + 기준 Teacher 에서 복사한 정합 모듈, 2.01 M)를 새로 학습(50,000 반복). U-Net 은 정답 손실(Teacher 오차가 큰 곳 가중) + Teacher 추종(Teacher 가 맞고 Student 가 뒤지는 곳만) + 정답 edge 손실로, 정합 모듈은 정답 손실만으로 학습. U-Net 의 edge 손실과 정합 모듈의 정답 손실에는 표본마다 q 가중(Teacher 정합 모듈의 예측이 일관된 표본일수록 큰 가중). 튜닝 대상은 정답 edge 감독 강도 · 정합 모듈 학습률 비율 · 정답 가중 · Teacher 추종 강도 · U-Net 학습률.

**s1 · s3 · s4 · s5 — 목표를 넘은 설정은 재현되는가, 그 이득은 어디서 오는가 (①)**

대상은 기준 Teacher 의 정합 모듈과, 같은 구조(폭 112 · 깊이 [1,2,3])에서 정합 강도만 다른 기존 모델들 — 정합 모듈 없음 · 보정량 일관성 가중치 0 / 3e-5 / 1e-4(기준 Teacher) / 3e-4 / 1e-2 · 09-10 이동 연습 정합 모듈을 고정해 쓴 모델. 새로 잰 것은 (a) 같은 모델에서 장면별 예측 대신 그 예측들의 평균 하나를 모든 장면에 적용한 원 해상도 재평가(3 seed), (b) 축소 해상도에서 학습된 보정량에 배율을 곱한 재평가, (c) 정합 모듈이 기준으로 삼는 확대 MS 와 정답 영상 사이의 어긋남 분해. 어긋남 크기는 경계 기반 상관 측정기로 잰 값이며 센서 참값이 아님.

- **정합이 강할수록 원 해상도 지표가 나빠짐.** 원 PAN 과의 공간 상관(fSCC)도 정합 강도에 따라 단조 하락(정합 모듈 없음 0.900 → 기준 Teacher 0.879 → 가중치 1e-2 0.847 → 이동 연습 정합 모듈 고정 0.813) — 오르는 지표는 시점 선택에 쓴 HQNR 하나. HQNR 의 공간 왜곡 D_s 가 옮기기 전 원 PAN 을 기준으로 하기 때문이며, 모든 모델에 같은 외부 보정을 적용한 뒤 재면 순위가 뒤집힘(가장자리 64 px 제외 HQNR: 정합 모듈 없음 0.9233 최저, 이동 연습 정합 모듈 고정 0.9632 최고). 다만 그 기준은 이동 연습 정합 모듈 자신의 보정이라 순환적이고 논문 수치와 비교할 수 없어 판정에 쓰지 않음.
- **정답이 있는 축소 해상도에서도 같은 순서.** 같은 모델 안에서는 학습된 보정 배율(1배)에서 ERGAS 가 가장 낮지만, 이는 U-Net 이 옮겨진 PAN 에 맞춰 학습됐기 때문이라 정합의 정확성과 무관. 보정을 빼면 ERGAS 가 기준 Teacher +4.8%, 이동 연습 정합 모듈 고정 +77% — 강한 정합일수록 정합 모듈에 크게 의존하는 모델.
- **원인은 정합 모듈의 기준 영상.** 확대 MS 와 정답 영상의 0.68 px 차이는 배율이 아닌 샘플링 위상의 차이(같은 내용을 흐리기만 한 측정기 바닥은 0.21 px). 정합 모듈은 PAN 을 이 확대 MS 에 정확히 맞추지만 정답과의 어긋남은 그대로여서, 복원 손실 입장에서는 정답에 가까워지지 않는 이동 — 학습 중 보정 크기가 약 1/3 로 줄어든 것과 부합.
- **판정 — 현재 형태로는 "장면에 적응하는 정합"을 방법의 기여로 제안 불가.** 운영 변화 없음(기준 Teacher · 보정량 일관성 가중치 1e-4 유지). 제안하려면 상수 보정을 처음부터 학습한 대조, 시점 선택과 보고를 분리한 테스트 세트 분할, 위상이 맞는 MS 를 정합 모듈 기준으로 쓰는 실험이 필요.

| 샘플링 위상 차이 | 격자 크기는 같지만 화소 중심 위치가 1 px 보다 작게 어긋나는 것. 여기서는 MS 를 4배 bicubic 확대한 영상과 정답 영상 사이의 차이 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용 |
| 기준 Teacher | 보정량 일관성 가중치 1e-4, seed 2025 로 학습한 정합 모듈 + U-Net(폭 112 · 깊이 [1,2,3]). 이후 실험의 Teacher 이자 정합 모듈 출처 |
| q (정합 일관성 점수) | 고정한 Teacher 정합 모듈에 PAN 을 알려진 양만큼 옮긴 입력을 여러 개 넣었을 때, 예측 이동량이 그 이동을 정확히 되돌리지 못하는 정도(표본별 잔여 오차의 평균). 낮을수록 정합 예측이 일관됨 |
| q 가중 | 표본별 가중 = q_ref / (q_ref + q). q_ref 는 학습 데이터 q 의 중앙값(0.328)이라 q 가 중앙값이면 0.5, 실제 범위 약 0.40–0.55 |
| q 가중 복원 KD | Student 의 U-Net 은 정답 손실(정답 가중) + Teacher 추종 + q 가중 정답 edge 손실로, 정합 모듈은 q 가중 정답 손실만으로 학습하는 KD. 두 손실의 기울기를 각 부분에만 적용 |
| 정답 edge 감독 | 출력과 정답 영상의 경계(방향별 미분) 차이를 줄이는 보조 손실. 강도 0.0006 · 0.002 · 0.006 |
| 정답 가중 | Teacher 오차가 큰 위치의 정답 손실을 키우는 계수 α (0.5 · 1 · 1.5). 손실 = (1 + α × 0–1 로 정규화한 Teacher 오차) × 정답 오차. q 가중과 별개 |
| Teacher 추종 강도 | Teacher 오차가 작고 Student 가 Teacher 보다 뒤지는 위치에서만 Student 출력을 Teacher 출력에 맞추는 항의 강도(0.05 · 0.1 · 0.2) |
| 정합 모듈 학습률 비율 | Student 정합 모듈의 학습률을 U-Net 학습률의 몇 배로 둘지(0.003 · 0.01 · 0.03) |
| 상수 0.5 대조 · 층 안 섞기 대조 | q 가중을 모든 표본에 0.5 로 고정 · 같은 층(Teacher 복원 오차 10분위 × 데이터 증강 상태) 안에서 가중값을 다른 표본에 무작위 재배정 — 가중값 분포는 두고 표본과의 연결만 끊음 |
| 목표 하한 · 공동 목표 | HQNR 0.9585 이상(논문 PAN-Crafter 보고값 0.958 보다 높게 잡은 하한) · 같은 모델에서 하한과 ERGAS 2.040 미만(논문 보고값)을 함께 만족 |
| 목표 모델 선택 규칙 | 50개 시점 중 HQNR 0.9585 이상인 시점 가운데 ERGAS 최소(②·③). 이전 규칙은 같은 조건에서 SCC 최대 |
| 서버 간 재현 확인 | 같은 설정 · 같은 seed 를 다른 서버에서 다시 학습한 비교. 새 seed 로 세지 않음 |
| 테스트 세트 선택 편향 | 학습 시점 · 가중치를 보고용 테스트 세트로 고를 때 생기는 과대 추정. 종료 시점 · 학습 후반 20% 평균은 선택이 없는 값 |
