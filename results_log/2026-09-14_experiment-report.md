**작성일:** 2026-09-14
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 이날 통합 실험의 목표는 HQNR 0.959 이상(확장 목표 0.960).
**서버:** s1 · s2 · s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

전날까지의 결론 — 정합 모듈 + 보정량 일관성(가중치 1e-4)이 정합 모듈 없는 모델보다 3 seed 평균 +0.0046 높은 유일한 개선 요소(평균 HQNR 0.9560), 정합 모듈 없는 같은 크기 KD 는 모델 92개에서 이득 없음. 이날은 두 갈래를 하나로 묶어 HQNR 0.959 를 겨냥한 통합 실험을 다섯 서버에서 시작하고, s1 에서는 정합 모듈의 일관성 지표가 무엇을 가리키는지 검증.

**s1 · s2 · s3 — 기준 Teacher 의 정합 모듈을 Student 에 넘기고 Teacher 정보로 복원 학습을 보강하면 0.959 에 닿는가**
- **문제:** 기준 Teacher(HQNR 0.9570)와 같은 방법의 3 seed 평균(0.9560)이 목표보다 0.002–0.003 낮음. 정합 모듈 없는 KD 는 효과가 없었고, 정합 모듈이 있는 상태의 KD 는 미검증.
- **접근:** 기준 Teacher 의 정합 모듈을 Student 에 복사하고 U-Net 만 새로 학습. (1) 복사한 정합 모듈을 계속 학습(공동 적응)할지 고정할지, (2) KD 방식(정답 L1 만 / 정답 가중만 / 적응형 KD + 정답 edge / 여기서 Teacher 추종 제거)의 두 축을 같은 초기값 · 같은 데이터 순서의 대응 비교로 분리. 서버마다 seed 하나(1234 · 777 · 2026).

**s4 — 같은 seed 의 서버 간 차이와 정합 모듈 학습 폭**
- **문제:** 서버마다 seed 가 달라 서버 차이와 seed 차이가 섞임. 복사한 정합 모듈의 업데이트가 과할 가능성.
- **접근:** s1 과 같은 seed 로 기본 두 설정을 다시 학습(서버 교차)하고, 정합 모듈 학습률만 0.3배로 줄인 두 설정 추가. 적응형 KD 계수 조정과 확인 seed 는 결과를 본 뒤 조건부.

**s5 — 정합 모듈을 언제, 어떤 손실로 학습시킬 것인가**
- **문제:** 새로 초기화한 U-Net 의 초기 부정확한 경사가 복사한 정합 모듈을 흔들거나, KD 추가 손실이 정합 모듈에 불리하게 작용할 가능성.
- **접근:** s3 과 같은 seed 로, 처음 5,000 반복 동안 정합 모듈 고정(초기 고정)과 추가 손실을 U-Net 에만 보내는 방식(수신 경로 제한)을 비교.

**s1 — 정합 일관성 점수(q)는 좋은 정합의 표지인가**
- **문제:** 보정량 일관성 가중치를 1e-4 보다 키우면 정합 반응은 좋아지지만 HQNR 은 하락. q 가 "정합이 잘 된 표본" 을 가리키는지, Teacher 신호를 믿을 표본을 고르는 기준이 될 수 있는지 확인되지 않은 상태.
- **접근:** 새 모델 학습 없이 저장된 모델에서 표본별 q 와 복원 오차 e 를 재어 네 집단으로 나누고 보정 치환 · 추가 이동 · 짧은 적응 학습으로 가설 검증(④). 같은 질문을 Student 쪽에서 반복하고 정합 모듈 고정 대 적응의 대응 학습을 더해 확인(⑤).

## 3. 결과 요약

- **s1 · s2 · s3 — 목표 0.959 에 닿은 모델 없음(최고 0.9583), 어느 설정도 세 seed 에서 일관된 개선 없음.** 적응형 KD + 정답 edge 는 정답 L1 만 대비 +0.0004 · +0.0034 · +0.0001 로 모두 양수이나 판정 기준을 넘은 것은 s2 하나. 정합 모듈 고정은 공동 적응과 차이 없음(+0.0021 · −0.0019 · −0.0013). 고정 상태의 KD 는 이득 없고 s2 · s3 에서 축소 해상도 지표 악화(ERGAS 2.065 → 2.361 · 2.041 → 2.192).
- **s4 — 0.959 이상은 KD 없는 대조 한 개(0.9594)뿐이고, 같은 설정 · 같은 seed 재실행은 0.9568.** 같은 설정의 반복 차이(0.0026 · 0.0017)가 판정 기준에 근접. 적응형 KD 는 두 번 모두 KD 없는 대조보다 낮고(−0.0036 · −0.0027), 정합 모듈 학습률 0.3배는 이득 없음.
- **s5 — 초기 고정은 KD 없는 기준 대비 −0.0040, 수신 경로 제한은 공동 적응 KD 와 차이 없음(−0.0007).**
- **s1 — q 는 조각 수준 정합 품질의 표지가 아님.** q 가 낮은 조각이 오히려 복원 오차가 높음(3 seed 모두) — PAN 텍스처가 q 를 낮추고 오차를 높이는 공통 요인이며, 텍스처를 통제하면 상관이 양으로 역전. 장면 단위로는 q 가 낮은 장면이 HQNR 이 높음. q 로 Teacher 신호를 배분한 5,000 반복 적응은 모든 방식에서 HQNR 이 0.0034–0.0043 하락하고 방식 간 차이 없음 → q 기반 Teacher 신호 선택은 채택 안 함.
- **s1 사분면 검증 — Student 에서도 조각 수준 q–오차 상관은 거의 0, 학습된 보정은 0 보정보다 HQNR +0.007.** 정합 모듈 적응(Teacher 추종 경사만 차단)은 고정보다 +0.0032 — seed 하나, 판정 기준 경계.

- **조각 수준 q–오차 상관은 거의 0** — 기준값용 1,024개에서 −0.06, 탐색 · 확인용에서 −0.02(신뢰구간 0 포함). q 와 e 는 각각 텍스처와 강하게 연관(−0.53 · +0.62) — ④ 와 같은 방향.
- **장면 수준 q–HQNR 음의 상관(−0.61 ~ −0.69)은 분광 왜곡 D_λ 와의 관계**(+0.87 ~ +0.88), 공간 왜곡 D_s 와는 유의하지 않음.
- **보정 자체는 작동하나 q 값이 정합 품질을 보증하지는 않음** — 학습된 보정을 0 으로 바꾸면 HQNR −0.007, 부호를 뒤집으면 −0.008 ~ −0.010(두 모델 모두 신뢰구간 0 제외), 고정 치우침 ±0.25 px 는 평균 −0.0026. 두 예측에 같은 치우침을 더하면 q 는 그대로인데 복원 오차가 변함.
- **정합 모듈에서 복원 경사와 일관성 경사는 거의 직교**(평균 코사인 −0.03 ~ −0.12, 음수 56–62%), 가중치 1e-4 반영 시 일관성 경사 크기는 복원 경사의 약 1%.
- **정합 모듈 적응(Teacher 추종 경사만 차단)은 고정보다 +0.0032** — seed 하나, 판정 기준 경계. 같은 적응에서 Teacher 추종 경사까지 받는 설정(①)보다 +0.0028(차이 없음).
