# 2026-09-16 실험 보고서 — 정답 edge 감독의 강도·시점 조절(s2·s5) · q 가중 복원 KD 전 서버 튜닝(s1~s5)

**작성일:** 2026-09-16
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. q 가중 복원 KD 튜닝(③)은 목표를 따로 둠 — 원 해상도 HQNR 0.9585 이상이면서 같은 시점 모델의 축소 해상도 지표가 논문 PAN-Crafter 의 WV3 수치(SCC 0.988 · ERGAS 2.040 등)보다 좋은 것.
**서버:** s1 · s2 · s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

09-14 부터 기준 Teacher(먼저 학습해 고정한 모델)의 정합 모듈을 Student 에 복사해 재사용하는 지식 증류(KD)를 시험 중이고, 09-15 부터 Student U-Net 을 더 작게(폭 104 · 깊이 [1,2,1]) 줄여 진행. 09-15 에 시험한 q 선택 정답 edge 감독 — 정합 일관성 점수(q)로 고른 표본에만 정답 edge 손실을 주는 방식 — 은 기존 방식 대비 이득의 부호가 seed · 서버마다 달라 불확실한 상태. 이날은 두 방향 — (1) 정답 edge 감독의 강도 · 시점 조절(s2 · s5), (2) 학습 방식을 하나로 고정한 계수 튜닝(s1~s5). (2) 가 정해지면서 (1) 의 seed 반복 단계와, 같은 날 작성한 기존 방식 튜닝 계획은 (2) 로 대체.

**s2 · s5 — 정답 edge 감독을 얼마나 · 언제 줄 것인가**
- **문제:** 기존 방식은 정답 가중 · Teacher 추종 · 정답 edge 를 함께 써서 edge 만의 기여가 분리 안 됨. q 로 표본을 골라 edge 를 주는 방식의 추가 이득도 seed · 서버마다 부호가 다름.
- **접근:** q 선택을 더 정교하게 만들기 전에 edge 계수만 조절. s2 는 강도(기존 계수의 0 · 0.25 · 0.5 · 2배)와 구성 요소(Teacher 없이 정답 edge 만 · Teacher 추종 제거), s5 는 같은 평균 계수에서의 시점 배분(전반 1배 → 후반 0.5배 · 반대 순서 · 상수 0.75배)과 q 가 높은 표본도 약하게 감독하는 완만한 q 가중. seed 하나로 먼저 탐색하고 다른 두 seed 로 반복하는 구성.

**s1~s5 — 방식을 고정한 q 가중 복원 KD 의 계수 튜닝**
- **문제:** 기존 방식은 정합 모듈에도 Teacher 추종 · edge · 보정량 일관성 손실이 모두 전달되는 복잡한 구성이고, 요소별 효과가 seed · 서버마다 흔들림. 원 해상도 HQNR 0.9585 이상인 모델은 있었으나 같은 시점의 축소 해상도 ERGAS 가 2.07 이상으로 논문 수치(2.040)에 못 미침.
- **접근:** 학습 방식을 하나로 고정 — 기준 Teacher 정합 모듈로 미리 잰 표본별 q 로 표본 가중을 만들어, 정합 모듈은 이 가중을 곱한 정답 손실만으로 아주 작은 학습률로 조정하고, U-Net 은 적응형 KD 와 같은 가중을 곱한 작은 정답 edge 손실로 학습. 방식은 그대로 두고 계수(edge 계수 · 정합 모듈 학습률 · 정답 가중 · Teacher 추종 · 전체 학습률)만 서버별로 나눠 미리 정한 68개로 튜닝. q 가중의 실제 기여는 상수 가중 · 섞은 가중 · 정합 모듈 고정 대조로 확인.

### ③ q 가중 복원 KD 전 서버 튜닝 — s1~s5 — 67개 실행 · 1개 계획(실행 보류)

**방식** (전 서버 공통, 고정)
- Student — 폭 104 · 깊이 [1,2,1] U-Net(1.90 M, seed 별로 새로 초기화) + 기준 Teacher 에서 복사한 정합 모듈(0.105 M). Teacher — 기준 Teacher(고정). 입력은 원본 PAN · MS 그대로(학습 중 PAN 추가 이동 · 보정량 일관성 손실 없음).
- 표본 가중 w = q_ref / (q_ref + q). q 는 기준 Teacher 정합 모듈로 미리 잰 표본별 정합 일관성 점수, q_ref 는 학습 데이터 q 의 중앙값(0.328). q 가 낮을수록(정합 예측이 일관될수록) 큰 가중 — 실제 범위 0.40–0.55, 평균 0.50.
- U-Net 손실 = 정답 기준 적응형 KD(정답 가중 α · Teacher 추종 β) + λE × w × 정답 edge 손실.
- 정합 모듈 손실 = w × 정답 가중 L1 만(Teacher 추종 · edge · 보정량 일관성 없음). 같은 순전파에서 두 손실의 기울기를 따로 구해 각 모듈에만 반영.
- 정합 모듈 학습률 = U-Net 학습률 × 비율. 기준 설정 — edge 계수 λE 2e-3(기존 방식의 0.091 보다 훨씬 작은 값), 비율 0.01(정합 모듈 학습률 1e-6), α 1, β 0.1, U-Net 최고 학습률 1e-4. 50,000 반복, 배치 48.
- 목표 — 원 해상도 HQNR 0.9585 이상이면서 같은 시점의 축소 해상도 지표가 논문 PAN-Crafter 의 WV3 수치를 넘는 것(SCC 0.988 → ERGAS 2.040 → PSNR 37.956 → SAM 2.787 → Q8 0.922 → SSIM 0.976 순으로 우선).

| 정답 가중 α · Teacher 추종 β | 적응형 KD 의 두 계수 — Teacher 오차가 큰 위치의 정답 L1 가중을 (1 + α × Teacher 오차 비율)로 키우는 정도 · Student 가 뒤지는 위치에서 Teacher 출력을 따르게 하는 항의 크기 |
| 정답 edge 손실 (edge 감독) | 출력과 정답 영상의 밴드별 경사(가로 · 세로 Scharr 미분) 차이의 L1 손실. 경계 · 질감 구조를 정답에 맞추는 보조 손실 |
| 기존 방식 | 09-15 까지의 주력 설정 — 기준 Teacher 에서 복사한 정합 모듈을 이어 학습(학습률 1e-5, 보정량 일관성 1e-4) + 정답 기준 적응형 KD(α 1 · β 0.1) + 정답 edge 손실(계수 0.091) |
| q (정합 일관성 점수) | 고정한 Teacher 정합 모듈에 PAN 을 알려진 양만큼 옮긴 입력을 여러 개 넣었을 때, 예측 이동량이 그 이동을 정확히 되돌리지 못하는 정도(표본별 잔여 오차의 평균). 낮을수록 정합 예측이 일관됨 |
| q 선택 edge 감독 | q 가 학습 데이터 중앙값(0.328)보다 낮은 표본에만 정답 edge 손실을 주는 방식 |
| 완만한 q 가중 | q 가 중앙값보다 낮은 표본은 정답 edge 0.75배, 높은 표본은 0.25배로 감독 — 높은 표본을 끄지 않는 변형 |
| 표본 가중 w | w = q_ref / (q_ref + q), q_ref = 학습 데이터 q 의 중앙값 0.328. q 가 낮을수록 커짐(0.40–0.55, 평균 0.50) |
| q 가중 복원 KD | ③ 의 고정 방식 — 정합 모듈은 w 를 곱한 정답 가중 L1 만으로, U-Net 은 적응형 KD + w 를 곱한 정답 edge 손실로 학습하고, 두 손실의 기울기를 모듈별로 분리 |
| 기준 설정 | ③ 의 공통 기준 — λE 2e-3 · 정합 모듈 학습률 비율 0.01 · α 1 · β 0.1 · U-Net 최고 학습률 1e-4 |
| 정합 모듈 학습률 비율 | 정합 모듈 학습률 ÷ U-Net 학습률 |
| 상수 가중 · 섞기 · 정합 모듈 고정 대조 | q 가중 대신 모든 표본에 0.5(중앙값 q 의 가중과 같은 값) · Teacher 오차 10분위 × 데이터 회전 상태가 같은 표본끼리 가중값을 고정 순열로 맞바꿈(분포 유지, q 와 표본의 연결만 제거) · 복사한 정합 모듈을 학습하지 않음 |
| 목표 · 공동 목표 | ③ 의 목표 — 원 해상도 HQNR 0.9585 이상이면서 같은 시점 축소 해상도 지표가 논문 PAN-Crafter WV3 수치(SCC 0.988 · ERGAS 2.040 · PSNR 37.956 · SAM 2.787 · Q8 0.922 · SSIM 0.976) 이상. 공동 목표 = HQNR 0.9585 이상 · ERGAS 2.040 미만 동시 |
