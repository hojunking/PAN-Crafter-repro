# 2026-09-23 실험 보고서 — 구성 요소 제거 반복 확장(s1 · s2 · s3) · 주력 설정 민감도(s4 · s5)

**작성일:** 2026-09-23
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** 공개 팬샤프닝 벤치마크(PanCollection)의 위성 세트 3개. WV3 — WorldView-3 위성 영상, MS 8밴드 + PAN 1밴드. QB — QuickBird 위성 영상, MS 4밴드 + PAN 1밴드. GF2 — Gaofen-2 위성 영상, MS 4밴드 + PAN 1밴드. 세 세트 모두 PAN 해상도는 MS 의 4배. s1 · s4 · s5 는 WV3, s2 는 QB, s3 는 GF2 사용.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 이날 두 실험은 비교할 모델 시점을 HQNR 최고가 아닌 미리 정한 규칙으로 고름 — 구성 요소 제거 반복은 후보 시점 50개 가운데 검증 조각의 ERGAS 가 가장 낮은 시점, 주력 설정 민감도는 학습 종료 시점(50,000 반복).
**서버:** s1 · s2 · s3 · s4 · s5 — 실험용 GPU 서버(서버당 GPU 1장).

## 1. 실험 목적

WV3 에서 고정한 최종 방법의 논문용 근거를 쌓는 단계. 최종 방법은 Teacher 가 보정량 일관성으로 학습한 정합 모듈을 Student 가 물려받아 계속 학습하고, Student 는 PAN · MS 에 저·고주파 PAN 입력을 더해 정답 기준 적응형 KD 와 q 가중 정답 edge 감독으로 학습하는 구성. s1 · s2 · s3 는 이 방법의 구성 요소별 기여를 세 위성 세트에서 반복 측정, s4 · s5 는 그 전 단계 주력 설정의 계수 민감도 측정.

**s1 · s2 · s3 — 구성 요소별 기여를 세 위성 세트에서 반복 측정**
- **문제:** 09-21 부터 s1(WV3) · s2(QB)에서 구성 요소를 하나씩 더하거나 빼는 Student 17구성을, Teacher · Student seed 를 바꿔 가며 5회차 반복 학습 중. 공백 두 가지 — (1) Student 정합 모듈을 Teacher 정합 모듈로 초기화하는 효과가 Teacher 학습 때 준 보정량 일관성 덕인지, 먼저 학습된 정합 모듈이라는 점 덕인지 분리 불가. 기존 대조(Teacher 를 보정량 일관성 없이 학습한 Teacher 로 통째로 교체)는 초기값 외에 Teacher 출력 · 오차 · q 까지 함께 바뀜. (2) GF2 에는 같은 구성 요소 표가 없음.
- **접근:** (1) "일관성 Teacher 정합 모듈로 초기화" 구성과 모든 조건을 같게 두고 정합 모듈 초기값만 일관성 없는 Teacher 에서 가져오는 새 구성 1개 추가 — s1 · s2 의 기존 5회차에 보충, 이후 회차에도 포함. (2) s3 에서 GF2 반복을 새로 시작 — 회차마다 Teacher 2개 + Student 18구성을 WV3 · QB 와 같은 학습 길이(50,000 반복) · 같은 계수로 학습. GF2 에서 쓰던 전용 증강 · 긴 학습은 제외. (3) 세 서버 모두 서로 기다리지 않고 사용자가 멈출 때까지 반복.

**s4 · s5 — 주력 설정의 계수 민감도**
- **문제:** 09-17 이후 WV3 seed 반복의 기준으로 써 온 주력 설정(q 가중 복원 KD — edge 감독 계수 0.002, 정합 모듈 학습률 3e-6; seed 하나의 학습 중 최고 시점 HQNR 0.9591 로 목표선 0.9585 를 넘은 설정)이 계수 값에 얼마나 민감한지 미측정.
- **접근:** 계수 하나만 중심값의 위 · 아래 한 점으로 바꾼 모델 6개 + 중심값 모델 1개를 한 주기로 묶고, 같은 seed · 같은 초기값 · 같은 데이터 순서로 학습해 같은 주기의 중심값 모델과 비교. s4 는 손실 계수 3개(추가 정답 가중 · Teacher 추종 · edge 감독), s5 는 가중 기준값 2개(q 기준값 · Teacher 오차 기준값)와 정합 모듈 학습률. 주기마다 seed 를 바꿔 상한 없이 반복. Teacher 는 기준 Teacher 고정. 좋은 조합 탐색이 아닌, 정해진 설정 주변에서 계수 변화의 영향 측정이 목적.

| Teacher 추종 β | Student 오차가 Teacher 오차보다 큰 위치에서만 Student 출력을 Teacher 출력 쪽으로 당기는 항의 계수. Teacher 오차가 작은 위치일수록 강하게 적용 |
| Teacher 출력 균일 추종 | 모든 위치에서 같은 계수(0.1)로 Teacher 출력을 따르게 하는 KD. 정답 가중 · 위치 선택 없음 |
| 저·고주파 PAN 입력 | 저주파 PAN = PAN 을 가우시안으로 흐리게 해 MS 해상도로 줄였다가 다시 4배로 키운 영상, 고주파 PAN = PAN − 저주파 PAN. 둘 다 PAN 과 같은 이동량으로 정합한 뒤 PAN · MS 와 함께 Student 입력으로 사용. 이 입력이 없는 구성은 같은 입력 자리를 0 으로 채워 모델 크기를 맞춤 |
| 정답 edge 감독 | Student 출력의 경계 응답(방향별 Scharr 경사)을 정답 영상의 경계 응답에 맞추는 보조 손실. 계수 λE |
| q (정합 일관성 점수) | 고정한 Teacher 정합 모듈에 PAN 을 알려진 양만큼 옮긴 입력을 여러 개 넣었을 때, 예측 이동량이 그 이동을 정확히 되돌리지 못하는 정도(표본별 잔여 오차의 평균). 낮을수록 정합 예측이 일관됨 |
| q 가중치 · q 기준값 | q 가중치 = q 기준값 / (q 기준값 + q). q 가 기준값과 같으면 0.5, q 가 작을수록 1 에 가까움. q 기준값은 해당 Teacher 의 학습 데이터 q 중앙값(주력 설정 0.328). 누적 구성 중 q 도입 전 단계는 0.5 고정 |
| q 가중 복원 KD | U-Net 은 정답 기준 적응형 KD 손실 + q 가중치를 곱한 정답 edge 감독으로, 정합 모듈은 q 가중치를 곱한 정답 손실만으로 학습하는 방식. 두 모듈의 학습 신호를 분리해 한 번에 갱신(09-16 확정) |
| 전체 방법 | 최종 방법의 모든 요소를 쓴 구성 — 저·고주파 PAN 입력, 일관성 Teacher 정합 모듈 복사 후 계속 학습, 정답 기준 적응형 KD, q 가중 정답 edge 감독, 정합 모듈의 q 가중 정답 손실 |
| 주력 설정 | 09-17 이후 WV3 seed 반복의 기준으로 쓴 q 가중 복원 KD 설정 — 입력 PAN + MS, Student 폭 104 · 깊이 [1,2,1], 기준 Teacher 고정, α 1 · β 0.1 · λE 0.002 · τR 0.0125 · q 기준값 0.328 · 정합 모듈 학습률 3e-6 |
| 정합 모듈 학습률 | Student 정합 모듈의 최대 학습률. U-Net 최대 학습률(1e-4)의 비율로 정함 — 주력 설정 0.03배(3e-6) |
| 회차 · 주기 | ① ② 에서 Teacher 쌍과 Student 전 구성을 새 seed 로 한 번씩 학습하는 단위 · ③ 에서 중심값 모델 1개와 변형 6개를 같은 seed 로 학습하는 단위. 둘 다 안에서는 초기값 · 데이터 순서가 같음 |
| 목표선 | WV3 에서 HQNR 0.9585 이상 · ERGAS 2.040 미만 — 논문 PAN-Crafter 의 WV3 보고값(HQNR 0.958 · ERGAS 2.040)을 넘는 수준 |
