## 1. 1차 캠페인(MS-only plain, 7/7 완주)이 드러낸 것 — 계획의 전제가 깨졌다

계획 §1 은 "dual ≈ MS-only 이므로 빠른 MS-only plain 으로 탐색한다"를 전제로 삼았다.
이 전제는 **W96/W128 에서만 성립하고 4-6M 에서 무너진다.**

### 1.1 MS-only plain 은 학습 후반에 HQNR 을 잃고, 손실이 용량에 비례한다

| 실행 | Params | peak HQNR | 최종(ep245) | 손실 |
|---|---:|---:|---:|---:|
| `S1_C0_W96_D124_MS2` | 2.12M | 0.9515 | 0.9477 | −0.0038 |
| `S1_A0_W128_D124_MS2` | 3.77M | 0.9514 | 0.9449 | −0.0066 |
| `S1_T00_W160_D122_MS2` | 4.95M | 0.9551 | 0.9464 | −0.0087 |
| `S1_T02_W160_D124_MS2` | 5.88M | 0.9551 | 0.9415 | −0.0136 |
| `S1_T01_W144_D124_MS2` | 4.76M | 0.9536 | 0.9376 | **−0.0159** |
| `S1_T03_W176_D122_MS2` | 5.99M | 0.9548 | 0.9427(plateau) | −0.0121 |
| **`S1_T05_W160_D124_DUAL`** | 5.88M | 0.9564 | 0.9534 | **−0.0030** |

### 1.2 원인은 D_λ 다 — 같은 구조 A/B (W160·d124)

| ep | MS-only D_λ | dual D_λ | MS-only D_s | dual D_s |
|---:|---:|---:|---:|---:|
| 25 | 0.0211 | 0.0182 | 0.0514 | 0.0450 |
| 85 | 0.0301 | 0.0219 | 0.0507 | 0.0439 |
| 165 | 0.0370 | 0.0261 | 0.0520 | 0.0472 |
| 245 | **0.0398** | 0.0279 | 0.0531 | 0.0469 |

MS-only 는 D_λ 가 **0.021 → 0.040 으로 단조 악화**한다(ERGAS 는 2.03 에서 개선 정체).
D_s 는 거의 변하지 않으므로 HQNR 붕괴는 전적으로 spectral distortion 몫이다.
**PAN reconstruction task 가 없으면 큰 모델이 후반에 스펙트럼 일관성을 잃는다.**

기존 실행으로 원인을 더 좁힐 수 있다 (W128, plateau 기준):

| 구성 | plateau HQNR |
|---|---:|
| dual (`c6_c4d124`) | **0.9509** |
| MS-only, γβ 유지 (`MS1_w128_msonly`) | 0.9450 |
| MS-only plain (`S1_A0_W128_D124_MS2`) | 0.9460 |

→ 손실은 **PAN reconstruction task 제거**에서 오고, mode 조건화(γβ) 제거는 무관하다.

### 1.3 결과: 1차 탐색의 비교는 성립하지 않는다

- **plateau 로 보면 순위가 뒤집힌다.** 최고는 가장 작은 `S1_C0_W96_D124_MS2`(0.9486)
  이고 4-6M 후보는 전부 anchor(`S1_A0` 0.9460) 이하다.
  T01·T02·T03 은 best 와 plateau 의 **부호가 반대**다.
- 게이트가 best HQNR 로 뽑은 winner(`S1_T02` 0.9551)는 plateau 에서 0.9428 로 하위권이다.
- **같은 구조 dual vs MS-only plateau ΔHQNR = +0.0112 로 band(0.011)를 넘는다** —
  이 저장소에서 드문 유의 차이이고, 방향은 **dual 우세**다.

기존에 "MS-only 무손실"로 정리했던 결론(m1·MS1·MS2)은 **W96/W128 한정**으로 축소해야
한다. 그 대역에서는 붕괴 폭이 −0.004 수준이라 band 에 묻혔다.

## 2. 진행 중 — dual MARs 로 같은 격자 재탐색

기존 dual 실행 3벌을 재사용하고 5벌만 새로 돌려 4-6M 격자를 완성한다.

| 구성 | Params | 상태 |
|---|---:|---|
| W96·d124 (`R4_w96_d124_noattn`) | 2.13M | 재사용 |
| W128·d124 (`c6_c4d124`) | 3.77M | 재사용 |
| W144·d124 (`S1_T05_W144_D124_DUAL`) | 4.77M | 큐 2 |
| W152·d123 (`S1_T05_W152_D123_DUAL`) | 4.89M | 큐 4 |
| W160·d122 (`S1_T05_W160_D122_DUAL`) | 4.96M | **학습 중** |
| W160·d124 (`S1_T05_W160_D124_DUAL`) | 5.88M | 재사용 |
| W168·d123 (`S1_T05_W168_D123_DUAL`) | 5.97M | 큐 5 |
| W176·d122 (`S1_T05_W176_D122_DUAL`) | 5.99M | 큐 3 |

계획 §4.2 의 조건부 중간점(W152·W168)은 **조건 없이 둘 다** 돌린다 — 1차에서 SCC 가
포화(Δ<0.0002)라 게이트 조건이 성립하지 않았고, 24h 예산에 여유가 있어 격자를
비워 두는 것보다 채우는 편이 낫다. 예상 16h.

실행명 접두 `S1_T05_*` 는 1차 계획에서 "winner dual 대조"로 만든 config 를 그대로
쓴 것이다(구조 표기 `W160_D122_DUAL` 은 정확하다). 역할이 바뀐 점을 여기 남긴다.

## 3. 시트 기록

Note 에 **task 축을 항상 명시**하도록 바꿨다 — 이전에는 dual 이 기준값이라 아무것도
적히지 않아 MS-only 행과 dual 행을 시트에서 짝지을 수 없었다.

```
task=dual MARs (MS+PAN 재구성 · γβ mode 조건화)
task=MS-only plain (PAN 재구성 없음 · γβ 조건화 없음 — 4-6M 에서 후반 D_lambda 악화 주의)
task=MS-only (PAN 재구성 없음 · γβ 조건화 유지)
```

완료된 12행을 이 Note 로 갱신했다.
