# 2026-09-12 실험 보고서 — 정합 모듈 실험 종합 판정(s1) · 보정량 일관성 손실 가중치 탐색(s1) · 정합 모듈 없는 같은 크기 KD 최종 편성(s2·s3)

**작성일:** 2026-09-12
**과제:** 팬샤프닝(pansharpening) — 저해상도 다중분광 영상(MS)과 고해상도 흑백 영상(PAN)을 합쳐 고해상도 다중분광 영상(HRMS)을 만드는 문제. 논문 모델 PAN-Crafter(ICCV 2025)를 재현한 뒤 작은 U-Net 으로 줄이고, 줄인 만큼의 성능 손실을 회복하는 방법을 찾는 중.
**데이터:** WV3 — WorldView-3 위성 영상으로 만든 공개 팬샤프닝 벤치마크(PanCollection)의 WV3 세트. MS 8밴드 + PAN 1밴드, PAN 해상도는 MS 의 4배.
**평가:** 주 지표 HQNR — 원 해상도 테스트 영상 20장을 정답 없이 평가(1 에 가까울수록 좋음, 논문 비교 기준). 보조로 축소 해상도 테스트 20장의 SCC(높을수록 좋음) · ERGAS(낮을수록 좋음). HQNR 차이 0.0031 미만은 무작위 초기값(seed)만 바꿔도 생기는 범위라 "차이 없음"으로 판정. 이 0.0031 은 이날 ① 에서 처음 실측한 값. ① 의 분석에는 학습 마지막 평가 5회의 HQNR 평균(수렴 HQNR)도 사용.
**서버:** s1 · s2 · s3 — 실험용 GPU 서버(서버당 GPU 1장).

정합 모듈이 옮긴 PAN 을 기준으로 잰 HQNR 은 모델마다 기준 영상이 달라지고, 그 방식으로는 어떤 변형도 0.951~0.957 로 좋게 나옴 — 진단에만 쓰고, 판정은 모든 모델 공통의 원 PAN 기준 HQNR 로 고정.

| 잔여 오차 | 추가 이동을 되돌린 뒤 남는 이동량 오차의 평균 |
| 원 해상도 이동량 | 원 해상도 테스트 20장에서 정합 모듈이 PAN 을 옮기는 양의 중앙값 |
| 실측 PAN–MS 어긋남 | WV3 원 해상도 테스트 영상의 PAN–MS 전역 어긋남 중앙값 1.79 px(09-10 측정). 20장 모두 같은 방향 |
| 정답 기준 위치 감독 | 옮긴 PAN 의 경사 방향이 정답 영상(밴드 평균)의 경사 방향과 일치하도록 하는 손실. 정합 모듈에만 학습 신호 |
| 정답 edge 감독 | 출력 영상의 경계 응답(부호 있는 경사)을 정답 영상의 값에 직접 맞추는 보조 손실 |
| KD · Teacher · Student | 지식 증류 — 먼저 학습한 모델(Teacher)의 출력을 새로 학습하는 모델(Student)의 보조 정답으로 사용. 여기서는 Teacher 와 Student 의 크기가 같음 |
| KD 방식 단계 | 정답 L1 손실만 → 정답 손실 + 고정 비율로 Teacher 추종 → Teacher 오차가 큰 곳에 정답 손실 가중(정답 가중) → 여기에 Teacher 오차가 작은 곳에서 Teacher 추종 추가 → 여기에 Student 가 Teacher 보다 뒤지는 곳에서만 추종하도록 제한(적응형 KD). 모두 정답 손실은 모든 위치에 유지 |
| 정답 가중의 가중 지도 | 정답 가중 단계에서 Teacher 오차가 큰 위치일수록 정답 손실을 키우는 위치별 가중치. 대조 — 배치 평균 상수로 대체(위치 정보 제거) · 위치만 섞기(값 분포 유지) |
| 출력 통계 감독 | 출력 영상의 국소 통계를 목표 통계에 맞추는 보조 손실. 통계 종류 — 밝기(영상) 분산 · 방향별 경사 분산 · 경사 공분산 · 밴드 간 분광 공분산, 또는 경계(edge) 응답 자체 |
| 통계 정보원 | 목표 통계를 어디서 가져오나 — 정답 / Teacher 통계 오차가 큰 곳에 정답 가중 / 적응(적응형 KD 규칙으로 정답·Teacher 혼합) / 정답·Teacher 고정 비율 결합 / Teacher 단독 |
| 통계의 정답 항 · Teacher 항 | 통계 감독 손실 중 정답 통계에 맞추는 부분 · Teacher 통계에 맞추는 부분. 고정 결합 = 정답 항 + 0.1 × Teacher 항, 적응 = Teacher 오차 가중 정답 항 + 적응형 규칙의 Teacher 항, Teacher 단독 = Teacher 항(계수 1) |
| 방향 선택 KD | Teacher 추종 항 가운데 정답 방향과 맞는 출력값 · 통계 성분만 남기는 KD. 대조 — 같은 총량을 무작위 위치에 배치(총량 맞춤) · 선택 위치만 섞기 |
