# Teacher–Teacher DML — 합의 정규화로 작동하며 RR↔FR 트레이드다 (2026-08-27, 170hx)

동일 구조(T7 재구성본, 7.17 M) 두 peer 를 나란히 학습시키며 서로의 MS-mode 출력을
타깃으로 삼는 **symmetric Deep Mutual Learning** 을 검증했다.
계획: [s2_teacher_teacher_mutual_learning_plan.md](../research_log/s2_teacher_teacher_mutual_learning_plan.md)

## 결론

| | |
|---|---|
| **사전 등록 기준 판정** | **실패** — "ERGAS 유의한 악화 없음" 을 peer A 가 위반 (+0.45%, p=0.0001) |
| **실질 패턴** | **DML 은 RR↔FR 트레이드다.** HQNR·D_s 가 두 peer 방향 일관으로 개선(A 는 8/8), 대가는 시드 잡음 이하의 ERGAS 후퇴 |
| 기전 해석 | mutual loss 가 각 peer 의 특이한 고주파 환각을 상쇄하는 **합의 정규화** — no-reference FR 왜곡(D_λ·D_s)이 줄어든다 |
| 계획 §9 분기 | "한쪽만 개선" → **asymmetric λ 또는 one-way online KD 검토** |
| 부산물 | M0(λ=0) = **LN+nocrop 시드 2벌** — LN 의 RR 이득·FR 손실이 같은 서버에서 실측됐다 |

> **수치 신뢰도.** `matlab`(tools/metrics), 서버 170hx, **25K**(절대값 3.6% 비관적 — 50K·논문과
> 가로 비교 금지), FR 은 12–19 8장. 시드 1쌍(2025/2026) — 0.8% 미만 차이는 확정하지 않는다.

### 대응표본 t-검정 (M1 vs M0, RR 20장 / FR 8장)

| | ERGAS | HQNR | D_λ | D_s |
|---|---:|---:|---:|---:|
| peer A | **+0.45%** p=1.4e-4 (3/20) | **+0.57%** p=6e-5 (**8/8**) | **−10.3%** p=6e-5 (8/8) | **−5.4%** p=0.007 (7/8) |
| peer B | +0.21% p=0.050 (6/20) | +0.12% p=0.050 (6/8) | +0.22% p=0.85 | −3.5% p=0.07 (6/8) |
| 방향 일관 | 아니오(둘 다 악화) | **예** | 아니오 | **예** |

- **FR 개선은 실재한다**: HQNR·D_s 가 두 peer 같은 방향, A 는 강한 유의(8/8).
  B 는 p≈0.05 경계 — 시드 1쌍 한계로 확정하지 않는다.
- **RR 비용도 실재한다**: peer A ERGAS +0.45% 는 대응표본 유의. 크기는 시드 잡음(0.81%) 안.
- 앙상블은 FR 전 지표 유의 개선 — 그러나 단일 peer 기준이 판정 기준이다(Case D).

### peer 다양성

| | 오차 상관 | 오라클 ERGAS | 이득 |
|---|---:|---:|---:|
| M0 | 0.9557 | 1.9377 | +8.16% |
| M1 | 0.9706 | 1.9802 | +6.57% |

λ=0.10 이 peer 를 붙였지만(0.956→0.971) **붕괴는 아니다** (disagreement 0.0035 유지).
**시드 다양성(ρ=0.9557)이 8/20 의 구조쌍(용량비 1.2×, ρ=0.9733)보다 크다** —
"용량비 1.0 이면 ρ≥0.97" 외삽은 틀렸다.

## 3. 부산물 — LN 의 같은 서버 실측 (M0 = LN+nocrop 시드 2벌)

| 25K, s2, crop=False 고정 | norm | ERGAS↓ | HQNR↑ | D_λ↓ |
|---|---|---:|---:|---:|
| `p25_nocrop` | gn | 2.1611 | **0.9427** | **0.0281** |
| M0 peer A/B | **ln** | **2.1098 / 2.1185** | 0.9315 / 0.9335 | 0.0352 / 0.0334 |

**LN: RR −2.4/−2.0% (시드폭의 2.4~2.9배), FR HQNR −1.0~1.2% (두 peer 일치).**
s1 관측(RR 이득·FR 손실)이 같은 서버에서 재현됐다. LN 은 트레이드오프다.

흥미로운 대칭: **DML(λ=0.10)의 FR 이득(+0.57%)이 LN 의 FR 손실(−1.1%)의 절반을 되돌린다.**
LN + DML 조합은 RR 이득을 유지하며 FR 손실을 줄이는 방향일 수 있다 — 미검증.

## 4. 배제한 가설

| λ=0.10 에서 peer collapse | disagreement 곡선 | **기각.** 0.0035 유지, 상관 0.971 |
