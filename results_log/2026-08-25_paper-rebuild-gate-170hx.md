# 논문 재구성본 관문 — 50K 결과와 그 해석 (2026-08-25, 170hx)

[논문 충실 재구성본](2026-08-24_paper-faithful-rebuild.md)(7.1707 M)의 **WV3 50K 학습**이 끝났다.
[실험 계획서](../research_log/paper_faithful_experiment_plan_v1.md) Phase 1 이 사전 등록한
판정 기준에 따라 결과를 읽는다.

## 결론

| | |
|---|---|
| **결과** | reduced ERGAS **2.1423** (`fixed` 계열, `matlab`, 170hx) |
| **사전 등록 판정** | **실패 구간** — 기준선 `≥ 2.13` 이면 "구조는 원인이 아니다" |
| **다만** | 프로젝트가 낸 **50K 최고 수치**이고 RR 4개 지표 전부 배포 코드보다 낫다 |
| **분기** | 계획서대로 `fallback` — 재구성본의 미확정 선택지 4종 (25K) 로 선회 |

**구조는 격차의 일부를 설명하지만 사전에 정한 문턱을 넘지 못한다.**
논문 2.040 대비 격차가 **+6.09% → +5.01%** 로 줄었을 뿐이다.

> **수치 신뢰도.** 실행 `fixed`(재구성본은 논문 Eq (10)/(11)·Sec 3.3 를 반영한 상태),
> 측정 `matlab`(DLPan 프로토콜 포팅 `tools/metrics/`), 서버 **170hx**.
> **비교 대상인 배포 코드 수치는 다른 서버에서 나왔다** — §3 의 경고를 반드시 함께 읽을 것.

## 2. 사전 등록 기준에 따른 판정

계획서가 **결과를 보기 전에** 정해 둔 기준이다.

| 결과 | 해석 | 다음 |
|---|---|---|
| ERGAS ≲ 2.08 | 재구성 성공 | Phase 2 진행 |
| 2.08 ~ 2.13 | 부분 성공 | 진행하되 병행 조사 |
| **≳ 2.13** | **구조는 원인이 아니다** | **계획 중단, 학습 파이프라인으로 선회** |

**2.1423 은 세 번째 구간이다.** 문턱을 0.6% 차이로 넘지 못했다.

**사후에 기준을 옮기지 않는다.** 2.1423 이 프로젝트 최고 수치라는 이유로 "부분 성공" 으로
재분류하고 싶은 유혹이 있으나, 그것이 사전 등록을 하는 이유를 무너뜨린다.
계획서가 정한 분기(`fallback`)를 그대로 실행했다.

### 그럼에도 기록해야 할 것 — 방향은 맞았다

RR 네 지표 **전부** 배포 코드보다 낫다.

| 지표 | 배포 `fixed` (구서버) | 재구성본 (170hx) | 차이 |
|---|---:|---:|---:|
| ERGAS↓ | 2.1804 | **2.1423** | **−1.75%** |
| SAM↓ | 2.9024 | **2.8863** | −0.55% |
| Q8↑ | 0.9178 | **0.9188** | +0.11% |
| PSNR↑ | 37.4559 | **37.6026** | +0.39% |

**파라미터가 28% 적은데 RR 이 더 좋다.** 논문 대비 격차도 ERGAS +6.09% → **+5.01%**,
SAM +4.50% → **+3.56%** 로 줄었다. 배포 코드에 성능에 기여하지 않는 부분이 있었다는
[재현 감사 §2.5 후보 A](2026-08-24_reproduction-audit.md) 와 일관된다.

### 반대 방향도 있다 — FR 은 나빠졌다

| | D_λ↓ | D_s↓ | HQNR↑ |
|---|---:|---:|---:|
| 배포 `fixed` (구서버) | 0.0234 | 0.0265 | 0.9508 |
| 재구성본 (170hx) | 0.0280 | 0.0299 | **0.9431** |

**HQNR −0.81%**, D_λ·D_s 둘 다 악화다. RR 이 좋아지면서 FR 이 나빠졌다.
[8/24 요약 §3.2](2026-08-24_wv3-summary-and-protocol.md) 의 기전과 방향이 맞다 —
**PAN 고주파를 더 주입할수록 RR 은 좋아지고 D_s 는 나빠진다.** 재구성본은 AttnBlock 이 3개뿐이지만
입력이 9ch 로 줄면서 오히려 CM3A 경로 의존이 커졌을 가능성이 있다(§4 ③이 이것을 다룬다).

**FR 8장은 검정력이 낮다**(D_λ 표준편차가 평균의 46%). 단정하지 않는다.

## 3. 이 비교의 한계 — 서버가 다르다

**§2 의 배포 코드 대조는 구서버 수치이고 재구성본은 170hx 수치다.**
같은 설정 4벌의 폭이 이미 **0.79%**, 동일 구성 시드 폭이 **0.81%** 였다.

| 차이 | 크기 | 잡음 대비 |
|---|---:|---|
| 재구성본 vs 배포 `fixed` (ERGAS) | −1.75% | 잡음의 2.2배 — **시사적** |
| 재구성본 vs 배포 `baseline` (ERGAS) | −1.02% | 잡음의 1.3배 — **판정 불가** |
| SAM·Q8·PSNR 차이 | 0.1~0.6% | **전부 잡음 이하 — 인용 금지** |

**ERGAS 개선만 잡음을 넘고, 그것도 `fixed` 대조에서만이다.** 나머지는 방향만 참고한다.

### 같은 서버 증거는 오히려 반대였다

170hx 에서 배포 코드(`wv3_fixed_valsel`)를 epoch 90 까지 돌리다 중단했는데,
**같은 epoch 에서는 배포 코드가 앞섰다.**

| epoch | 재구성본 val ERGAS | 배포본 val ERGAS | |
|---:|---:|---:|---:|
| 15 | 2.7675 | 2.6831 | 배포본 우세 3.1% |
| 90 | 2.3849 | 2.3327 | 배포본 우세 **2.2%** |

재구성본은 **약 25 epoch 뒤처져 있었다.** 파라미터가 28% 적으니 초기 수렴이 느린 것은
자연스럽고, cosine 스케줄은 마지막 1/3 에 이득이 몰린다. 그러나 **배포본을 끝까지 돌리지 않았으므로
같은 서버 최종 대조는 존재하지 않는다.** 이것이 이 문서의 가장 큰 한계다.

> **교훈**: 대조군을 중간에 죽이면 나중에 그 자리가 빈다.
> 배포 코드 앵커를 중단한 판단([WIP](2026-08-24_WIP_170hx-teacher-baseline.md))은
> "비교 대상이 없다" 는 이유였으나, 그때는 재구성본이 그 비교 대상이 될 줄 몰랐다.

| | |
|---|---|
| best val ERGAS | 2.265851 @ **epoch 245 / 248** |
| 상위 5개 epoch 폭 | **0.05%** (2.2659 ~ 2.2670) |

best 가 245/248 이라는 것은 **50K 에서 아직 수렴이 끝나지 않았다**는 뜻이기도 하다.

## 5. 다음 — 사전 등록대로 `fallback` 을 실행 중

**남은 격차 +5.01% 는 구조 밖에 있다.** 재구성본에서 논문이 정하지 않아 임의로 골라야 했던
선택지 넷을 25K 로 확인한다. 전부 대조군 `p25_s2025`(25K) 대비 **정확히 한 항목만** 다르다.

| # | 실행 | 변경 | Params | 근거 |
|---|---|---|---:|---|
| ① | `p25_drop02` | `dropout 0.0 → 0.2` | 불변 | 배포본은 0.2, 재구성본은 0.0. **논문은 dropout 을 언급하지 않는다** — 논문 충실성과 무관하게 임의로 정해진 값 |
| ② | `p25_nocrop` | `crop True → False` | 불변 | [감사 §2.5 후보 B](2026-08-24_reproduction-audit.md). 배포본 `crop` 은 자른 뒤 `cv2.resize` 로 복원이라 실은 scale jitter 이고 MS→GT 열화관계를 깬다. 기존 `d1_nocrop` 은 배포 모델용이라 재구성본 적용은 새 실험 |
| ③ | `p25_in11` | 입력 9ch → 11ch | +2,304 (7.1730 M) | [KNOWN_ISSUES A-3](../KNOWN_ISSUES.md) 이 "본문이 축약된 것" 으로 판정한 항목. 빠진 `pan − ↑lpan` 은 INTRO 가 "정합 보정의 실체" 라 부른 고주파 채널이다. **논문 일치(+0.041%)가 깨지지 않는다** |
| ④ | `p25_d134` | depth (2,2,4) → (1,3,4) | **완전 동일** | 논문은 stage 별 ResBlock 수를 기재하지 않는다. `2(d₀+d₁)+d₂ = 12` 를 만족하는 배분 **7가지가 전부 7.1707 M** 이다 |

**②·③ 이 특히 FR 악화(§2)와 연결될 수 있다** — 둘 다 PAN 고주파가 모델에 들어가는 경로를 바꾼다.

### 무엇을 보면 되는가

- **대조군은 `p25_s2025`(25K, 같은 서버)다.** 50K 인 이 문서의 2.1423 과 가로로 읽으면 안 된다
  (25K 편향 −3.6%).
- 네 개 중 하나라도 **2σ 를 넘어 개선**되면 그것이 남은 격차의 일부다.
- **넷 다 무차별이면** 격차는 구조도 이 네 선택지도 아니며, 남는 후보는
  학습 파이프라인(잔차 기준선) 또는 **저자 코드 없이는 규명 불가**다.
- σ 는 구서버 25K×3 (`p25_s2025/s1234/s7777`) 이 준다. **성질값으로만 참고하고
  우리 수치와 같은 표에 넣지 않는다.**

## 7. 한계

- **같은 서버 배포 코드 50K 대조가 없다**(§3). 이 문서에서 가장 큰 구멍이다.
- **시드 1벌.** ERGAS −1.75% 는 시드 폭 0.81% 의 2.2배라 시사적이나 확정은 아니다.
- **FR 8장**은 검정력이 낮다(D_λ 표준편차가 평균의 46%).
- **FLOPs 는 여전히 미해결** — 재구성본도 161.9 G 로 논문 79.03 G 의 2.05배다.
- **WV3 단독.** QB·GF2 미측정.
- best 가 epoch 245/248 이라 **50K 에서도 수렴이 끝나지 않았다.** 더 긴 학습이
  격차의 일부를 메울 가능성은 배제되지 않았다.
