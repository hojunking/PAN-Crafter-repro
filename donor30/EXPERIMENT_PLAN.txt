1. Scope and isolation
This additive donor30 namespace does not change or stop a running DirectShift48
campaign. S1 stays WV3 (8 bands); S3 stays GF2 (4 bands). Each server makes its own
donors, chooses one local donor and uses that SAME A/T checkpoint for every local
Stage 2 comparison. No cross-server absolute-metric ranking or donor exchange.
Implementation/checking does not itself authorize starting or killing jobs.

3. Checkpoint retention and local donor choice
For EACH run preserve a best-HQNR checkpoint AND a donor-gate minimum-ERGAS
checkpoint, plus resumable latest state. A/T always come from one step.
Donor gates: WV3 HQNR>=.959; GF2 HQNR>=.965, full precision inclusive.
Among gate-passing checkpoints, minimize ERGAS; ties maximize HQNR, then SCC,
then use earlier step/stable run ID. No ERGAS cap blocks research donor storage.
Best-HQNR fallback ranking is HQNR, SCC, ERGAS, earlier step, stable run ID.
Checkpoint files need actual reload/identity verification before selection.
After BOTH donor runs finish, select one server-local donor from saved records.
Default if no model reaches the HQNR gate: continue Stage2 with best-HQNR donor
ONLY under explicit BEST_HQNR_EXPLORATORY status and conspicuous warning; never
mark it donor-qualified or final-target-qualified. Fallback may be disabled in
the lane config. No valid reloadable donor means BLOCKED, never fabricated A/T.
Research donor qualification, final HQNR+ERGAS target qualification and existing
sheet representative rules are distinct. Existing sheet thresholds do not move.

4. Shared Stage2 conditions
Frozen single shared donor Aligner, frozen donor Teacher, fresh W104 d(1,2,2)
P0/BICUBIC_MS Student; Student alone receives optimizer gradients. Teacher and
Student see the SAME corrected PAN. No A clone that silently trains.
Student LR=1e-4, AdamW wd=.01, batch48=12x4, FP32, warmup100/cosine50K.
Same initial Student/data/augmentation streams within each replica across modes.
S1 Student seeds 261015111/261015112; S3 261015311/261015312.
Teacher-only GT error e and aligned-PAN/GT Scharr discrepancy q are detached.
tau_e/tau_q are global PIXEL medians from the complete RR TRAIN population,
not medians of scene medians, not validation/test values. Identical normalization,
RGB channel indexing, Scharr and valid support in calibration and training.
Any numerical floor, population counts and calibration donor hash are recorded.
No q/e input or GT dependency at FR inference. Geometry isn't guaranteed to be
accurate merely because q is small; q includes sensor/contrast/texture effects.

Modes (same Student and frozen donor for all comparisons):
GT: hard GT L1 only.
E: (1-w_e)*Teacher L1 + w_e*GT L1, w_e=e/(e+tau_e).
EQ: E plus mean(w_q*Student-GT Scharr edge), w_q=q/(q+tau_q), lambda_edge=1.
UNIFORM: E plus unweighted Student-GT Scharr edge, lambda_edge=1; optional
diagnostic separating q weighting from the effect of adding any edge loss.
The two L1 blend weights sum to one: E redistributes GT/Teacher trust; it does
not by itself increase total pixel weighting. Do not claim guaranteed improvement.
UNIFORM is a raw lambda-matched edge ablation, not mean-gradient-matched weighting.

8. Interpretation
The experiment tests whether fixed geometry lets reconstruction improve while
preserving HQNR, and whether E/EQ improve on same-capacity GT-only training.
Frozen A does not guarantee fixed D_s: Student output still changes. No claim
that current Teacher capacity is exhausted; no guaranteed 0.959+ERGAS target.
Compare paired modes within server and replica; report both seeds, not only the
winner. Calibration uses train only, but HQNR model selection is test-aware;
record that limitation rather than describing these evaluation scenes as held-out.
